Correlation with entropy

Topological features measure the geometry of internal computation, not the uncertainty of output distribution. That's why the correlation with output entropy is near zero — these are orthogonal signals.

Each prompt's hidden states at the final layer form a point cloud in Rd. Persistent homology extracts topological structure — connected components (H0) and loops (H1) — that correlates with whether the model will answer correctly.

The 7 features

The bridge feature comes from a discovery that transformer hidden states universally organize into two clusters, with position 0 serving as the sole computational bridge between them. See ATT research.

Get started

$ pip install -e .

Python API

from topo_confidence import TopoConfidence

tc = TopoConfidence("Qwen/Qwen2.5-1.5B-Instruct")
tc.calibrate(calibration_prompts, calibration_labels)

# Predict confidence on new problems
confidences = tc.predict_confidence(["What is 2+2?", "Prove the Riemann Hypothesis"])

# Only answer when confident
results = tc.selective_predict(problems, threshold=0.7)

Combined scorer (topo + entropy fusion)

from topo_confidence import CombinedConfidence

cc = CombinedConfidence("Qwen/Qwen2.5-1.5B-Instruct")
cc.calibrate(prompts, labels)  # 7 topo + 2 output = 9 features

CLI

# Score prompts
$ topo-confidence score "What is 2+2?"

# Calibrate on labeled data
$ topo-confidence calibrate data.jsonl -o calibrated.pkl

# Selective prediction
$ topo-confidence selective -c calibrated.pkl -f problems.txt -t 0.7

# Explain a prediction
$ topo-confidence explain -c calibrated.pkl "What is 2+2?"

Applications

Model routing

Use as a gate for cheap-to-expensive model cascading. Route low-confidence queries to a stronger model.

Agentic verification

Per-step confidence without multi-sampling. Know which tool calls and reasoning steps to trust.

Training data filtering

Select high-confidence synthetic data for fine-tuning. Better training signal from the same generation budget.

Real-time monitoring

Track hidden-state geometry during generation. Alert when topology shifts toward uncertain territory.
