Each prompt's hidden states at the final transformer layer form a point cloud in Rd. Persistent homology extracts topological structure — connected components (H0) and loops (H1). Layer-wise dynamics (cosines, PCA spectrum, SVD ratios) capture how representations evolve across depth. Together: 44 features that predict correctness.

Get started

$ pip install -e .

Python API

from topo_confidence import TopoConfidence

tc = TopoConfidence("Qwen/Qwen2.5-1.5B-Instruct")
tc.calibrate(calibration_prompts, calibration_labels)

# Predict confidence on new problems
confidences = tc.predict_confidence(["What is 2+2?", "Prove the Riemann Hypothesis"])

# Only answer when confident
results = tc.selective_predict(problems, threshold=0.7)

CLI

# Score prompts
$ topo-confidence score "What is 2+2?"

# Calibrate on labeled data
$ topo-confidence calibrate data.jsonl -o calibrated.pkl

# Selective prediction
$ topo-confidence selective -c calibrated.pkl -f problems.txt -t 0.7

Applications

Topo-gated majority vote

Gate majority voting with topo-confidence. At tau=0.3: zero regressions, 89% sample savings with adaptive sampling.

Model routing

Route low-confidence queries to a stronger model. Single-pass scoring means no generation overhead for the routing decision.

Agentic verification

Per-step confidence without multi-sampling. Know which reasoning steps to trust before committing to an action.

Training data filtering

Select high-confidence synthetic data for fine-tuning. Better signal from the same generation budget.
