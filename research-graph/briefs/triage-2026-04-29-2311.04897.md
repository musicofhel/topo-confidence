# Triage brief — 2311.04897 — Future Lens: Anticipating Subsequent Tokens from a Single Hidden State

Source: https://arxiv.org/abs/2311.04897
Triaged: 2026-04-29

## Refutations

1. **Refutes F-2's "abstract correctness" reading by reducing it to next-token forecasting.**
   Future Lens shows that a single GPT-J-6B hidden state encodes the literal future-token stream (>48% accuracy on t+2 with linear approximation; higher with learned soft prompts). If the *same* probe applied to Qwen-2.5-1.5B's prefill L19 hidden state decodes the upcoming answer tokens with sharply higher accuracy on K=1-correct vs K=1-incorrect problems, then the F-2 prefill DoM signal (AUROC 0.7731) is not measuring abstract familiarity / "can-I-solve-this" — it is measuring "the early layers have already drafted a token sequence that happens to be the correct answer." That collapses F-2 into a *degenerate look-ahead*, not a structural correctness predictor.
   *Mechanism*: linear future-state probe trained on Pile-style next-token targets, applied per-problem to prefill L19 of MATH-500.
   *Falsifiable test*: compute per-problem t+2…t+10 token-prediction accuracy from prefill L19 via Future-Lens linear probe; correlate with K=1 outcome and compare AUROC to DoM AUROC. If Future-Lens accuracy alone matches or beats 0.7731, the abstract framing is gone.

2. **Refutes H-5 directly: "familiarity vs decomposability" reduces to future-token surfaceness.**
   H-5 hypothesizes the prefill signal is about problem familiarity or decomposability. Future Lens demonstrates the alternative competing hypothesis with mechanism: hidden states *literally contain* the upcoming surface-form tokens. If on MATH-500 the Future-Lens-decoded tokens at the last prefill position predict K=1 correctness via simple "is the decoded prefix a plausible answer onset" heuristic at AUROC ≥ 0.70, then there is no abstract structure to discover — H-5 is killed and replaced by a more boring story.
   *Mechanism*: trained future-token-decoder hits the *vocabulary surface* not a latent decomposability variable.
   *Falsifiable test*: extract Future-Lens predicted tokens at last prefill position; classify "starts-with-numeric-equation-onset" vs "starts-with-verbal-hedge"; check AUROC against K=1 outcome.

3. **Refutes F-3 orthogonality as a probe-choice artifact.**
   F-3 reports cos(prefill_DoM, final_DoM) = 0.046, used to argue prefill and final-token signals live in distinct subspaces. Future Lens shows position-t hidden states already encode position-t+k information *with a learnable transformation*. If a learned linear map T such that T·h_prefill ≈ h_final brings the two DoM directions into alignment (cos(T·prefill_DoM, final_DoM) ≫ 0.046), then the orthogonality finding is not a structural fact about the network — it is an artifact of comparing raw vs. raw without the position-shift transform Future Lens describes.
   *Mechanism*: any learned position-shift map analogous to Future Lens's linear approximation could absorb the orthogonality.
   *Falsifiable test*: train a single linear map h_prefill → h_final on cached Stage 2 NPZs (no labels needed — just position pairs); compute cos(T·prefill_DoM, final_DoM). If > 0.5, F-3 needs to be retitled "raw-coordinate orthogonality" not "subspace orthogonality."

4. **Refutes F-7's "collective geometric" framing by attributing D-bucket fragility to future-token decoder confidence.**
   F-7 says D-bucket (K=1 right, K=8 wrong) has a distinctive *collective* geometric signature, hinted at in HYPOTHESES H-7 and H-21. Future Lens provides a simpler hypothesis: D-bucket prefill states are exactly those that have a *low-margin* future-token decoder distribution — the model has greedy-decoded a correct answer but the decoder distribution is broad, so K=8 sampling diverges. That is a *per-problem* property (entropy of the future-token distribution), not collective geometry. If Future-Lens decoder entropy at the last prefill position separates D from A bucket, the "collective signature" framing is supplanted.
   *Mechanism*: D-bucket = high-entropy next-token distribution that happens to have correct argmax.
   *Falsifiable test*: compute Future-Lens decoder entropy at last prefill position for the 36 D-bucket and 207 A-bucket problems; if Mann-Whitney U separates them at p < 0.01, F-7's "collective" framing weakens.

## Direct connections to F-N / H-N

- **F-2 (Prefill L19 DoM AUROC 0.7731 OOF, 1.5B)** — Future Lens's >48% t+2 accuracy on GPT-J directly competes for the same explanatory mechanism on prefill activations. Either DoM ≈ future-token-decoder, or the two signals are independent (which would *strengthen* F-2 as something Future Lens does not already capture). This connection is the central thing to test.
- **F-3 (cos(prefill, final) = 0.046)** — Future Lens reframes the comparison: the right alignment is via a learned shift map, not raw cos. Pre-Lens transformation is a missing step in F-3.
- **H-5 (familiarity vs decomposability)** — Future Lens supplies the strongest competing hypothesis to date. Promotion priority of H-5 should be reconsidered until the Future-Lens probe has been run on prefill L19.
- **H-13 (head-level attribution of prefill vs final-token circuits)** — Future Lens locates future-token signal in mid-network MLP outputs; if Qwen replicates, H-13 should specifically isolate MLP-output projections at L19.
- **H-8 (DoM stability across training checkpoints)** — Future Lens's transferability across prompts (transplanted hidden states retain decoding behavior) provides a complementary stability test we have not run.

## Methodologies extracted

- **Linear future-state approximation (per-layer)** — fit a linear map W: h_t^layer → h_{t+k}^last_layer, then decode with the model's unembedding. One linear regression per (layer, k) pair.
  *Replication cost*: ~20min CPU on cached Stage 2 NPZs (Qwen-2.5-1.5B prefill activations already stored).
  *We'd plausibly run this*: yes — cleanest way to test Refutation 1.

- **Fixed-prompt causal intervention** — transplant a hidden state from a source context into a fixed neutral target prompt at a chosen layer/position; decode the resulting completion to see whether source-context tokens leak through.
  *Replication cost*: ~2h H100 (needs a forward pass per problem-layer combo for 500 problems).
  *We'd plausibly run this*: yes — directly tests Refutation 4 by comparing leakage strength on D vs A bucket.

- **Learned soft-prompt causal intervention** — train a learnable prefix vector that, when prepended to a transplanted hidden state, maximizes decoding of the source context's next tokens. Surfaces signals invisible to fixed-prompt extraction.
  *Replication cost*: ~6h H100 (small backprop loop over a few hundred soft-prompt parameters; data-cheap).
  *We'd plausibly run this*: yes — gives the strongest single-layer "what does this hidden state know about its future" signal, and matches H-5's level of rigor.

- **Future Lens visualization** — render decoded probabilities for tokens at positions t+2…t+k overlaid on the source position t, per layer.
  *Replication cost*: trivial (matplotlib over the linear-probe outputs).
  *We'd plausibly run this*: yes — gives a per-problem readout we can publish alongside the headline DoM heatmap.

## Approaches & framings

- **Future-token surfaceness as a default null** — the right baseline for *any* hidden-state correctness probe is "could a Future-Lens-style decoder have done the same job by reading off the upcoming surface tokens?" This is a stronger null than Gaussian-noise null (F-10 already used this for PH); we have not yet run it for DoM.
- **Position-shift transforms as the natural alignment** — comparing hidden states at different positions in *raw coordinates* is naive; the Future Lens framing argues for first applying a learned t→t+k map. Re-do F-3 with this framing.
- **Hidden states as draft-token caches** — the framing that mid-layer activations literally cache future surface tokens (rather than abstract reasoning state) is in direct tension with our preferred "abstract correctness signal" narrative. Worth taking seriously as the simpler explanation.
- **Vocabulary-side decoding as a debugging tool** — treat the unembedding-projection of probed activations as primary signal, not just a sanity check. We have under-used logit-lens-style readouts.

## Datasets & benchmarks

- **The Pile (or Pile-style next-token prediction prompts)** — used by Future Lens to fit the linear and soft-prompt probes. License: open. Applicable? *Yes* — we can replicate their training setup using a Pile slice as auxiliary fitting data, then evaluate on MATH-500 prefill states.
- **Custom transplant prompts (released)** — small set used for fixed-prompt interventions. Open via the project page (future.baulab.info). Applicable? *Yes* — start point for Qwen replication.

## Implementation details worth capturing

- Probes target GPT-J-6B (28 layers, dim 4096). Qwen-2.5-1.5B has 28 layers, dim 1536 — same depth, narrower. Per-layer probing should transfer in shape.
- Mid-network layers carry the strongest future-token signal in GPT-J. For Qwen, that is squarely in our L19 zone — convenient.
- MLP-output projections are reportedly the dominant carrier; isolate `mlp_out` versus `attn_out` residual contributions, do not just probe the residual stream.
- Soft prompt is a small learnable prefix (handful of vectors); training is data-cheap, backprop only through the prefix.
- Linear probe: standard ridge regression with mild L2; no exotic optimizer needed.
- Code & data on the project page (future.baulab.info) and GitHub. CoNLL 2023 camera-ready PDF available.

- **Future-Lens decoder entropy on D vs A bucket** — Mann-Whitney on entropy of decoded distribution at last prefill position; tests Refutation 4.

## Proposed PAPER_INDEX.md classification

## 2311.04897 — Future Lens: Anticipating Subsequent Tokens from a Single Hidden State (Pal, Sun, Yuan, Wallace, Bau, CoNLL 2023)

**Relevance:** Future Lens demonstrates that single hidden states in GPT-J-6B encode the literal future token stream — >48% top-1 accuracy at t+2 via a per-layer linear approximation, with stronger results from learned soft-prompt causal interventions. This is the strongest available competing null for our F-2 prefill DoM signal: either prefill L19 DoM is a degenerate read-off of the upcoming answer tokens (in which case F-2 collapses into next-token forecasting), or DoM survives the Future-Lens null and we have evidence for a structural correctness predictor distinct from look-ahead. The paper also reframes F-3's raw-cosine comparison as naive (the natural alignment is via a learned position-shift transform) and supplies an alternative mechanism for F-7's D-bucket fragility (broad future-token decoder distribution with correct argmax).

**Key claim we tested:** A single mid-network hidden state encodes its own future tokens with sufficient fidelity that a small linear probe (or learned soft prompt) can decode them.

**Our result:** **TO TEST.** Three falsifiable experiments specified (P11-FE97, FE98, FE99): linear future-state probe on Qwen-2.5-1.5B prefill L19, position-shift transform recheck of F-3, MLP-out / attn-out decomposition of prefill DoM. None yet executed. F-2 narrative should be tagged "pending Future-Lens null check" until FE97 completes.

**Related experiments:** P11-FE97, P11-FE98, P11-FE99, P11-FE100; H-97, H-98, H-99.

**Status:** TO TEST
