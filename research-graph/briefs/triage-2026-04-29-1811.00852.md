# Triage brief — 1811.00852 — Understanding Deep Neural Networks Using Topological Data Analysis

Source: https://arxiv.org/abs/1811.00852
Triaged: 2026-04-29

## Refutations

1. **Refutes F-7 (D-bucket has *distinctive* collective geometric signature) if Mapper finds incorrect-prediction images cluster into multiple semantically-coherent topological groups generically.** Goldfarb's pixel-feature Mapper run (Figs. 9–14) shows misclassifications partition into ≥4 distinct interpretable clusters (cluttered backgrounds, glare, camouflage, low saturation) on a generic vision task. If applying Mapper to our cached prefill L19 activations on MATH-500 also yields multiple correctness-imbalanced clusters, then "D-bucket as a singular geometric signature" loses its specificity — it would just be one of several incorrect-leaning clusters that any Mapper-on-activations would surface, refuting F-7's "collective signature" framing. Falsifiable: run KeplerMapper with VarianceNormalizedEuclidean + PCA-2 lens (Goldfarb's params, resolution 50, gain 3) on our 1.5B prefill L19 activations cache; if the D-bucket 36 problems do not concentrate in a single dense node-group disjoint from other incorrect-bucket nodes, F-7 is refuted.

2. **Refutes F-2 (Prefill L19 DoM as a *supervised-direction* correctness predictor) if unsupervised Mapper-cluster membership achieves comparable correctness AUROC.** Goldfarb's earliest figure (the activation-Mapper colored by classification accuracy, Fig. 1) shows red/blue cluster separation arising directly from unsupervised topological structure — no labels were used to fit the lens or metric. If Mapper-cluster membership on our prefill L19 cache predicts MATH-500 correctness at AUROC ≥ 0.7731, then the supervised DoM direction is gratuitous — the same predictive content is recoverable by unsupervised topology, refuting the "trained probe is the channel" story underlying F-2. Mechanism: Mapper builds clusters from local density / lens; if correctness sorts onto those clusters, the predictive content is a property of the embedding, not of any single linear direction. Falsifiable: cluster-purity-by-correctness on Mapper graph vs. AUROC of held-out logistic probe.

3. **Refutes F-10 (PH on trained residual streams is at the Gaussian null) as "no exploitable topology" if Mapper exposes structure where PH did not.** F-10's strong reading is that residual-stream geometry has no usable topological signal — but Goldfarb's whole paper argues Mapper *does* surface usable structure on trained-network activations, even though PH-style Betti numbers on the same data would likely also be uninformative. Persistent homology summarizes global cycles; Mapper summarizes local connectivity. If Mapper-cluster cohesion on our P11 H100 residuals is non-trivially associated with correctness while PH-Betti is null, then F-10's interpretation needs to be narrowed from "no topology" to "no PH-detectable topology" — a different and weaker claim. Falsifiable: re-run Mapper on the same residual cache that produced F-10's null and check cluster→correctness purity.

## Direct connections to F-N / H-N

- **F-7 (D-bucket collective signature)** — Goldfarb's "problematic-label" cluster discovery (≥3 occurrences, <40% accuracy) is structurally identical to our D-bucket definition (K=1 right, K=8 wrong concentrated). The headline anchor here is the 36 D-bucket / 207 A-bucket split; Goldfarb's method would test whether that split is one cluster or many.
- **F-10 (PH at Gaussian null)** — direct methodological prior on TDA-applied-to-activations, but uses Mapper not PH. Anchor: F-10's null result is a PH-specific result; this paper hints Mapper might escape that null.
- **F-2 (Prefill L19 DoM AUROC 0.7731)** — connection via "unsupervised topology vs supervised direction" framing. The 0.7731 number is the bar Mapper-cluster purity would have to clear to refute the supervision premise.
- **F-8 (Selective prediction at coverage 0.5 = 71.6%)** — Goldfarb's "use cluster-membership as a confidence prior on the prediction" idea (the cougar-in-cage example) is a direct selective-prediction analog without a trained probe. Mapper-cluster purity might match or beat 71.6% on the same coverage budget.
- **H-7 (Density-based outlier detection finds D-bucket)** — Mapper is essentially density-on-lens-space; this paper supports H-7's premise but with a categorical-cluster rather than continuous-outlier flavor.
- **H-19 (C_exact verification routing beats C_infer scaling)** — Goldfarb's "train new learners for each problematic cluster" proposal is a topology-gated mixture-of-experts, the exact prior-art for cluster-conditioned routing in H-19's frame.

  *Replication cost*: ~30min CPU on cached prefill L19 activations using KeplerMapper (open-source).
  *We'd plausibly run this*: yes — directly tests Refutations 1 and 3 against our existing data.

- **Variance-Normalized Euclidean metric + PCA-2 lens, resolution=50, gain=3** — Goldfarb's specific Mapper hyperparameters.
  *Replication cost*: trivial (parameter dict).
  *We'd plausibly run this*: yes — gives a concrete starting point so we don't need to sweep.

- **"Problematic label" definition** — categorical: "appears ≥3 times in test set with <40% accuracy".
  *Replication cost*: trivial; equivalent to our D-bucket bookkeeping.
  *We'd plausibly run this*: no — we already have a sharper version (K=1 right / K=8 wrong).

- **Cluster-conditioned auxiliary learners (mixture-of-experts gated by topology)** — train a separate classifier per problematic Mapper cluster.
  *Replication cost*: 1 day CPU if MATH-500 clusters are clean.
  *We'd plausibly run this*: yes — directly intersects H-19's verification-routing frame.

- **Heat-map visualization for activation localization (per Ozbulak 2019)** — gradient-based saliency on convolutional layers.
  *Replication cost*: not directly applicable (no spatial structure in transformer residuals).
  *We'd plausibly run this*: no — closest analog would be per-token attention attribution, which we already have routed in H-13.

## Approaches & framings

- **Topology-as-input-property prior on confidence**: "use cluster-membership *before* the network runs to set a prior on prediction confidence" — analogue to our prefill-DoM-as-confidence frame, but unsupervised. Intersects F-2 / F-8 by suggesting an alternative confidence channel.
- **Failure modes are content-categorical, not on a continuous difficulty axis**: Goldfarb's failure clusters (cages, glare, camouflage, shadows) are interpretable input-content categories, not points on a "harder vs easier" line. Tension with H-9 (breathing amplitude predicts difficulty), which assumes a continuous difficulty signal.
- **Mapper-as-explainability for black-box failures**: reframes "why did the network get this wrong" as "which topological neighborhood does this input live in". Could be applied to MATH-500 incorrect problems to surface categorical failure modes that the K=1/K=8 bucket scheme flattens.

## 1811.00852 — Understanding Deep Neural Networks Using Topological Data Analysis (Goldfarb, 2018)

**Relevance:** Short workshop-style report from an AFRL Summer-of-TDA internship. Applies the Mapper algorithm (Singh-Memoli-Carlsson 2007) to VGG16 activations on a 5,000-image cat/dog ImageNet subset, demonstrating that Mapper-on-activations yields correctness-imbalanced topological clusters that can be inspected to surface interpretable failure modes (cages, glare, camouflage, shadows). Methodologically foundational for TDA-on-NN-activations, but uses Mapper not persistent homology — orthogonal to F-10's PH null. The paper's central proposal — train per-cluster auxiliary learners gated by Mapper topology — is the direct prior art for our H-19 verification-routing frame.

**Key claim we tested:** Mapper-on-activations surfaces categorical failure-mode clusters that supervised correctness probes would miss; cluster membership can serve as an unsupervised correctness prior.

**Related experiments:** P11-FE82, P11-FE83, P11-FE84, H-72, H-73, H-74
