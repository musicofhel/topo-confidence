# Triage brief — 2604.19974 — Are LLM Uncertainty and Correctness Encoded by the Same Features? A Functional Dissociation via Sparse Autoencoders

Source: https://arxiv.org/abs/2604.19974
Triaged: 2026-04-29

Paper: Patel, Chen, Wei, Papalexakis, Chen (2026). Llama-3.1-8B and Gemma-2-9B; GemmaScope-family SAEs; ARC-Challenge, RACE, MMLU (multiple-choice). Three feature populations: (1) pure-uncertainty — functionally essential, (2) pure-incorrectness — statistically distinguishing but **functionally inert** under suppression, (3) confounded — encode both, suppression yields +1.1% accuracy, 75% entropy reduction, transfers across benchmarks. Headline downstream: 3 confounded features from a single mid-layer give selective-abstention AUROC ≈ 0.79, lifting accuracy 62 → 81 % at 53 % coverage.

## Refutations

1. **F-2 mechanistic reframing — "DoM is a correctness predictor" may collapse into "DoM is a confounded uncertainty feature."** F-2 reports prefill L19 DoM AUROC = 0.7731 and frames it as a correctness signal. Patel et al. show that *pure-incorrectness* features are functionally inert; the only features that lift selective accuracy are *confounded* (uncertainty + correctness) features. **Mechanism:** train an SAE on Qwen-2.5-1.5B L19 prefill activations (or use a transferred basis), project the cached F-2 DoM into the SAE basis, and measure the cosine to (a) entropy-correlated features vs (b) features that distinguish correct/incorrect but have flat entropy. **Falsifiable:** if DoM is dominantly parallel to entropy-correlated features and ≪ parallel to flat-entropy distinguishing features, F-2's "correctness predictor" framing is downgraded to "confounded uncertainty signal" — and the project's narrative needs re-grounding away from "geometry of correctness" toward "geometry of confidence." (P10-FE5 already exists for this projection but does not include the entropy-vs-flat decomposition.)

2. **H-12 refuted — semantic-entropy probes cannot replace supervised DoM if pure-correctness signal is non-residual.** H-12 conjectures that a label-free SEP can stand in for supervised DoM. Patel et al. find that "pure-incorrectness features are functionally inert" — so a probe that picks up only the entropy/uncertainty subspace (which SEPs do, by construction) will recover the *uncertainty* component but miss any *correctness-specific* component. **Mechanism:** SEPs are trained against semantic entropy clusters, which is exactly the uncertainty axis Patel et al. argue is dissociable from correctness. **Falsifiable:** train an SEP on Qwen-2.5-1.5B / MATH-500 hidden states, evaluate AUROC vs F-2's 0.7731. If SEP AUROC ≪ 0.7731, H-12 is refuted — label-free entropy probes systematically miss whatever non-uncertainty correctness signal supervised DoM is using.

3. **F-3 mechanism reframing — prefill/final-token DoM orthogonality (cos 0.046) may *be* the uncertainty/correctness dissociation.** F-3 currently reads the orthogonality as "two independent computations." Patel's 2×2 implies a different read: prefill DoM may be the uncertainty axis and final-token DoM the correctness axis (or vice versa). The 0.046 cosine then has a *mechanistic* explanation rather than being a coincidence. **Mechanism:** project each DoM into the SAE basis. If prefill loads on confounded/pure-uncertainty features and final loads on pure-incorrectness or different confounded features, the orthogonality is *predicted*, not surprising. **Falsifiable:** if both DoMs project onto overlapping feature subsets despite cos = 0.046 (i.e., they are projections of the same multi-feature subspace into different bases), F-3's "independent computations" interpretation is refuted; if they cleanly partition the SAE feature space into uncertainty vs correctness subsets, F-3 is reframed.

4. **F-8 selective-prediction provenance challenge — DoM-based selection at 50 % coverage may be ≈ MaxProb selection.** F-8: selective accuracy 71.6 % at 50 % coverage on Qwen-2.5-1.5B / MATH-500. Patel: 62 → 81 % at 53 % coverage from 3 confounded features (which by their own analysis are partly uncertainty). If our F-8 lift is dominated by the uncertainty-correlated component of DoM, then a token-entropy / MaxProb / semantic-entropy filter at the same coverage should reproduce most of the lift. **Mechanism:** at matched coverage, compare {DoM-selected, MaxProb-selected, SEP-selected} accuracies on MATH-500. **Falsifiable:** if MaxProb at 50 % coverage gets ≥ 70 % on the same answered set, F-8's "DoM is doing meaningful work beyond confidence filtering" claim is refuted, and Patel's finding becomes a direct explanation.

- **F-2 (Prefill L19 DoM AUROC 0.7731, OOF 5-fold).** Patel's 3-feature SAE probe AUROC ≈ 0.79 from a single mid-layer is in the same range, suggesting the correctness-predictive substrate may be similarly low-rank in both setups. Their "confounded features" framing offers the most plausible candidate explanation for what F-2's DoM actually is.
- **F-3 (cos(prefill_DoM, final_DoM) = 0.046).** If prefill = uncertainty axis and final = correctness axis, F-3's surprising orthogonality is *predicted* by Patel's dissociation rather than being a free-standing finding.
- **F-8 (Selective-prediction acc 71.6 % at 50 % coverage).** Direct numerical comparator: Patel's 62 → 81 % at 53 % coverage. Different model + multiple-choice (not CoT/MATH), so apples-to-oranges, but suggests the +X-point lift from confidence-aware selection is broadly replicable.
- **H-1 (Per-position DoM steering).** Patel's "suppression of confounded features = +1.1 % accuracy" is a concrete steering result on a static feature basis. If H-1's per-position bank is essentially per-position confounded-feature suppression, the two converge mechanistically.
- **H-12 (Label-free SEP replaces DoM).** Direct refutation candidate (see Refutation 2).
- **H-13 (Head-level attribution of prefill vs final-token circuits).** Patel's feature-population partition is the SAE-feature analogue of H-13's circuit-level attribution; complementary, not competing.

## Methodologies extracted

- **2×2 contingency partition over (correctness × model-self-confidence)** — partition predictions into TP/FP/TN/FN-style cells before fitting any feature analysis. *Replication cost*: 30 min CPU on cached MATH-500 completions (need per-problem MaxProb / mean-token-prob already computed). *We'd plausibly run this*: yes — it costs almost nothing and would let us re-bin our 243 correct / 257 incorrect 1.5B problems by within-bucket confidence.
- **Functional ablation as ground truth (vs statistical activation difference).** Suppress a feature in the residual stream and re-measure downstream accuracy/entropy; statistical separation alone (the kind correlation-based probes report) does not imply functional role. *Replication cost*: 1–2 H100 days for SAE training + per-feature ablation on MATH-500 generation. *We'd plausibly run this*: yes — directly tests whether F-2's DoM is causal or correlational. This is the most important methodology to import.
- **GemmaScope SAE as feature basis.** Pretrained SAE library across all Gemma layers, lets you skip SAE training. *Replication cost*: download (~hours), inference cost only. *We'd plausibly run this*: partially — GemmaScope only covers Gemma; for Qwen we'd need either Qwen-Scope (if released) or to train our own L19 SAE on Qwen-2.5-1.5B (≈ H100 day).
- **Suppression-driven selective abstention from k features.** Use the k features whose suppression damages accuracy most as the abstention signal (rather than raw activations). *Replication cost*: small once SAE trained. *We'd plausibly run this*: yes — direct alternative selection rule for F-8.
- **Cross-benchmark transfer of feature suppression.** Suppress the feature on dataset A, evaluate on dataset B. *Replication cost*: trivial post-hoc. *We'd plausibly run this*: yes if we run cross-task DoM (already partially in P5).

## Approaches & framings

- **Statistical separation ≠ functional role.** Many features distinguish correct from incorrect (≥ p<0.01) but suppressing them does nothing. This is a sharp methodological warning for the entire P5 / P6 / P10 program: every "this direction differs between buckets" claim should ideally be back-checked with an ablation experiment. Intersects F-2 and F-7 most directly.
- **Multi-axis decomposition of the "correctness signal."** Where our project has been treating correctness-prediction as scalar (one direction, one AUROC), Patel et al. partition it into uncertainty + correctness + confound axes. F-3's orthogonality is suspiciously consistent with this partition and may have been over-interpreted.
- **Inert separators are a type signature of confounder pickup.** A "pure-incorrectness" feature that fails to change accuracy under suppression is the hallmark of a feature that's downstream of correctness rather than upstream — a frame our F-7 ("D-bucket geometric signature") should be tested against.

Cost: 30 min CPU. High correlation → F-2 signal is heavily uncertainty-coupled → directly evidences refutation 1 even before SAE training.

If DoM disappears in one cell and concentrates in the other, the 2×2 is structuring the F-2 signal.
- **Project F-2 DoM into Qwen Scope SAE basis (if a public Qwen-2.5-1.5B SAE exists).** Cost: hours if SAE downloadable; otherwise SAE training is 1 H100 day → out of scope for "right now."
