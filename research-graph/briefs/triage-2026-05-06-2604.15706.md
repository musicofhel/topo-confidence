# Triage brief — 2604.15706 — Target-Oriented Pretraining Data Selection via Neuron-Activated Graph

Source: https://arxiv.org/abs/2604.15706
Triaged: 2026-05-06

## Refutations

1. **F-2 (single L19 direction predicts correctness at AUROC 0.7731) — multi-layer sparse neuron features could dominate single-layer DoM.**
   NAG demonstrates that task-relevant signals are distributed across all layers: restricting NAG to the final layer loses 4.1% average accuracy. If NAG-style sparse neuron-activation features (top-K activated FFN UP neurons per layer) were extracted across all 28 Qwen-2.5-1.5B layers for MATH-500 and used to predict correctness, and that multi-layer NAG feature vector yielded AUROC > 0.7731, it would show that F-2's L19 prefill direction is leaving distributed signal on the table. The single-layer finding would not be wrong, but its framing as *the* correctness predictor would be incomplete. **Falsifiable:** extract 28-layer NAG features from cached forward passes, train logistic probe on correct/incorrect, compare AUROC to 0.7731.

2. **F-9 (CoE-60 trajectory features redundant with single-layer L19 DoM) — NAG's multi-layer aggregation method may expose signal that CoE-60's mean-pooling missed.**
   F-9 concluded that CoE-60 trajectory features don't add AUROC over L19 DoM. But CoE-60 aggregates via mean pooling across token positions within each layer, which could wash out sparse, high-impact neuron signals. NAG instead identifies the *sparse* subset of neurons (~0.3% per layer) that carry task-discriminative signal. If NAG-style sparse neuron features across 60 layers beat L19 DoM (0.7731) for correctness prediction, it would refute F-9's claim that trajectory features are redundant — the redundancy was an artifact of the aggregation method, not the multi-layer information itself. **Falsifiable:** compute NAG features (top-K neuron indices per layer across 28 layers) from cached activations, compare correctness-prediction AUROC against F-2's 0.7731 and F-9's CoE-60 features.

3. **H-64 (prefill DoM signal concentrated in ≤10 attention heads) — NAG's FFN-UP neurons may carry most of the correctness signal outside attention heads entirely.**
   NAG shows that the UP projection neurons (not attention) are most effective for task-discriminative signals, outperforming K-proj, V-proj, and DOWN-proj neurons. Their deactivation experiment demonstrates 23.5% collapse from deactivating 0.12% of FFN UP neurons. If the MATH-500 correctness signal at L19 is primarily carried by FFN UP neurons rather than attention heads, H-64's framing of a sparse *attention-head* circuit would be misspecified — the critical circuit may be in the FFN pathway. **Falsifiable:** compare neuron-importance ranking of L19 FFN UP columns (NAG-style) against attention-head attribution for correctness prediction; measure which decomposition captures more of the 0.7731 AUROC.

## Direct connections to F-N / H-N

- **F-2 (L19 prefill DoM AUROC 0.7731):** NAG's neuron-impact metric (column-wise activation magnitude in projection layers) is a different decomposition of the same residual-stream activations that produce DoM. NAG decomposes the activation into neuron-level contributions, while DoM projects onto a single direction. The 0.7731 ceiling might be lifted by using NAG's sparse neuron-importance decomposition as features for the correctness probe.

- **F-9 (CoE-60 redundant with L19 DoM):** NAG's key finding that all-layer aggregation beats final-layer-only by 4.1% directly challenges the claim that multi-layer trajectory features are redundant. The mechanism matters: NAG uses sparse top-K selection per layer, not mean pooling. This suggests the CoE-60 redundancy finding may be method-specific rather than reflecting a fundamental information-theoretic redundancy.

- **F-10 (PH null on residual streams):** NAG constructs a graph from neuron-activation patterns that captures task-discriminative structure invisible to Euclidean distance metrics. This is a different representation space — neuron-index overlap (Dice similarity) rather than Euclidean distance in R^1536. The PH-null result at F-10 was tested in Euclidean residual-stream coordinates; NAG's discrete graph structure operates in a combinatorial space where PH was never tested.

- **H-13 (head-level attribution of prefill vs final-token circuits):** NAG provides a complementary attribution method — instead of attention heads, it identifies which FFN UP neurons are critical. Combining head-level and neuron-level attribution could give a more complete mechanistic picture of the circuits underlying F-2 and F-3.

- **H-64 (sparse attention-head circuit for DoM):** NAG's finding that 0.12% of neurons cause 23.5% collapse is directly analogous to H-64's question about whether ≤10 attention heads carry ≥80% of AUROC. NAG offers the FFN-side complement to H-64's attention-side question.

- **H-67 (DoM is task-recognition probe, not per-problem correctness probe):** NAG's t-SNE visualization shows that neuron activation patterns cluster by task type (MathQA and GSM8K cluster together, separate from XNLI). If DoM's L19 direction aligns with NAG's task-discriminative neurons, it would support H-67's task-recognition interpretation.

## Methodologies extracted

- **Neuron impact scoring (column-wise activation magnitude)** — For a projection weight matrix W, neuron importance = ||h_in^T W_{:,k}|| for each column k. Computed per-input during a single forward pass, no gradients needed.
  *Replication cost*: 20min CPU on cached activations (just need to decompose existing L19 hidden states into FFN sub-layer contributions).
  *We'd plausibly run this*: yes — directly applicable to cached Qwen-2.5-1.5B L19 activations if we also cache the FFN weight matrices.

- **Neuron-Activated Graph (NAG) construction** — Select top-K neurons per layer by impact score, represent each input as a set of (layer, neuron-index) pairs. Similarity = Dice coefficient over these sets.
  *Replication cost*: 30min CPU for 500 samples × 28 layers if weight matrices are cached; 2h H100 if forward passes needed.
  *We'd plausibly run this*: yes for a single-layer version on L19 (CPU); uncertain for all-28-layers (needs fresh forward passes to get per-layer neuron activations).

- **Sparse neuron deactivation** — Zero out top-K neuron columns and measure performance collapse. Identifies functional backbone.
  *Replication cost*: 2h H100 (need fresh forward passes with modified weights).
  *We'd plausibly run this*: no — primarily a pretraining data selection tool; the deactivation experiment is interesting mechanistically but not directly applicable to our correctness-prediction pipeline without fresh inference.

- **High-Δ neuron selection** — Select neurons with largest difference in mean impact between target and random inputs. Only 0.006% of neurons (25 total) cause 17.8% collapse.
  *Replication cost*: 30min CPU if activations for correct vs incorrect groups are cached.
  *We'd plausibly run this*: yes — compute High-Δ neurons between correct and incorrect MATH-500 groups, test whether these sparse neurons carry correctness signal.

## Approaches & framings

- **Sparse functional backbone:** The idea that a tiny fraction (0.12%) of neurons constitutes a "functional backbone" for each capability. Intersects H-64's question about whether the DoM signal is carried by a similarly sparse subset of the L19 circuit.

- **Neuron-level task alignment vs embedding-level task alignment:** NAG outperforms BETR (embedding similarity) because it captures neuron-level computation patterns distributed across layers, not just final-layer semantic representations. This reframes F-9's CoE-60 redundancy finding: the issue may not be that multi-layer information is redundant, but that embedding-level (or mean-pooled) aggregation loses the sparse neuron-level signal that matters.

- **Expansion-layer selectivity:** FFN UP projection neurons (in the higher-dimensional latent space) are more task-discriminative than DOWN projection or attention K/V neurons. This suggests that if we're looking for correctness-discriminative features, the FFN intermediate activations (d_internal = 5440 in Qwen) may be richer than the residual stream (d_model = 1536).

## Implementation details worth capturing

- NAG width ratio rk = 0.3% per layer is optimal across model scales (1.7B, 4B, 8B)
- For Qwen3-1.7B-Base: d_internal = 6144, K = 20 neurons per layer
- UP projection neurons outperform Q, K, V, DOWN for task-discriminative signal
- NAG extraction requires only a single forward pass per input (no gradients, no generation)
- Code released at https://github.com/asillycat/NAG
- Pearson correlation between local neuron-impact proxy and actual |Δloss| is +0.71±0.02
- NAG ranking stabilizes with as few as 200 target samples (Spearman ρ ≥ 0.999)
