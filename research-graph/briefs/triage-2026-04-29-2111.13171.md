# Triage brief — 2111.13171 — Intrinsic Dimension, Persistent Homology and Generalization in Neural Networks

Source: https://arxiv.org/abs/2111.13171
Triaged: 2026-04-29

## Refutations

### Refutation 1 — F-10 nullity may be an estimator-choice artifact, not a structural absence

F-10 says persistent homology on trained residual streams sits at the Gaussian
null. But Birdal's PHD is **not** a single PH fingerprint statistic — it is
a *scaling law* extracted from the regression of `log(sum of PH-0 bar
lifetimes)` against `log(subsample size n)`. Our pathway 7/8 PH probes used
bottleneck distances, persistence landscapes, or top-K features — all
single-resolution. Birdal-style PHD is integral over the full PH-0 bar code
*and* across multiple subsample sizes, which is a strictly different statistic.

- **Mechanism**: if trained-residual point clouds have weak fractal structure
  invisible to fixed-scale PH features, it would still show up as a non-trivial
  PHD slope ≠ 1/(1-0) under Birdal's regression.
- **Falsifiable**: re-run F-10 using Birdal's `calculate_ph_dim`
  (github.com/tolgabirdal/PHDimGeneralization) on cached pathway 8 layer-wise
  L19 NPZ residuals. Compare PHD against the known Gaussian-null reference
  (synthetic Gaussian point cloud of same shape). Cited at F-10 (PH = Gaussian
  null) — this is the cleanest refutation test for it.

### Refutation 2 — F-7's "collective not per-problem" signature could be a single PHD scalar

F-7 explicitly claims D-bucket has a **collective**, not per-problem, geometric
signature. Birdal's framework asserts that a single fractal-dimension scalar
(PHD) is in fact extractable from a single point cloud of as few as ~1000
points (their default sliding window). 1024-tok L19 activations per problem is
a 1024-point cloud — exactly the regime Birdal validated.

- **Mechanism**: per-problem PHD computed on the per-token L19 residual cloud
  may be the *missing scalar* that operationalises F-7. If D-bucket problems
  systematically have higher (or lower) PHD than A/B/C-bucket, F-7's
  "collective only" hedge collapses.
- **Falsifiable**: compute per-problem PHD over cached `prefill_gated_compute`
  Stage 2 NPZs at L19. Stratify by A/B/C/D bucket (defined in pathway 11). One
  shot: KS test between bucket PHD distributions.

### Refutation 3 — Label-free PHD-AUROC could match supervised DoM, refuting F-2/F-8 probe-necessity framing

F-2 (AUROC 0.7731 prefill L19 DoM) and F-8 (selective prediction at 71.6%
@cov=0.5) currently rely on a *supervised* logistic probe trained on
correct/incorrect labels. Birdal's PHD is an unsupervised scalar extracted from
geometry alone. If per-problem PHD on prefill L19 separates correct from
incorrect at AUROC ≥ 0.7, that's a label-free competitor with no probe
training and no held-out fold split.

- **Mechanism**: PHD regresses log-summed-PH-0-lifetimes against log-n; the
  slope captures fractal complexity of the activation cloud. Correct trajectories
  may have systematically lower (or higher) per-problem PHD than incorrect.
- **Falsifiable**: 30-min CPU run on cached prefill L19 NPZ. Direct comparison
  against the F-2 0.7731 anchor. If PHD-AUROC ≥ 0.7, F-2's supervised-probe
  framing is significantly weakened (and we get a label-free correctness signal
  for free).

### Refutation 4 — Object-level mismatch: Birdal's bound does NOT apply to per-input correctness

This is a *meta* refutation — anyone (including us) invoking 2111.13171 as
generic "topology helps with LLM correctness" is conflating two pipelines.
Birdal bounds the **generalization gap** (test loss − train loss) of a
trained-from-scratch network via PHD of its **SGD trajectory in parameter
space** (sliding window of 1000 weight snapshots). F-2/F-7/F-8/F-10 are about
**per-input activation geometry** at fixed (frozen, pretrained) weights.

- **Mechanism**: definitional. Birdal's PHD point cloud `W ∈ R^d` is
  `(W_t)_{t=1..1000}` where `d = #params`; ours is `(h_i)_{i=1..1024}` where
  `h_i ∈ R^{hidden}` is a per-token L19 activation.
- **Falsifiable**: not directly — but it falsifies any claim that 2111.13171's
  bound supports our work. Status implication: PAPER_INDEX should mark this
  paper as CITED ONLY with the explicit object-mismatch caveat, rather than
  REPLICATED or PARTIALLY CONFIRMED.

  hardens.

## Methodologies extracted

- **PHD scaling-law estimator (`calculate_ph_dim`)** — given point cloud `W`,
  log-uniformly subsample sizes `n_1, …, n_K`; for each `n_k` draw a random
  subset, run Vietoris-Rips on its pairwise distance matrix, take PH-0 only,
  sum bar lifetimes `E_k = Σ (death − birth)`; regress `log E_k ~ log n_k`,
  estimate slope `m`, output PHD = `1 / (1 − m)`. Defaults: `min_points=200`,
  `max_points=1000`. CPU via `ripser`; differentiable GPU via `TorchPH`.
  *Replication cost*: 20 min CPU on a 1024×1536 prefill cloud.
  *We'd plausibly run this*: **yes** — drop-in replacement for our
  PH-on-residuals probe at near-zero cost.

- **Sliding-window trajectory tracking** — maintain a deque of 1000 weight
  snapshots during SGD; re-estimate PHD per window for trajectory-level
  generalization monitoring.
  *Replication cost*: requires from-scratch training.
  *We'd plausibly run this*: **no** — we don't train models from scratch in
  this program; doesn't apply to frozen-Qwen pipeline.

- **Differentiable PHD regularizer** — TorchPH backend allows PHD as an
  end-to-end training loss term, regularizing toward lower fractal dimension.
  *Replication cost*: requires training run with PHD loss.
  *We'd plausibly run this*: **no** — same reason as above.

## Approaches & framings

- **Generalization as a property of the SGD trajectory, not final weights** —
  connects to our breathing framing: both treat the *dynamic* (training
  trajectory or per-token activation trajectory) as the carrier of meaningful
  geometry, rather than a static snapshot. This is consonant with H-4
  (breathing ↔ EoS) and the chain-of-embedding (CoE) family.
- **Multi-scale PH as a fractal-dimension estimator** — reusable framing for
  P7/P8 work: instead of single-scale PH features, treat sum-of-PH-0-lifetimes
  vs subsample-size as a signal. This is what F-10's nullity test missed.
- **Object-level care about *what* the point cloud is** — Birdal is explicit
  that PHD bounds generalization only when the point cloud is the SGD
  trajectory. Useful framing for our PAPER_INDEX hygiene: every PH-on-
  neural-net paper should be classified by what point cloud it operates on
  (params vs activations vs attention).

## Implementation details worth capturing

- Code: `https://github.com/tolgabirdal/PHDimGeneralization` (MIT, 4 commits).
- `topology.py:calculate_ph_dim(W, min_points=200, max_points=1000, h_dim=0)` —
  drop-in CPU function; depends on `ripser`. Output: scalar PHD.
- `calculate_ph_dim_gpu` requires `TorchPH` (https://github.com/c-hofer/torchph)
  if differentiability needed; not needed for our probe-only application.
- Default subsample-size schedule is 7 log-spaced points between 200 and 1000.
- The estimator is invariant to ambient embedding dimension *as long as the
  intrinsic dimension is far smaller* — important for L19 residuals (1536-dim
  ambient, expected ID much smaller).
- Architecture choices in original paper (FCN/AlexNet/VGG) are irrelevant to
  us; only `topology.py` is reusable.

## Proposed PAPER_INDEX.md classification

## 2111.13171 — Intrinsic Dimension, Persistent Homology and Generalization in Neural Networks (Birdal, Lou, Guibas, Şimşekli, 2021)

**Relevance:** NeurIPS 2021 paper that introduces "persistent homology
dimension" (PHD) as an unsupervised scalar fractal-dimension estimator and
proves a generalization bound in terms of PHD applied to the **SGD trajectory
in parameter space** (1000-step sliding window of weight snapshots). The bound
itself does NOT apply to our setting (frozen-weights, per-input activation
geometry) — Birdal's point cloud is `(W_t)_{t=1..1000} ∈ R^{#params}`, ours is
`(h_i)_{i=1..1024} ∈ R^{1536}`. However, the **PHD estimator algorithm**
(`calculate_ph_dim`: log-regression of PH-0 sum-of-bar-lifetimes against
subsample size) is fully reusable as a different-statistic re-test of F-10
nullity and as a label-free correctness probe candidate against F-2/F-8.

**Key claim we tested:** That PHD-via-log-regression is a more sensitive
fractal-dimension estimator than fixed-scale PH fingerprints, and that PHD
applied to a sufficiently large point cloud (~1000 points) is informative
about that cloud's geometry.

**Our result:** **TO TEST.** Birdal's algorithm has not yet been run against
our cached residual-stream point clouds. The natural tests are P7-FE51 (re-run
F-10 with `calculate_ph_dim`) and P11-FE71 (per-problem PHD-AUROC against K=1
correctness). The Birdal bound itself is object-mismatched and CITED ONLY for
the bound; the algorithm is TO TEST.

**Related experiments:** P7-FE51, P11-FE71, P11-FE72; H-93, H-94, H-95.

**Status:** TO TEST (algorithm portion); CITED ONLY (bound — object mismatch).
