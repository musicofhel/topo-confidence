# Triage brief — 2606.07502 — Your UnEmbedding Matrix is Secretly a Feature Lens for Text Embeddings

Source: https://arxiv.org/abs/2606.07502
Triaged: 2026-06-10

Authors: Songhao Wu, Zhongxin Chen, Yuxuan Liu, Heng Cui, Cong Li, Rui Yan (Renmin Univ. / Lenovo / Wuhan Univ.), 2026.

**One-line:** LLM text embeddings are dominated by an anisotropic "average-token" direction; the unembedding matrix `W_U = U Σ Vᵀ` has an "edge spectrum" (right singular vectors with the **largest *and* smallest** singular values) that encodes high-frequency/non-semantic tokens. Removing it — keep only the mid-range "bulk spectrum" via `Φ_τ = V[l:r] V[l:r]ᵀ`, `ẽ = e Φ_τᵀ` — improves zero-shot embeddings up to +14.1% on MTEB and gives free, distance-preserving dimensionality reduction to `d/τ`. Backbones: Qwen-2.5-0.5B, Llama-3.1-8B, Mistral-7B.

## Refutations

The paper's central deflationary claim — *the dominant, highest-energy directions of LLM hidden states are a frequency/anisotropy artifact, not semantics* — is a direct adversary to several of our "the top direction predicts correctness" findings. **Crucially, this is a Qwen-2.5 paper and we run Qwen-2.5-1.5B, so its `W_U`-SVD machinery transfers to our cached activations with no forward passes.**

1. **Refutes F-2 (single L19 DoM ≈ PC1 predicts correctness, AUROC 0.7731; cos(DoM,PC1)=0.9216).**
   *Mechanism:* The paper says the top covariance/singular direction of LLM representations is the "average token" anisotropy axis — `h_avg = log(p̂) W_U⁺` — which is **content-independent** (their Logit-Lens word-clouds are identical regardless of input). If our DoM (which is ≈PC1, the top covariance eigenvector) is largely aligned with `h_avg`, then F-2's "correctness direction" is partly a frequency/anisotropy confound, not a learned correctness computation. A correctness signal that is mostly the anisotropy axis would be deflationary.
   *Falsifiable:* Compute `h_avg` for Qwen-2.5-1.5B from `W_U` + RedPajama token frequencies; measure `cos(DoM, h_avg)` and `cos(PC1, h_avg)`. If |cos| ≳ 0.5, F-2's signal is confounded with the average-token axis.

2. **Refutes H-892 (correctness signal is dominated by "stiff-mode" / high-eigenvalue PCs) and the cov-spectrum probe headline (top-20 log-eigvals → AUROC 0.7928, FE881).**
   *Mechanism:* Our cov-spectrum probe explicitly uses the **largest** eigenmodes (top-20). The paper's Δπ analysis finds the **largest** singular subspaces (one half of the "edge spectrum") are precisely what writes high-frequency non-semantic tokens. If the edge spectrum overlaps our top-eigvalue subspace, then projecting cached L19 activations onto the **bulk spectrum** (removing the edge) should *destroy* the 0.7928 cov-spectrum AUROC — meaning the lift over DoM lives in a frequency-noise subspace, not a semantic one.
   *Falsifiable:* Apply `Φ_τ` (drop top-k and bottom-k singular directions of `W_U`) to cached L19 prefill activations; recompute the top-20 log-eigval probe AUROC. A large drop refutes H-892's "stiff-mode = correctness" reading.

3. **Refutes/recasts F-3 (prefill vs final-token DoM orthogonal, cos = 0.046).**
   *Mechanism:* If both prefill and final-token representations carry a large shared `h_avg` anisotropy component, raw cosine between *uncentered* group-mean differences could be artificially suppressed or inflated by that shared axis. The paper's claim that all embeddings collapse toward one common region predicts a dominant shared component that mean-subtraction in our DoM may not fully remove if it lives off the class-mean axis.
   *Falsifiable:* Recompute `cos(prefill_DoM, final_DoM)` after applying EmbedFilter (`Φ_τ`) to both prefill and final cached activations. If the 0.046 moves materially (e.g. >0.2 or <−0.1), the orthogonality is partly an anisotropy artifact, weakening F-3's "structural orthogonality" claim.

4. **Refutes F-8 (selective prediction at 50% coverage → 71.6% answered acc) as anisotropy-limited.**
   *Mechanism:* If the DoM score is partly the frequency-anisotropy axis, then the selective-prediction ranking inherits a length/frequency bias. EmbedFilter-refined activations should, on the paper's logic, give a *cleaner* (or at least different) score that re-orders abstentions.
   *Falsifiable:* Re-derive the selective-prediction curve from EmbedFilter-refined L19 activations; compare answered-accuracy at coverage 0.5. A material change implies F-8's confidence ordering is entangled with anisotropy.

## Methodologies extracted

- **EmbedFilter / Bulk Spectrum Transformation** — SVD the unembedding matrix `W_U = UΣVᵀ`; keep only mid-range right singular columns `Φ_τ = V[l_τ:r_τ] V[l_τ:r_τ]ᵀ`; post-process embeddings `ẽ = e Φ_τᵀ`. Training-free, weight-only.
  *Replication cost*: ~15min CPU (one SVD of a 1536×151k matrix → V is 1536×1536; then matmuls on cached 500×1536).
  *We'd plausibly run this*: **yes** — directly applies to cached L19 activations; tests Refutations 1–4.
- **Reverse-engineered "average token"** — `h_avg = log(p̂) W_U⁺` (Moore–Penrose pseudo-inverse), with `p̂` = empirical token frequencies from a corpus. Gives an explicit anisotropy/frequency direction in hidden-state space.
  *Replication cost*: ~10min CPU (pinv of `W_U`; token-freq histogram from any corpus, or uniform as a control).
  *We'd plausibly run this*: **yes** — `cos(DoM, h_avg)` is the cheapest decisive test of the confound.
- **Logit Spectroscopy (Δπ per singular direction)** — for each right singular vector `i`, filter `Ψ_i = I − V[i]V[i]ᵀ`, measure cumulative logit shift `Δπ⁽ⁱ⁾` on the top-k frequent tokens; identifies which spectral subspaces write frequent tokens.
  *Replication cost*: ~20min CPU (1536 single-vector filters × logit recompute over top-100 tokens).
  *We'd plausibly run this*: **yes-ish** — gives the per-eigenmode frequency map we'd overlay on our correctness-eigenmode ranking (H-892 test).
- **Logit Lens on embeddings** — project a hidden state to vocab via `W_U` and read top tokens; diagnostic for anisotropy.
  *Replication cost*: ~5min CPU.
  *We'd plausibly run this*: maybe — useful as a qualitative sanity check on what the DoM axis "decodes to."

## Approaches & framings

- **The unembedding matrix as a "feature lens" for hidden states.** Reframes the readout weights `W_U` as an analysis instrument over the residual stream — its singular basis partitions hidden-state directions into semantic ("bulk") vs frequency-writing ("edge"). Intersects our entire program: we have always analyzed L19 geometry in the *raw activation* basis (PCA/covariance); this offers a *weight-derived, content-independent* basis to factor the DoM/PC1 direction against.
- **"Edge spectrum" (both extremes) = non-semantic.** A specific, falsifiable claim that BOTH the largest and smallest singular subspaces are non-semantic — counter to our implicit assumption that the largest covariance modes carry the most correctness signal (H-892). Sharpens the stiff-mode debate.
- **Anisotropy as a removable, distance-preserving nuisance.** Casts the dominant shared direction as a transformation we can subtract while *preserving* pairwise distances (orthogonal `V` columns) — directly relevant to whether F-3's orthogonality and F-1's breathing are anisotropy artifacts.

## Implementation details worth capturing

- Code: https://github.com/CentreChen/EmbFilter (training-free post-processing).
- `Φ_τ` drops the top-k AND bottom-k singular columns; `τ` is a filtering ratio that also sets output dim = `d/τ` (they report τ ∈ {2,4,8}).
- Because `V` columns are orthonormal, `ẽ = e Φ_τᵀ` is distance-preserving, so you can replace `Φ_τᵀ` with just `V[l_τ:r_τ]` (the kept columns) to *reduce* dimensionality with no similarity change (their Eq. 1).
- `h_avg = log(p̂) W_U⁺`; a shared additive bias term `b` across logits is dropped as it doesn't change spectral properties.
- Δπ uses top-k=100 frequent tokens; frequency peaks at spectral extremes (Fig. 2), flat for random/infrequent tokens (Fig. 4).
- **Gotcha for us:** Qwen-2.5-1.5B uses tied embeddings (`tie_word_embeddings=True`), so `W_U` = the input embedding matrix (transposed) — a single downloadable tensor; no GPU needed for the SVD. We may not have this tensor cached locally yet (≈0.46 GB), so the FEs below carry a one-time weight-download dependency.

## Replicable intermediates

- **cos(DoM, h_avg) cross-check** — load Qwen-2.5-1.5B `W_U` (= tied embedding matrix), compute `W_U⁺`, build `h_avg` (uniform-freq control needs no corpus), and compute `cos(h_avg, DoM)` / `cos(h_avg, PC1)` against the cached DoM/PC1 vectors used in FE291. Smallest decisive test of Refutation 1. CPU, ~10min.
- **Bulk-spectrum DoM AUROC** — SVD `W_U`, project cached L19 prefill activations (`pathway11_h100/...` 500×1536) through `Φ_τ`, recompute the 5-fold OOF DoM AUROC and the top-20 cov-spectrum AUROC; compare to 0.7731 / 0.7928. Tests Refutations 1–2. CPU, ~20min.
- **Orthogonality recompute** — apply `Φ_τ` to both prefill and final cached activations, recompute `cos(prefill_DoM, final_DoM)` vs the 0.046 baseline. Tests Refutation 3. CPU, ~10min.
