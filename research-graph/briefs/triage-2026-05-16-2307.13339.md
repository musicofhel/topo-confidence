# Triage brief — 2307.13339 — Analyzing Chain-of-Thought Prompting in Large Language Models via Gradient-based Feature Attributions

Source: https://arxiv.org/abs/2307.13339
Triaged: 2026-05-16

## Refutations

**R1 — Against F-5 (Breathing is content-dependent, not AR-mechanics):**
The paper's central finding is that CoT prompting *decreases* saliency scores on content-relevant tokens across all datasets and attribution methods (Figure 1). Their "dilution" hypothesis attributes this to a mechanical effect: longer CoT prompts spread gradient mass over more tokens regardless of semantic relevance. If the dominant effect of CoT on internal representations is mechanical (sequence-length-driven gradient dilution) rather than content-driven redistribution, this would challenge F-5's claim that dimensional breathing is content-dependent. The refutation fires if we observe that our L19 DoM signal changes systematically with prompt length when content is held constant — i.e., padding a prompt changes breathing but rewriting the math problem at fixed length does not.
*Falsifiable experiment:* Compare L19 prefill DoM vectors on MATH-500 problems with standard vs. zero-padded prompts at matched content. If DoM shifts correlate with length more than content perturbation, F-5 is weakened.

**R2 — Against F-2 (L19 prefill DoM predicts correctness at AUROC 0.7731) / F-8 (selective-prediction via prefill DoM):**
The paper shows that switching between standard and CoT prompting dramatically reshapes gradient-based internal signals (lower saliency magnitudes, different variance profiles) *even when accuracy is unchanged* (GPT-J on GSM8K, CoinFlip, CSQA). This demonstrates that internal representation geometry can be format-dependent rather than stable-correctness-encoding. If our DoM direction is similarly prompt-format-dependent, the AUROC 0.7731 may not generalize across prompting strategies. The refutation fires if extracting L19 prefill activations under a CoT vs. direct-answer prompt format on the same problems yields a substantially different DoM direction (e.g., cos < 0.5).
*Falsifiable experiment:* Extract L19 prefill activations for the same 500 MATH-500 problems under standard vs. CoT few-shot prompts, fit DoM separately, compare directions and AUROC.

**R3 — Against H-2 (Breathing happens on short CoT reasoning):**
At 6B scale (comparable to our 1.5B regime), CoT changes internal gradient structure without improving accuracy (Section 4.1: GPT-J accuracy unchanged on GSM8K, CoinFlip, CSQA under CoT). This means CoT-induced changes to internal representations can be "empty" — format artifacts rather than reasoning improvements. If H-2 predicts that breathing patterns during CoT reflect genuine reasoning activity, this paper's finding that CoT reshapes internals even when reasoning quality doesn't change is a confound. The refutation fires if breathing patterns measured during CoT generation correlate with CoT prompt format rather than answer correctness.
*Falsifiable experiment:* On problems where CoT doesn't change the answer (correct→correct or wrong→wrong), check whether breathing pattern still shifts — if yes, breathing is format-driven, not reasoning-driven.

## Direct connections to F-N / H-N

- **F-2 (AUROC 0.7731):** The paper's demonstration that prompt format reshapes gradient geometry at 6B scale raises the question of whether our prefill DoM signal (extracted under a specific prompt format) is format-invariant. Our AUROC 0.7731 is measured under a single prompt template; this paper motivates testing format robustness. Connection is indirect — they measure gradient saliency, we measure activation geometry — but the underlying concern (format-dependent internal signals) is shared.

- **F-5 (content-dependent breathing):** The "dilution" finding — that CoT spreads gradient mass mechanically across more tokens without increasing focus on relevant tokens — is a partial counterpoint to content-dependence claims. If the model's internal attention shifts are mechanical (length-driven) at ≤6B scale, content-dependence of breathing (F-5) requires a demonstration that it persists after controlling for sequence length.

- **H-2 (breathing on short CoT):** Directly relevant. The paper shows CoT changes internal signal patterns even at scales where it doesn't improve accuracy. Any future test of H-2 needs to control for the possibility that observed breathing during CoT is a prompt-format artifact rather than a reasoning signature.

- **F-8 (selective-prediction at 50% coverage, 71.6% acc):** If the DoM direction is prompt-format-sensitive (per R2), selective prediction reliability depends on deployment using the exact training prompt format. The paper's robustness finding (CoT makes saliency more stable to rewordings) suggests that CoT-format extraction might actually *improve* our predictor's robustness — a possible upside if format-sensitivity is confirmed.

## Methodologies extracted

- **Gradient × Input saliency scoring** — Compute per-token saliency as the element-wise product of input embedding and gradient of output logit w.r.t. that embedding, then take L2 or L1 norm. Four variants tested: Grad×Input, L1 Norm, Contrastive Grad×Input, Contrastive L1 Norm.
  *Replication cost*: 30min–1hr GPU (requires gradient access, not just forward pass).
  *We'd plausibly run this*: no — our pipeline uses forward-pass activations only; gradient computation on Qwen-2.5-1.5B requires different infrastructure and doesn't directly connect to the residual-stream geometry we study.

- **Contrastive saliency** — Saliency computed not w.r.t. the predicted token's logit but w.r.t. the difference between predicted and runner-up token logits. Isolates what makes the model choose one answer over another.
  *Replication cost*: same as above (gradient access required).
  *We'd plausibly run this*: no — same infrastructure barrier.

- **Reworded-question stability test** — Manually rewrite questions with changed sentence structure but preserved meaning; compare saliency distributions across original and reworded versions to measure robustness.
  *Replication cost*: 2–4hr manual rewriting + 30min compute.
  *We'd plausibly run this*: yes (adapted) — the *experimental design* of testing signal stability under paraphrase is directly applicable to our DoM predictor. We could reword MATH-500 problems and check whether prefill L19 DoM predictions are robust. This doesn't need gradients.

## Approaches & framings

- **Saliency as mechanistic interpretability for prompting strategies:** The paper frames gradient-based attribution as a way to understand *why* a prompting strategy works, distinct from evaluating the quality of the model's generated reasoning. This "look at the gradients, not the explanations" framing could apply to our work: rather than asking whether breathing *correlates with* correctness, we could ask what gradient-level signals differentiate correct from incorrect prefill representations.

- **"Dilution" as mechanical explanation for CoT's internal effects:** CoT doesn't focus the model more — it spreads attention thinner over more tokens. This frames internal-signal changes under CoT as mechanical consequences of prompt length, not deeper reasoning changes. Relevant to interpreting any future CoT experiments in our pipeline.
