# Triage brief — 2306.03341 — Inference-Time Intervention: Eliciting Truthful Answers from a Language Model

Source: https://arxiv.org/abs/2306.03341
Triaged: 2026-04-29

Authors: Kenneth Li, Oam Patel, Fernanda Viégas, Hanspeter Pfister, Martin Wattenberg (Harvard) — NeurIPS 2023.

## Refutations

R1 — **Per-head, post-MHA probing may dominate residual-stream L19 DoM (refutes choice of probe target in F-2).**
ITI fits its probe on *post-MHA, pre-output-projection* head activations `x_l^h ∈ R^D` (D = d_model / H ≈ 64–128 dims) rather than the full residual stream. They report 83.3% top-head probe accuracy on LLaMA-7B (head 18, layer 14) and 84.4% by concatenating all heads — only marginally above the best single head, suggesting one head carries most of the signal. F-2's headline AUROC 0.7731 is fit on full residual-stream L19 (1536-dim for Qwen-2.5-1.5B). Mechanism: if a single Qwen head at some (l, h) carries an AUROC ≥ 0.78 for prefill correctness, F-2's framing of "L19 *layer* is canonical" is wrong — the canonical object is a head, and the layer-19 result is a coarse smoothing. Falsifiable: scan all (l, h) for Qwen-2.5-1.5B prefill correctness probing on cached P11 activations; refutation fires if max single-head AUROC > 0.78.

R2 — **A single static direction applied at every autoregressive step would refute F-3's "axis rotates through generation."**
ITI applies the *same* per-head direction `θ_l^h` at every generation token (Eq. 2, repeated autoregressively). The intervention is operationally a single fixed direction in head space, applied position-invariantly. F-3 says prefill DoM ⟂ final-token DoM (cos = 0.046). Mechanism: if we extract Qwen per-head ITI-style directions from MATH-500 prefill correctness labels and apply them at every position during K=1 greedy generation on a held-out 100-problem MATH-500 split, and accuracy rises by ≥ 5pp over baseline (current 48.6%), then the rotation captured in F-3 must be an artifact of probing the *full residual stream* — the per-head correctness subspace would be position-stable. Falsifiable: run intervention experiment on Qwen-1.5B with K=20, α ∈ {5, 10, 15, 20}, K_heads ∈ {16, 32, 48}, MATH-500.

R3 — **Cross-task direction transfer (TruthfulQA → NQ/TriviaQA/MMLU lifts of +1.5 to +4.5pp, Table 4) refutes the implicit task-specificity of F-2.**
ITI takes the *exact* TruthfulQA-fit direction with no retraining and gets +4.7 / +1.5 / +4.5pp on NaturalQuestions / TriviaQA / MMLU MC accuracy. F-2 reports AUROC 0.7731 on MATH-500 only and implicitly assumes the prefill direction is fit-per-task. H-5 explicitly says the prefill signal encodes "problem familiarity vs decomposability" — a MATH-500-specific construct. Mechanism: if we fit the L19 prefill DoM on a *non-MATH* QA correctness task (e.g., TriviaQA closed-book on Qwen-1.5B) and apply zero-shot to MATH-500, and AUROC > 0.65, then the correctness axis is partly task-general and H-5's "domain-familiarity" framing is too narrow. Falsifiable: 40min on cached Qwen-1.5B prefill activations + a fresh closed-book TriviaQA generation pass (~1k items, ~30min H100).

R4 — **Mass-Mean Shift > Probe-Weight direction (Table 3, +7.5pp gap) is a positive replication of DoM choice but contradicts the implicit assumption in F-9 that "single layer ≈ trajectory features".**
ITI explicitly compares Mass Mean Shift (DoM) vs probe-normal vs CCS direction; mass-mean wins decisively on True*Info (42.3% vs 34.8%). F-9 says CoE-60 (a 60-dim trajectory feature) is *redundant* with single-layer L19 DoM. But ITI's strongest result comes from K=48 *heads* across many layers — i.e., a 48 × 64 = 3072-dim *multi-layer, multi-head* DoM bank, not a single-layer single-direction. Mechanism: if we fit a multi-head, multi-layer DoM bank on Qwen-1.5B prefill (ranking heads by per-head AUROC, top-K), and the multi-head AUROC > 0.7731 + 0.03 absolute gain over single-layer L19, then F-9's "single layer suffices" is too strong — CoE was redundant only because we were comparing to the *wrong* DoM (single-layer instead of the multi-head bank). Falsifiable: 1h CPU on cached P11 prefill NPZs.

## Methodologies extracted

- **Per-head linear probe (post-MHA, pre-output-projection)** — train one binary linear probe per (layer, head) pair on `x_l^h ∈ R^{d_model/H}`. Rank heads by validation accuracy.
  *Replication cost*: 1h CPU on cached Qwen-1.5B prefill activations (need to extract per-head pre-projection activations, may require new forward pass — H100 30min).
  *We'd plausibly run this*: yes — directly tests R1 (per-head signal vs residual-stream L19 DoM).

- **Orthogonal probing** — fit a second probe `θ' ⊥ θ` to visualize 2D geometry of the truthful subspace. Reveals "truth lies in a subspace, not a single direction."
  *Replication cost*: 30min CPU.
  *We'd plausibly run this*: yes — would let us visualize whether prefill correctness is a single direction or low-rank subspace on Qwen-1.5B.

- **Mass-Mean Shift = (μ_truthful − μ_false)** — centroid difference vector, normalize, scale by σ_l^h, multiply by α. This is *operationally identical to our DoM*.
  *Replication cost*: zero — already implemented.
  *We'd plausibly run this*: already running it (this is our DoM).

- **σ-scaled, head-sparse intervention**: `x_{l+1} = x_l + Σ_h Q_l^h (Att(...) + α σ_l^h θ_l^h)` for h ∈ top-K, else θ_l^h = 0.
  *Replication cost*: implementation pass + H100 4h for MATH-500 generation sweep over (α, K).
  *We'd plausibly run this*: yes — direct test of H-1 with concrete hyperparameter grid (α ∈ {5, 10, 15, 20}, K ∈ {16, 32, 48}).

- **Bake-in via bias-term editing** (Eq. 3): `Bias_l += α Σ_h Q_l^h σ_l^h θ_l^h`. Lets the intervention live in a frozen model checkpoint without runtime hooks.
  *Replication cost*: 5min code change.
  *We'd plausibly run this*: yes — clean way to ship Qwen-ITI as a HF model artifact for reproducibility.

- **CCS-direction baseline** (Burns et al. 2022) — label-free direction-finding via consistency loss on paired activations.
  *Replication cost*: medium — requires implementing CCS loss; no cached implementation.
  *We'd plausibly run this*: yes for H-12 (semantic-entropy probes / label-free DoM).

- **2-fold cross-validation on a 5%-10% subset** — fit on 5%, evaluate on the rest, average across two folds.
  *Replication cost*: zero — protocol-only.
  *We'd plausibly run this*: yes — directly enables the data-efficiency check (R3).

- **CE + KL drift sentinels** — measure model behavior change on Open Web Text. CE before/after, KL of next-token distribution.
  *Replication cost*: 20min on cached generations + 1k WebText forward passes.
  *We'd plausibly run this*: yes — should be the standard sentinel for any future Qwen steering experiment.

- **Tiered evaluation: in-distribution + zero-shot OOD transfer** (TruthfulQA → NQ → TriviaQA → MMLU).
  *Replication cost*: 1 day H100 (closed-book QA generations).
  *We'd plausibly run this*: yes — directly tests R3 (cross-task direction transfer).

## Approaches & framings

- **"Knowing vs telling" gap (G-D gap)** — frames hallucination as a probe-accuracy / generation-accuracy mismatch (40pp gap on TruthfulQA for LLaMA-7B). Our F-2 is implicitly the *probe side* of an analogous gap on MATH-500 (probe ≈ 0.77 AUROC vs greedy generation ≈ 48.6% accuracy). Reframing F-2 explicitly as a "Qwen knows ~28pp more than it tells on MATH-500" claim would tighten the narrative and tie us into the canonical activation-editing literature.
- **Truth as a low-rank subspace, not a single direction** (Section 3.2, orthogonal probe) — directly motivates a multi-direction generalization of DoM. This is the paper's framing-level contribution: "second probe still yields better-than-chance accuracy." Would update H-5 / F-2 framing if we replicate.
- **Sparsity-as-minimal-invasion** — head-wise selection beats point-wise selection beats no-selection (Table 5), all at lower CE/KL drift. Argues for *fewer, head-localized* interventions over distributed ones. Tension with our P10 v2 findings (multi-direction steering didn't generalize) — head-sparsity may be the missing ingredient.
- **Trade-off-as-a-knob (α)** — frames truthfulness/helpfulness as a tunable scalar. Operational analog to our F-8 selective-prediction coverage knob. Suggests a unified "intervention-strength × abstention" 2D surface.

## Implementation details worth capturing

- LLaMA-7B: 32 layers × 32 heads, head dim 128, model dim 4096. Top probe: layer 14, head 18, val acc 83.3%.
- Optimal hyperparameters: K = 48 heads, α = 15 (sweep range α ∈ [0, 30], K ∈ [4, 96]).
- Probe is sigmoid(⟨θ, x_l^h⟩), trained on 4:1 train/val split of last-token concatenated (Q+A) activations.
- Direction normalization: θ → θ/‖θ‖, then scale by σ_l^h estimated from train+val pool.
- 2-fold CV on 5–10% of TruthfulQA → ~80 questions for fitting. Saturation at <40 examples (Figure 6A).
- True*Info evaluation via GPT-judge (two GPT-3-13B finetuned classifiers); authors note slight overestimation of truthfulness, underestimation of informativeness vs human eval.
- Code: https://github.com/likenneth/honest_llama (PyTorch + huggingface hooks).
- Pre-edited LLaMA2-7B artifact: https://huggingface.co/likenneth/honest_llama2_chat_7B (bias-baked).
- Activations are intercepted **after Att, before Q^h_l output projection** — this is the right hook point if we want to import their methodology faithfully. Our DoM hooks are on the residual stream after the full block, not at this finer point.

## 2306.03341 — Inference-Time Intervention: Eliciting Truthful Answers from a Language Model (Li, Patel, Viégas, Pfister, Wattenberg, NeurIPS 2023)

**Relevance:** Canonical activation-steering / probe-as-direction paper. Concurrent intellectual ancestor of our DoM and Pathway 2 / Pathway 10 work. Establishes (a) per-head, post-MHA probing as the canonical hook point, (b) mass-mean shift as the direction of choice (vs probe-normal vs CCS), (c) head-sparse intervention as minimally invasive, (d) α-scaling for tunable truthfulness/helpfulness trade-off. The reference baseline our orthogonality finding (F-3) is built against.

**Key claim we tested:** A linear probe fit to predict correctness from per-head residual-stream activations has a mass-mean direction that, when injected autoregressively at every token (`h' = h + α σ θ`), raises accuracy on the probed task — and the same fixed direction transfers zero-shot across QA datasets.

**Our result:** **CONTRADICTED for long-CoT reasoning at the residual-stream level; PARTIALLY CONFIRMED at the per-head level (untested but motivated).** F-3 reports cos(prefill_DoM, final_DoM) = 0.046 — the residual-stream correctness axis rotates through generation, so a single position-invariant direction (their core operational assumption) injects in the wrong subspace at most positions. F-8 confirms the *sign* of their core finding (selective signal exists) but the axis rotates. ITI's per-head probe target is finer-grained than F-2's residual-stream L19 hook; H-73 / P11-FE69 will test whether the per-head version of the claim survives on Qwen.
