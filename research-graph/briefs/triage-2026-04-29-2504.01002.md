# Triage brief — 2504.01002 — Token Embeddings Violate the Manifold Hypothesis

Source: https://arxiv.org/abs/2504.01002
Triaged: 2026-04-29

## Refutations

1. **F-10 (PH on residual streams = Gaussian null) — refutation: the
   *embedding layer* is non-Gaussian and very far from manifold structure.**
   Robinson et al. find Q1=20, Q2=389, Q3=531 for GPT2 small-radius dimension
   estimates and Q3=4096 (the full latent dim) for Llemma7B — these
   distributions are wildly heavy-tailed and reject manifold structure at
   p≈3×10⁻⁸. Our F-10 measured PH on Qwen-2.5-1.5B residual streams (later
   layers) and found a Gaussian null. **Mechanism**: PH at L19+ may be at
   null *because the embedding layer's singular structure has been smoothed
   by attention/MLP layers* — i.e. our null result is consistent with the
   paper, but the *input-layer* PH that we never measured may show large
   non-null persistence.
   **Falsifiable test**: extract Qwen-2.5-1.5B token-embedding matrix
   (`model.get_input_embeddings().weight`), run their Algorithm 1 on the
   152K-vocab embeddings (or a stratified subsample), check fraction of
   tokens with Bonferroni-corrected p<0.001. Then compute PH at *L0
   activations on MATH-500 prompts*, compare to Gaussian null with same
   covariance — predict that PH ≠ null at L0 even if at null at L19.

2. **H-5 (prefill encodes problem familiarity vs decomposability) —
   refutation: prefill DoM AUROC may be detecting input-token irregularity,
   not problem-decomposability.**
   The paper proves (Theorem 2) that token singularities propagate through
   *generic transformer composition* whenever 2d < ℓ (bounding-manifold
   dim < half the latent dim). For Qwen-2.5-1.5B (d_latent = 1536, w =
   32K), this condition almost certainly holds for the small-radius
   dimension estimate. **Mechanism**: MATH-500 problems differ in math-
   symbol density (`\frac`, `\sqrt`, `\int`, `^`, `_`, digits, LaTeX-
   token fragments). Such symbol-tokens are exactly the kind found at
   singularities (their Mistral7B example: `*` is singular, fragments and
   word-initial tokens dominate the rejection set). A prompt with high
   density of singular tokens is unstable → the model fails → prefill DoM
   labels it incorrect. The signal is therefore *token-irregularity*,
   not "familiarity vs decomposability".
   **Falsifiable test**: run Algorithm 1 on Qwen-2.5-1.5B vocab, score
   each MATH-500 prompt by mean / max token-singularity p-value, then
   compute Pearson correlation between (per-prompt singular-token density)
   and (per-prompt prefill L19 DoM score from
   `pathway11_h100/prefill_gated_compute/results.json`). If r > 0.5, H-5's
   semantic interpretation collapses to "prompt contains singular tokens".

3. **F-7 (D-bucket has distinctive *collective* geometric signature) —
   refutation: D-bucket may simply be the subset of prompts whose token
   composition contains more singularities, not a per-trajectory geometric
   property.**
   F-7 frames D-bucket as a property of *trajectory geometry* (collective,
   not per-problem). The paper proposes a strictly simpler input-side
   explanation: D-bucket prompts are those whose token-irregularity score
   is highest, and that input-layer irregularity persists into output via
   Theorem 2.
   **Falsifiable test**: stratify the 500 MATH-500 problems by per-prompt
   singular-token density (mean Bonferroni-p over tokens in the problem
   stem). If D-bucket problems (K=1 right, K=8 wrong, or whichever
   D-bucket definition the cached results use) cluster in the high-
   singular-density tertile, F-7's "collective" framing is unnecessary —
   the signal is at the embedding lookup, not at the trajectory.

4. **F-2 (prefill L19 DoM AUROC = 0.7731) — partial refutation: an L0
   embedding-only probe may already achieve a substantial fraction of
   that AUROC.**
   Theorem 2 implies the input singularity pattern is preserved into late
   layers under generic transformer conditions. If prefill DoM is largely
   reading out an already-present input-layer signal, then the "L19"
   specificity is misleading — the same signal exists at L0.
   **Falsifiable test**: build an L0-only DoM probe by averaging input
   embeddings across the prompt stem, project onto the difference-of-
   means direction at L0 between correct/incorrect, run 5-fold OOF on
   MATH-500 1024-tok labels. If AUROC > ~0.65 already at L0 (with no
   transformer computation), the L19 signal is partly inherited from
   input geometry, not from intermediate reasoning circuits.

## Direct connections to F-N / H-N

- **F-10 (PH = Gaussian null, AUROC test on residual streams)** —
  Robinson et al.'s methodology is the closest external analog of F-10's
  null-comparison approach. They reject the null at the embedding layer
  on four open-source LLMs; we reject it at residual streams (one model)
  in the *opposite direction*. Same statistical philosophy, different
  layer, different verdict. The paper is a methodological corroborator
  *and* a layer-specific contradicter for any claim that "transformer
  representations are non-manifold everywhere".
- **F-7 (D-bucket collective geometric signature)** — see Refutation 3.
- **F-2 (prefill L19 DoM AUROC 0.7731)** — see Refutation 4. The cos
  0.046 prefill-vs-final orthogonality (F-3) is also relevant: if prefill
  reads input geometry while final reads computational state, the
  orthogonality is mechanistic (different layers = different
  information), not a fact about reasoning structure.
- **H-5 (familiarity vs decomposability)** — see Refutation 2.
- **H-7 (density-based outlier detection finds D-bucket)** — Algorithm 1
  *is* a density-based outlier detector (local-dim from log-volume vs
  log-radius is exactly density estimation). Direct method-import
  candidate.
- **H-12 (semantic-entropy probes replace supervised DoM)** — paper
  suggests an unsupervised label-free signal: token-irregularity score.
  If irregular-token density predicts correctness, that is an entirely
  label-free correctness predictor based purely on the input prompt and
  the model's input embedding matrix.

## Methodologies extracted

- **Algorithm 1 — manifold + fiber bundle hypothesis test.**
  Compute n×n pairwise distance matrix on embedding vectors. For each
  token, sort the column → row index = volume, entry = radius. Compute
  log-log slopes (= local-dim estimates) via `numpy.gradient()` 3-point
  centered differences. Sliding-window 2-sample t-test on adjacent
  windows, manifold null = "slope is constant", fiber-bundle null =
  "slope does not increase with radius". Holm-Bonferroni multi-test
  correction.
  *Replication cost*: 152K vocab → 152K × 152K float32 distances = ~92
  GB RAM (need chunked computation or stratified sub-sample of e.g. 20K
  tokens). 1–2h CPU on chunked impl. Source code at Robinson [2025] on
  GitHub.
  *We'd plausibly run this*: yes — it's the cleanest off-the-shelf
  per-token irregularity score we have, and the paper's source is
  released. Drives FE-100, FE-101.

- **Local intrinsic dimension via log-volume slope.**
  Sub-method of Algorithm 1: for each token, ID = slope of
  log(num_neighbors) vs log(radius) over a chosen volume range. Robust,
  parameter-light, works on the bare embedding matrix.
  *Replication cost*: 20min CPU on 50K subsample.
  *We'd plausibly run this*: yes — gives us Robinson et al.'s "Q2=389"
  type summary on Qwen-2.5-1.5B for free, and lets us check whether
  H-7's density-based detector is equivalent.

- **Embedded-reach as a curvature proxy.**
  Largest τ such that any point within τ of X has unique closest point
  on X. Low reach = high local curvature = numerical instability. We
  could lift this concept onto residual streams as a "reach of trained
  representation" diagnostic.
  *Replication cost*: 1h CPU; relies on Berenfeld et al. 2022 estimator.
  *We'd plausibly run this*: maybe — diagnostic but no clear hypothesis
  it tests in our framework yet.

- **Holm-Bonferroni-corrected per-point hypothesis testing on geometric
  null.**
  General template: any per-token / per-trajectory geometric statistic →
  per-token p-value → multi-test correction → token-level rejection set.
  Direct portable methodology for any future probe-quality test.
  *Replication cost*: trivial wrapper.
  *We'd plausibly run this*: yes — should retrofit onto F-10's PH null
  test for per-point-cloud rejection rather than aggregate.

## Approaches & framings

- **Singularities as a *propagating* property of transformer
  computation (Theorem 2).** Reframes "what does the transformer do to
  irregular structure?" as a question with a sufficient condition rather
  than a vibe. Intersects with our F-3 prefill/final orthogonality:
  perhaps prefill reads inherited input singularities (preserved by
  Theorem 2), final reads computed state. This recasts F-3 from "two
  independent learned directions" to "one inherited + one computed".
- **Fiber bundle as a relaxed-manifold null.** Useful concept: instead
  of "is X a manifold?" ask "is X a fiber bundle?" — gives a graded
  ladder of nulls. Could refactor F-10's binary "PH=null vs not" into a
  ladder of geometric nulls (Gaussian → fiber bundle → manifold).
- **Polysemy/homonymy ↔ singularities.** Provides a *linguistic*
  predictive hypothesis for which tokens will be irregular (homonyms,
  word fragments, prefixed-fragments like `aunder`). Lets us pre-pick
  candidate "singular tokens" in MATH-500 by semantic role (latex
  fragments, polysemous math symbols like `*`).

## Datasets & benchmarks

- **GPT-2 token embeddings (n = 50,257)** — open, HF accessible. *Not
  applicable* directly (we use Qwen) but a useful sanity-check baseline
  for replicating the paper's Algorithm 1 before applying to Qwen.
- **Llemma7B (n = 32,016)**, **Mistral7B (n = 32,016)**, **Pythia6.9B
  (n = 50,254)** — open, HF. Same — sanity-check baselines, not core
  pipeline.
- **No new MATH-500 / 1024-tok regime data** — paper is purely vocab-
  level analysis. Applicable only by us re-running Algorithm 1 on the
  Qwen-2.5-1.5B vocab matrix and joining to per-problem prompts.

## Implementation details worth capturing

- Algorithm 1 is fully deterministic (no random seeds, fixed embedding
  matrix). Single-run reproducibility.
- Two `(vmin, vmax)` regimes per model: a "small radius" and a "large
  radius" pass, picked by inspecting a small simple-random-sample of
  tokens looking for elbow points in log-log curves. Heuristic — needs
  human-in-the-loop tuning per new model.
- Sliding-window size W and significance level α are tunable; Holm-
  Bonferroni applied across all tokens.
- They use the *raw input embedding matrix* (the lookup), not
  contextualized embeddings. Critical: we should NOT confuse with
  attention-output embeddings.
- `numpy.gradient()` 3-point centered differences for slope estimates.
- Source code: Robinson [2025], referenced as a GitHub repo (paper says
  "Source code is available at Robinson [2025]"; URL not in the
  fragment we have but should be findable).

## Replicable intermediates

- **L0-only DoM probe on MATH-500 1024-tok** — load Qwen-2.5-1.5B
  embedding matrix (it's part of the model checkpoint we already have);
  for each MATH-500 prompt mean-pool L0 token embeddings → compute DoM
  direction between correct/incorrect labels (labels in
  `pathway11_h100/prefill_gated_compute/results.json`); 5-fold OOF
  AUROC. Compares directly to F-2's 0.7731. ~30min CPU.
- **Per-token local-dim on Qwen-2.5-1.5B vocab** — 152K × 152K is heavy,
  use stratified 20K subsample. Compute log-volume slopes across two
  vmin/vmax regimes. ~1h CPU. Gives us per-token irregularity score for
  every Qwen vocab item.
- **Per-prompt singular-token-density correlation with prefill DoM** —
  given the irregularity score, compute mean / max irregularity across
  the prompt stem, correlate with cached prefill DoM scores. ~10min
  CPU.

## Proposed PAPER_INDEX.md classification

## 2504.01002 — Token Embeddings Violate the Manifold Hypothesis (Robinson, Dey, Chiang, 2025)

**Relevance:** Methodological cousin to F-10. Paper introduces a per-token
local-dim hypothesis test (Algorithm 1) on the *input embedding matrix*
of four open LLMs (GPT2, Llemma7B, Mistral7B, Pythia6.9B) and rejects
the manifold null at p≈3×10⁻⁸ — but at the embedding lookup, not at
residual streams. Theorem 2 gives sufficient conditions
(2 d_bound < d_latent) under which input-layer singularities propagate
into outputs through generic transformer composition; for Qwen-2.5-1.5B
(d_latent=1536, w=32K) the condition almost certainly holds. This is
load-bearing for our prefill-DoM mechanistic interpretation: the
correctness signal F-2 reads at L19 may partly be input-token
irregularity inherited unchanged through 19 layers.

**Key claim we tested:** Token subspaces of LLMs are not manifolds; this
non-manifold structure propagates to outputs and explains prompt-
sensitivity.

**Our result:** **TO TEST** Methodology directly portable; we have all
ingredients (Qwen-2.5-1.5B embedding matrix, MATH-500 prompts, cached
prefill DoM scores) for a 1-2h CPU replication. Three concrete
refutation tests in queue (FE100, FE101, FE102, P10-FE100). Until
those run, status is open.

**Related experiments:** P11-FE100, P11-FE101, P11-FE102, P10-FE100,
H-100, H-101, H-102. Adjacent: F-2, F-3, F-7, F-10, H-5, H-7, H-12.

**Status:** TO TEST (HIGH priority — refutation tests for F-2, H-5, F-7
all rely on FE100 output).
