# Triage brief — 2606.02765 — Representational Capacity: Geometric Limits on Feature Representation in Transformer Language Models

Source: https://arxiv.org/abs/2606.02765
Triaged: 2026-06-06

## Refutations

**R1: F-3 (cos(prefill_DoM, final_DoM) = 0.046 is "structurally orthogonal") may be geometric null, not structural.**
The paper classifies Qwen-2.5-1.5B as Class 1 (ε = 0.25998 — "indeterminate" representational capacity). At d = 1536, random unit vectors have expected |cos| ≈ 1/√1536 ≈ 0.0255 with the model's accepted deviation ε = 0.26. cos = 0.046 is ≪ ε, meaning it falls well within the range of incidental similarity the model tolerates between *unrelated* directions. F-3 claims the prefill/final orthogonality is structurally meaningful (two distinct computation modes); the representational capacity framework predicts any two arbitrary directions at d = 1536 would show similar near-zero cosine by chance alone.
*Falsifiable by:* Monte Carlo null: sample 10,000 random unit-vector pairs in R^1536, compute the fraction with |cos| ≤ 0.046. If the p-value is > 0.05, F-3's structural claim is undermined. This directly tests H-445 and H-694.

**R2: F-2's DoM-as-feature-direction interpretation is undermined by Qwen-2.5-1.5B's Class 1 status.**
The paper's two-class taxonomy places Qwen-2.5-1.5B firmly in Class 1 — models whose embeddings lack near-orthogonal structure and whose representational capacity bound is "vacuous." The Linear Representation Hypothesis (features = near-orthogonal directions in R^d) is the theoretical foundation for interpreting the DoM as a correctness "feature direction." If the model is in a regime where near-orthogonal feature superposition does not hold at the embedding level, then interpreting a supervised direction (DoM) as a genuine LRH feature direction at L19 is less justified. The AUROC = 0.7731 may reflect something other than a clean feature direction — e.g., an axis of variance that correlates with difficulty but is not a feature in the LRH sense.
*Falsifiable by:* Compute ε_latent for L19 prefill activations (pairwise cosine similarity distribution, μ + 2σ). If ε_latent < 0.1 (Class 2 regime), the latent space has better near-orthogonal structure than the embedding space and the LRH interpretation is rescued. If ε_latent ≫ 0.1, the Class 1 status extends to the residual stream and undermines LRH-based interpretation of DoM.

**R3: F-6 (7B prefill PR inversion) may be explained by a Class 1 → Class 2 transition across scale.**
Qwen-2.5-7B has ε = 0.07501 (Class 2), while Qwen-2.5-1.5B has ε = 0.25998 (Class 1). These models are in fundamentally different geometric regimes. The 7B model maintains tight near-orthogonal feature structure with representational capacity ≈ 1.20 × 10^8 directions, while the 1.5B model has indeterminate (vacuous) capacity. F-6 reports that the 7B model shows inverted prefill precision-recall behavior. This could be a direct consequence of the Class 1/Class 2 boundary: at 7B, features are tightly packed and near-orthogonal, so a single DoM direction must compete with ~10^8 other feature directions for the inner product channel — diluting the signal. At 1.5B, in the unstructured Class 1 regime, there is less interference and a single direction can dominate more easily.
*Falsifiable by:* Compute ε_latent at L19 for both 1.5B and 7B cached activations. If the ε_latent values mirror the embedding ε split, the Class 1/Class 2 boundary mechanistically explains F-6. If both have similar ε_latent, the explanation is elsewhere.

**R4: H-862 (intrinsic dimensionality determines AUROC ceiling via ε²) gets a concrete formula.**
The paper's adjusted capacity formula k ≤ d · exp(d·ε²/C) provides an exact relationship between ε, d, and representable directions. If we estimate ε_latent from L19 activations and compute capacity, we can test whether the AUROC ceiling (0.7731 for DoM, 0.7928 for cov-spectrum) correlates with log(capacity). If capacity at L19 is low, the ceiling is a capacity constraint; if capacity is high, the ceiling must come from elsewhere (e.g., computational capacity, information not yet in the residual stream at L19). This operationalizes H-862 with a specific functional form.
*Falsifiable by:* Compute capacity at L19 from ε_latent. If capacity ≪ 500 (number of samples), the probe is geometrically constrained. If capacity ≫ 500, the ceiling is not a representational capacity issue.

## Direct connections to F-N / H-N

- **F-2 (AUROC 0.7731, L19 prefill DoM):** The paper's representational capacity framework questions whether DoM is a genuine LRH feature direction or a correlate of variance structure. Qwen-2.5-1.5B's Class 1 status (ε = 0.26) means the LRH may not hold at the embedding level for this model. However, the paper leaves open whether latent-space geometry differs from embedding geometry (Section 2.4), so F-2 is not directly refuted — it is *qualified*.

- **F-3 (cos = 0.046, prefill/final orthogonality):** Most directly threatened. At d = 1536, cos = 0.046 is ~1.8σ from zero under i.i.d. random vectors (std ≈ 1/√d ≈ 0.0255). With the paper's ε = 0.26 for this model, any pair with |cos| < 0.26 is "incidentally similar." The structural interpretation of F-3 requires showing cos = 0.046 is anomalously low *relative to other direction pairs in the same latent space*, not merely relative to zero.

- **F-10 (PH ≈ Gaussian null):** The paper's finding that Qwen-2.5-1.5B embeddings are Class 1 (lacking near-orthogonal structure) is *consistent* with F-10's PH-null result. If the model doesn't maintain clean near-orthogonal geometry, topological summary statistics would indeed be indistinguishable from Gaussian noise. This is a corroboration, not a refutation.

- **H-445 (cos = 0.046 at/below high-dim baseline) and H-694 (ETF null):** Directly testable using this paper's framework. The paper provides the exact ε and d_model values needed to construct the null distribution. These hypotheses become *actionable* with the paper's representational capacity formula.

- **H-693 (strong superposition regime at L19):** The paper classifies Qwen-2.5-1.5B as Class 1 at the embedding level — meaning superposition is NOT operating at the embedding level. Whether L19 latents are in the superposition regime (Class 2) is an open empirical question the paper's methodology can directly test.

- **H-862 (intrinsic dimensionality vs AUROC ceiling):** The adjusted JL formula k ≤ d · exp(d·ε²/C) gives an explicit ε² dependence for capacity, matching H-862's predicted ε² ~ r^{-1/D} scaling. Computing ε_latent at L19 and comparing capacity to AUROC provides a concrete test.

## Methodologies extracted

- **Embedding ε estimation (μ + 2σ of pairwise cosine similarity distribution)** — compute all-pairs cosine similarity of a set of vectors, fit mean and std, take ε = μ + 2σ as the boundary between incidental and meaningful similarity.
  *Replication cost*: 5min CPU on cached 500×1536 activations.
  *We'd plausibly run this*: yes — directly applicable to L19 prefill activations to get ε_latent.

- **Optimized vector packing (Gram-matrix penalty minimization)** — initialize k random unit vectors in R^d, minimize L = Σ_{i≠j} |G_ij|^p on the Gram matrix via Adam (5000 steps, p ∈ [40,60]) to find the tightest achievable ε* for given (k,d).
  *Replication cost*: 10-30min CPU per (k,d) pair; sweep over multiple pairs ~2hr.
  *We'd plausibly run this*: yes — could validate the adjusted JL formula at d=1536 specifically, and test whether our L19 activations achieve packing closer to the optimized or random regime.

- **Adjusted JL capacity formula: ε = √(C·ln(k/d)/d)** — single-parameter modification to the JL bound (replacing ln(k) with ln(k/d)) that reduces MAPE from 975% to 8% on optimized vectors.
  *Replication cost*: trivial computation once ε and d are known.
  *We'd plausibly run this*: yes — plug in ε_latent from L19 activations and d=1536 to get capacity bound.

- **Two-class model taxonomy via ε threshold** — classify models as Class 1 (ε > 0.2, no near-orthogonal structure) or Class 2 (ε < 0.1, active superposition) based on embedding cosine similarity distributions.
  *Replication cost*: 5min CPU per model (requires embedding matrix access).
  *We'd plausibly run this*: yes — extend to latent-space classification at each layer to find if/where Class 1 → Class 2 transition occurs in the residual stream.

## Approaches & framings

- **Representational capacity as shared resource.** Embeddings, unembeddings, and features all draw from the same pool of near-orthogonal directions in R^d_model. This reframes our DoM direction as consuming one of a finite number of distinguishable directions — and the question becomes whether the model has *capacity* for a dedicated correctness direction vs. overloading existing directions. Intersects F-2 and the cos(DoM, PC1) = 0.9216 finding: DoM ≈ PC1 suggests the correctness signal rides the dominant variance direction rather than being a dedicated feature.

- **ε as emergent property, not hyperparameter.** The paper frames near-orthogonality tolerance as something that *emerges* from training, not something set by design. This reframes H-693 (superposition regime): instead of asking "is the model in the superposition regime?" we can measure ε_latent layer by layer and find where (if anywhere) the model transitions to structured feature superposition during forward processing.

- **Stability-capacity trade-off.** Larger models favor tighter ε (less capacity but more stability) rather than maximizing raw capacity. This is a new lens for understanding why the 7B model (Class 2, ε = 0.075) doesn't show a better DoM AUROC than the 1.5B (Class 1, ε = 0.26) — tighter orthogonality may actually make single-direction probing harder by distributing signal across more competing directions.

## Datasets & benchmarks

- **48-model embedding analysis dataset** — pairwise cosine similarity distributions computed across 48 open-source LLMs (Table 1 in Appendix D). Not released as a separate dataset, but reproducible from public model weights.
  Applicable? yes — Qwen-2.5-1.5B and Qwen-2.5-7B are both included, providing direct ε_embedding values for our models.

- **Optimized vector packing dataset** — (k,d) sweep with d ∈ {32,...,4096}, k ∈ {2000,...,32000}, optimized via Gram matrix penalty minimization.
  Applicable? yes — d=1536 is included in the sweep, giving us baseline packing efficiency for our specific dimensionality.

## Implementation details worth capturing

- Gram matrix penalty: L = Σ_{i≠j} |G_ij|^p with p ∈ [40,60], Adam optimizer, 5000 steps. Higher p approximates L∞ (minimax) norm, encouraging tight packing.
- Adjusted JL formula (single-parameter): C ≈ 1.293, R² = 0.9984, MAPE = 7.9%.
- Fully parameterized: C = 0.458, a = 1.067, b = 1.447, c = 0.972, R² = 0.9998, MAPE = 5.4%.
- Qwen 2.5 1.5B: d_model = 1536, ε = 0.25998, capacity = indeterminate (Class 1).
- Qwen 2.5 7B: d_model = 3584, ε = 0.07501, capacity ≈ 1.20 × 10^8 (Class 2).
- Code: https://github.com/Alex-Guha/representational-capacity
