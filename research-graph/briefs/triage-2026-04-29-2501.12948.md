# Triage brief — 2501.12948 — DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning

Source: https://arxiv.org/abs/2501.12948
Triaged: 2026-04-29

## Refutations

1. **F-2 (prefill L19 DoM AUROC 0.7731 on Qwen-2.5-1.5B)** could be regime-locked
   to non-reasoning-trained checkpoints. DeepSeek-R1 distills long-CoT reflection
   behavior (the "aha moment" of "Wait, wait. Wait.") into Qwen-2.5-Math-1.5B
   producing R1-Distill-Qwen-1.5B, which exhibits *runtime self-revision* —
   trajectories that switch direction mid-stream. **Mechanism**: prefill DoM
   measures the residual-stream state *before* generation, so it cannot
   anticipate post-hoc reflection-driven corrections that the R1-trained
   policy adds at runtime. **Falsifier**: extract L19 prefill embeddings from
   R1-Distill-Qwen-1.5B on the same MATH-500 prompts, recompute 5-fold OOF
   AUROC. If AUROC drops below 0.65 (vs 0.7731 on base), F-2 is downgraded
   from "intrinsic to the architecture" to "intrinsic to non-RL Qwen weights"
   and HYPOTHESES.md needs a regime-of-validity caveat.

2. **F-3 (cos(prefill_DoM, final_DoM) = 0.046)** predicts orthogonality
   because the project's base Qwen-2.5-1.5B has no learned reflection circuit
   that systematically reuses prefill encodings during generation. R1-style
   training explicitly rewards trajectories that re-enter their own reasoning
   ("verify, reconsider"). **Mechanism**: if reflection involves a circuit that
   reads the prefill representation and writes corrections to the final
   residual stream, the two DoMs should partially align. **Falsifier**:
   recompute cos on R1-Distill-Qwen-1.5B. If cos rises above 0.25 with the
   same fitting protocol, "prefill ⊥ final" stops being a universal claim
   about LLM geometry and becomes a marker for *absence of learned
   reflection*. That would invert the framing in PERSPECTIVES.md (orthogonality
   is no longer a deep finding — it is a tell that the model isn't a reasoner).

3. **F-9 (CoE-60 ≡ single-layer L19 DoM at 1024-tok)** is fragile under R1
   training. The "aha moment" in DeepSeek-R1-Zero appears at training step 8.2k
   as a sudden discontinuity in response length and "wait" frequency — i.e.
   trajectories acquire discrete events that base models lack. **Mechanism**:
   CoE-60 takes 60 trajectory features (per-layer norm/PR/centroid drift); a
   discrete reflection event should add information beyond a single layer's
   DoM precisely because the event is non-monotonic and visible in trajectory
   curvature, not in any single layer's static projection. **Falsifier**: run
   CoE-60 vs L19-only AUROC on R1-Distill-Qwen-1.5B. If the gap (CoE − DoM)
   exceeds the noise floor we measured on base Qwen (≈ 0.01), F-9's
   "redundancy" claim is regime-specific.

4. **F-1 (universal dimensional breathing) and H-9 (breathing amplitude
   predicts difficulty)** both rest on data from base / instruct checkpoints.
   DeepSeek-R1's 8.2k-step phase transition implies reasoning capability is
   *acquired*, not architectural. **Mechanism**: if breathing is RoPE/AR-mechanics
   (H-17), R1-distill should breathe identically; if it reflects acquired
   computation, the amplitude / temporal profile should *change*. **Falsifier**:
   measure peak PR and breathing amplitude across base Qwen-2.5-1.5B,
   Qwen-2.5-Math-1.5B (the R1-distill base), and DeepSeek-R1-Distill-Qwen-1.5B
   on the same 50-prompt subset. A statistically distinguishable amplitude
   shift refutes "breathing is universal" and confirms H-10 ("breathing
   pattern changes after fine-tuning"). The current H-1...H-22 framing
   doesn't anticipate that *post-training is the relevant axis of variation*.

5. **H-5 (prefill encodes problem familiarity vs decomposability)** —
   DeepSeek-R1's training signal is *outcome-only* with format reward; the
   model learns to allocate variable inference compute (long CoT for hard
   problems, short for easy ones) without any prefill-time computation that
   "previews" the answer. **Mechanism**: if the prefill genuinely predicts
   correctness, an R1-trained model should still expose that signal even
   though its decision to reflect is now runtime. But if prefill AUROC
   collapses on R1-distill (refutation 1) while accuracy *rises*, the
   prefill signal in base Qwen was never an estimate of decomposability — it
   was an estimate of *whether the model would mechanically arrive at the
   right answer without reflection*. That makes prefill DoM a marker of
   "easy-mode answers", not of problem-intrinsic difficulty.

## Direct connections to F-N / H-N

- **F-2** (prefill AUROC 0.7731): replication on R1-Distill-Qwen-1.5B is the
  cleanest test the project can run because the released distilled model is
  drop-in compatible with the existing P11 H100 extractor pipeline.
- **F-3** (cos = 0.046): same replication target; this is the headline
  geometric claim with the most surprising implication, so the asymmetric
  cost of being wrong here is high.
- **F-7** (D-bucket collective signature): R1-distill might *eliminate* the
  D-bucket entirely (problems where K=1 right but K=8 wrong) because long
  CoT collapses K=1 vs K=8 into a single high-quality run. If D-bucket
  membership shrinks dramatically, F-7's "collective signature" loses its
  test set.
- **F-8** (selective-prediction acc 71.6% at coverage 0.5, K=2.5 avg): the
  paper's core efficiency story is "DeepSeek-R1 dynamically allocates
  compute" — section 6, "Token efficiency". This is *the same problem*
  F-8 solves with prefill DoM, framed as routing in the model rather than
  routing across samples. Direct conceptual overlap with H-19 (C_exact
  verification routing).
- **F-10** (PH at Gaussian null): R1's training induces *long-range
  structural change* (length doubles, "wait" tokens appear). If PH on
  R1-distill is *also* at Gaussian null, F-10 is robust to post-training.
  If R1-distill shows non-null persistence, F-10 was specific to the
  base-model regime.
- **H-1** (per-position DoM steering): R1's GRPO is conceptually a *steering
  signal acquired by RL*. If F-3's orthogonality breaks on R1-distill,
  H-1 changes from "we're trying to engineer steering vectors" to "RL
  already engineered them — can we read them off the weights?"
- **H-10** (breathing pattern changes after fine-tuning): R1-distill is the
  ideal test article — it is not just fine-tuned, it is *long-CoT-distilled*
  on 800k samples averaging 5355 tokens. H-10 is essentially blocked on
  this paper's released models being downloaded.
- **H-19** (C_exact verification routing): DeepSeek-R1 *is* a verification-
  routing model trained end-to-end. It already exhibits the routing
  behavior H-19 hopes to engineer, which makes R1-distill the obvious
  upper-bound baseline for any C_exact routing experiment.

## Methodologies extracted

- **Group Relative Policy Optimization (GRPO)** — PPO without a value model;
  advantage = (r_i − group_mean) / group_std over G samples per question.
  *Replication cost*: $50K+ H100 for full training; trivial in TRL/verl
  for toy validation.
  *We'd plausibly run this*: no — out of scope; but worth knowing the
  reference policy is swapped every 400 steps, which is an experimental
  knob other papers don't expose.

- **Outcome-only rule-based reward (no PRM, no ORM, no neural RM)** —
  accuracy reward (sympy / compiler / option matching) + format reward
  (`<think>...</think><answer>...</answer>`) + language reward.
  *Replication cost*: minimal; the design lesson is the explicit refusal
  to use neural reward models for reasoning ("susceptible to reward
  hacking during large-scale RL").
  *We'd plausibly run this*: no — but it informs how we should treat
  any neural-RM-derived correctness label in our own datasets.

- **Reflection / "aha-moment" detector** — the paper tracks frequency of
  the word "wait" during CoT generation (Figure 9b in their supplement)
  and shows a sharp jump at step 8.2k.
  *Replication cost*: 30min CPU on existing P11 generations.
  *We'd plausibly run this*: yes — running this on our cached MATH-500
  generations from base Qwen-2.5-1.5B vs R1-Distill-Qwen-1.5B would tell
  us whether reflection events are present in our regime, which gates
  refutations 3 and 5.

- **Long-CoT context expansion (32k → 65k tokens at step 8.2k)** —
  curriculum-style increase of max generation length partway through RL.
  *Replication cost*: needs RL infrastructure we don't run.
  *We'd plausibly run this*: no — but informs interpretation of our
  1024-tok labelling regime as drastically truncated relative to R1.

- **Cold-start SFT + 2-stage RL (rejection-sampling SFT between stages)** —
  thousands of human-readable seed traces → first RL → rejection-sample
  600k correct traces → SFT → second RL (mixed reasoning + preference).
  *Replication cost*: O(GPU-month) per stage at any meaningful size.
  *We'd plausibly run this*: no.

- **DeepSeek-V3-as-judge for non-rule-verifiable rewards (Listing 4)** —
  generative LLM-judge prompt with explicit "correct/incorrect" output
  field for cases where sympy/compiler can't decide.
  *Replication cost*: API cost only.
  *We'd plausibly run this*: yes for a small bucket — could replace our
  current correctness labelling on edge cases where extractor sympy
  parsing fails.

- **Language consistency reward (proportion of target-language tokens in
  CoT)** — added to total reward, slightly degrades benchmark accuracy
  but improves readability.
  *Replication cost*: trivial.
  *We'd plausibly run this*: no — not in scope.

- **High GRPO clip ratio ε = 10** — the paper notes (§3.2.1) "clip ratio
  plays a crucial role; lower values truncate gradients for many tokens,
  higher values cause instability." 10 is dramatically larger than the
  standard 0.2 used in PPO/GRPO literature.
  *Replication cost*: hyperparameter for any future RL fine-tune.
  *We'd plausibly run this*: only if H-1 graduates to a real RL steering
  experiment (currently parked).

## Approaches & framings

- **"Pure RL beats SFT for reasoning"** — direct challenge to the framing
  that human reasoning trajectories are upper-bound supervisors. F-2's
  AUROC measurement implicitly assumes the model arrives at correctness
  via an SFT-style trajectory; if R1 is right, our prefill probe
  measures something specific to that trajectory class.

- **"Reasoning capability is *incentivized*, not designed"** — the paper
  argues reasoning circuits already exist in the base model; RL just
  amplifies them. This is the conjugate of H-1's framing (DoM is a
  steering signal we can inject) — the alternative framing is that GRPO
  has *already* sculpted the same direction we're trying to find with
  probing.

- **"Token efficiency = dynamic compute allocation"** (their §6 limitation
  framing). They explicitly position their model against majority voting
  and MCTS, claiming dynamic allocation is intrinsically more efficient.
  This is the same dichotomy we have between C_infer (sample more) and
  C_exact (think harder per sample) — H-19.

- **"Reward hacking is the bottleneck for general RL"** — neural reward
  models break under large-scale RL. This is a methodological warning for
  any future probing-as-reward work (H-1 v2 if anyone proposed RL'ing the
  L19 DoM as an objective).

- **Distillation > small-model RL** — Supplementary F (not loaded here
  because the HF rendering omits the distillation table) reportedly
  shows that SFT'ing R1 reasoning traces into Qwen-2.5-1.5B beats running
  GRPO on Qwen-2.5-1.5B directly. This re-frames "small-model reasoning"
  as a data problem, not a training-algorithm problem.

## Implementation details worth capturing

- **R1-Distill-Qwen-1.5B** is on HF (`deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B`),
  same architecture as our current Qwen-2.5-1.5B (28 layers, 1536 hidden) —
  drop-in for our P11 extractor with no code changes. **This is the single
  most actionable lever from this paper.**
- **R1-Distill-Qwen-7B** is similarly drop-in for the 7B extractor.
- Long-CoT default temperature 1.0 during rollout (we run 0 / greedy);
  lower temperature 0.7 in the second RL stage; "few-shot prompting
  consistently degrades performance" — they recommend zero-shot.
- Maximum context they use during eval is 65,536 tokens; our 1024-tok
  labelling regime is therefore ~64× shorter than R1's natural inference
  envelope. Direct comparison numbers are not apples-to-apples.
- GRPO hyperparameters they used: lr=3e-6, KL coef=0.001, ε_clip=10,
  G=16 group size, batch=512, ref policy refresh every 400 steps,
  10,400 total steps = 1.6 epochs.
- Code repo: https://github.com/deepseek-ai/DeepSeek-R1
- Author list at end shows Zhibin Gou led the R1-Distill series — useful
  if we ever email them.

### H-72: Prefill L19 DoM AUROC degrades on reasoning-distilled checkpoints
**Priority:** HIGH
**Motivated by:** 2501.12948 + F-2
**Test:** Extract L19 prefill activations from `deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B` on the full MATH-500 set. Compute 5-fold OOF logistic-regression AUROC for K=1 correctness. Compare to the 0.7731 baseline measured on base Qwen-2.5-1.5B at 1024-tok labels. Decision threshold: AUROC drop of ≥ 0.06 (i.e. < 0.71) is the falsifier.
**Requires:** H100 (~30 min for extraction), CPU for fitting, no new data — MATH-500 prompts are reused.
**Would change:** On confirm (drop), F-2 is rewritten with a regime-of-validity clause restricting it to non-reflection-trained checkpoints; the project narrative shifts from "we found a universal correctness direction" to "we found a direction that decays under post-training that adds reflection." ## Proposed PAPER_INDEX.md classification

## 2501.12948 — DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning (DeepSeek-AI, 2025)

**Relevance:** R1 is the canonical reasoning-RL paper of 2025 and the
direct upstream of `deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B`, an
architecturally drop-in replacement for the project's base
Qwen-2.5-1.5B. The paper's claims about emergent reflection ("aha
moment", §2.3) and outcome-only RL with rule-based reward provide the
single sharpest test we have of whether F-2 (prefill AUROC), F-3
(prefill ⊥ final), and F-1 (universal breathing) survive aggressive
post-training that adds long CoT and self-revision. It also frames our
