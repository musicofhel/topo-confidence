# Triage brief — 2311.01460 — Implicit Chain of Thought Reasoning via Knowledge Distillation

Source: https://arxiv.org/abs/2311.01460
Triaged: 2026-04-29

## Refutations

1. **F-9 ("CoE-60 trajectory features are redundant with single-layer L19 DoM") is contradicted on tasks where vertical-layer trajectory carries non-redundant content.**
   - *Mechanism*: Implicit-CoT's diagonal extraction (one teacher hidden state per layer, indexed `z_{ll}`) achieves **100% validation accuracy** on 4×4 multiplication using GPT-2 Small as the student input substitute, while the **top row alone gets 84.4% and the bottom row 57.6%** (Section 6, "Taking Different Subsets"). This is direct evidence that under task settings dominated by stepwise computation, the layer-wise trajectory carries information that no single layer reproduces. F-9's redundancy claim was tested on MATH↔BBH transfer (Δ = +0.004 favoring DoM over CoE-60). If we replicate the diagonal-vs-single-layer probe protocol on Qwen-2.5-1.5B prefill activations and the diagonal probe beats L19 by >2 points on MATH-500 K=1 correctness, F-9 needs a domain qualifier ("redundant for transfer-style features; non-redundant for stepwise correctness signals").
   - *Test*: index a "diagonal" feature `z_{l, t_l}` with `t_l = ⌊1 + ∆(l−1)⌋, ∆ = (T−1)/(L−1)` on the cached P11 1.5B prefill activations (28 layers × prompt-token length per problem), then fit the same supervised correctness probe used in F-2/F-9. Compare AUROC against L19 DoM. If Δ ≥ +0.02 AUROC for the diagonal probe at 1024-tok labels, F-9 is refuted on this regime.

2. **F-3 ("Prefill and final-token DoM directions are orthogonal", cos = 0.046) loses informational significance if the entire trajectory is input-determined.**
   - *Mechanism*: The paper's "Thought Emulator" trains a ~24-layer LSTM-with-self-attention to predict the teacher's full vertical hidden-state sequence `ẑ_1...ẑ_L` **from the input alone** (Section 3.2, MSE loss `min Σ ‖z_l − ẑ_l‖²`). On 4×4/5×5 multiplication this works to ≥96% answer accuracy. Applied to our setting, this means a feed-forward emulator predicts the *entire* layer-wise trajectory deterministically from the prompt. F-3 currently treats the orthogonality between prefill DoM and final-token DoM as evidence that "the model computes new things across positions". But if `prefill_DoM_direction` and `final_DoM_direction` are *both* predictable from the prompt, the orthogonality is a fact about the model's compression scheme (two near-orthogonal heads in the residual stream), not about new computation happening between prefill and final token.
   - *Test*: train a small input-conditioned regressor (e.g., 2-layer MLP on token-mean embeddings) on the cached 1.5B prefill activations to predict (a) the projection of prefill L19 onto our DoM direction and (b) the projection of final-token L19 onto its DoM direction. If both regressors achieve R² > 0.5 from input alone, the cos = 0.046 finding is recharacterized as "the model uses two orthogonal residual subspaces, both input-determined" — F-3's interpretive gloss is refuted even though the number stands.

3. **F-2 ("prefill L19 DoM AUROC 0.7731") is probe-bound, not signal-bound, in the regime where vertical CoT is possible.**
   - *Mechanism*: GPT-2 Medium (24 layers) trained with implicit CoT achieves **96% accuracy on 5×5 multiplication** producing the answer directly with no token-CoT, vs **2% No-CoT baseline** (Table 3). That is 47× lift from the same set of layers carrying enough information *deterministically* to produce correct answers. Our F-2 ceiling of AUROC 0.7731 on Qwen-2.5-1.5B/MATH-500 is from a single linear probe at L19 of a *pretrained* model that was never trained to compress CoT into vertical layers. If the gap between 0.7731 and the upper bound is mostly probe-class (linear probe over single-layer mean-pooled hidden state), then F-2 is reframed as "the *current probe* extracts 0.7731", not "the prefill state encodes only 0.7731-worth of correctness signal".
   - *Test*: on the same cached P11 1.5B prefill activations, fit a 2-layer MLP with all 28 layer-mean activations concatenated (28 × hidden_dim input) for binary correctness. If AUROC > 0.82, the F-2 ceiling is probe-bound; if AUROC ≤ 0.78, the ceiling reflects the true information content of the prefill state and F-2 stands.

4. **F-1 ("dimensional breathing is universal") may be a verbalization-artifact rather than a property of reasoning.**
   - *Mechanism*: Implicit CoT replaces horizontal token-by-token generation with vertical layer-wise computation; the student produces the answer in a *single* forward pass of input → 1 answer token. There is no temporal trajectory, hence no PR breathing curve to measure. If breathing reflects the cost of incremental verbalization (each new token forces dimensional inflation to disambiguate continuations), then a model trained à la Implicit CoT should show *no breathing* even though it solves the same task. This dovetails with H-22 (Abstract-CoT) and would refute F-1's universality framing if confirmed.
   - *Test*: replicate the public Implicit-CoT GitHub release (github.com/da03/implicit_chain_of_thought) on GPT-2 Medium / GSM8K-Aug, then run our P11 breathing-curve extraction on its hidden states across the (limited) generation steps. If the PR curve is flat or monotone vs the U-shape we see on horizontal-CoT models, F-1 needs qualification: "breathing is universal among models that verbalize their reasoning".

## Direct connections to F-N / H-N

- **H-11 (big-to-small distillation of 7B self-prediction into 1.5B)**: Implicit CoT *is* the canonical recipe for teacher → emulator KD on hidden states. The "Mind-Reading the Teacher" + "Thought Emulation" + "Couple and Optimize" three-step strategy is directly transposable: 7B teacher provides hidden-state targets, 1.5B emulator predicts them, 1.5B student answers from emulated states. The paper shows the recipe works at 96% on 5×5 multiplication for GPT-2 Medium → makes H-11's plausibility concrete. Numerical anchor: cos(prefill_DoM, final_DoM) = 0.046 — implies our 1.5B already has ~orthogonal residual subspaces that a 7B-supervised emulator could shape.
- **H-22 (Abstract-CoT compressed breathing)**: 2311.01460 is the *progenitor* of 2604.22709 (already in graph). Implicit CoT is the most extreme abstract-CoT — pure hidden-state computation, no token output. If we test breathing on Abstract-CoT (H-22) we also need an Implicit-CoT control.
- **H-2 (breathing on short CoT)**: Implicit CoT compresses long horizontal chains (50–70 tokens for 5×5 mult) into ~24 vertical layers. Provides a clean test of whether breathing scales with horizontal CoT length: if H-2 fails on Implicit-CoT-trained models, breathing is verbalization-driven.
- **F-2 (prefill DoM AUROC 0.7731)**: see refutation 3 above. The 96% answer-accuracy ceiling on multiplication implies prefill states *can* carry near-perfect correctness signal under the right training regime.
- **F-3 (cos 0.046)**: see refutation 2 above. Direct numerical anchor.
- **F-7 (D-bucket distinctive collective signature, group prefill PR 14.49)**: the paper's "Multiple Reasoning Pathways" mixture-of-Gaussians extension (Section 3.2) gives a clean framework for testing whether D-bucket problems sit at a *specific* mixture component vs being a degenerate "averaged" mode. Anchor: D-bucket's PR=14.49 vs A-bucket's higher PR → analogous to the paper's example where averaging "30 books" and "25 books" pathways yields no valid solution.
- **F-9 (CoE-60 redundancy)**: see refutation 1 above. Direct conflict on whether multi-layer trajectory carries non-redundant info.

## Methodologies extracted

- **Diagonal hidden-state extraction `z_{l, t_l}`** — from the L×T teacher hidden-state matrix (L layers, T intermediate tokens), select one vector per layer along an evenly-spaced diagonal `t_l = ⌊1 + ∆(l−1)⌋, ∆ = (T−1)/(L−1)`. Section 3.1 shows diagonal beats first-column (29.9%), top row (84.4%), bottom row (57.6%) on 4×4 mult validation.
  *Replication cost*: 4h CPU on cached P11 H100 prefill activations (28 layers × tokens per problem); no model re-extraction needed.
  *We'd plausibly run this*: **yes** — directly tests F-9 on our setting.

- **Hidden-state normalization** — apply layer-norm without trainable params (zero-mean, unit-std) to each teacher vector before substitution. Footnote 5: "We found that hidden states from higher layers tend to have larger norms."
  *Replication cost*: 5min — single normalization step.
  *We'd plausibly run this*: yes — should re-check our DoM direction extraction protocol; if we don't normalize, layer-19 DoM might be norm-confounded.

- **Variable-length ∆ search** — paper sweeps ∆ ∈ {fixed values, dynamic `(T−1)/(L−1)`} on validation to handle variable-length CoTs.
  *Replication cost*: cheap — wraps around any diagonal probe.
  *We'd plausibly run this*: yes — for any per-problem trajectory feature.

- **Mixture-of-Gaussians teacher-state predictor with categorical token supervision** — to handle multi-modal reasoning paths, predict `P(ẑ_l) = Σ_c P(ẑ_l|c)P(c)` with each component Gaussian `N(f(h_l, c_l), 1)` and supervise the mixture index `c_l` to be the actual intermediate token at position `t_l`. Loss: `Σ ‖z_l − f(h_l, c_l)‖² / 2 − log P(c_l = z_{t_l})` (Eq. 2). Without mixture: 11.2% on GSM8K-Aug; with mixture: 20.2%.
  *Replication cost*: ~1 week H100 — needs custom pipeline + intermediate-token labeling.
  *We'd plausibly run this*: maybe — only if we ever want to model "the model has multiple reasoning pathways for the same problem", which is exactly the F-7 D-bucket question.

- **LSTM-with-self-attention emulator architecture** — for predicting the L vertical hidden states from input. Section 4.3.
  *Replication cost*: standard PyTorch.
  *We'd plausibly run this*: yes for H-11 (KD).

- **Couple-and-Optimize end-to-end finetune with low-temperature softmax for differentiable argmax** — temperature 0.05 for the mixture. On GSM8K-Aug GPT-2 Medium ∆=1: without optimize 9.4%, with optimize 21.9%; with emulator frozen 13.0%.
  *Replication cost*: small.
  *We'd plausibly run this*: yes.

- **Trainable one-layer MLP on top of teacher states before copying** — small adapter so the student doesn't need to consume raw teacher states. Section 4.3.
  *Replication cost*: trivial.
  *We'd plausibly run this*: yes for H-11.

- **GPT-4 data augmentation pipeline** — generated 400k additional GSM8K-format problems (GSM8K-Aug, 7k → 378k) with original test set unchanged.
  *Replication cost*: $50–100 OpenAI credits + cleanup.
  *We'd plausibly run this*: no — MATH-500 is the canonical bench; augmentation would muddy comparison.

## Approaches & framings

- **"Vertical vs horizontal" reasoning** — reframes CoT not as text generation but as "horizontal" computation across positions, contrasted with "vertical" computation across layers. Connects to our prefill/final-token orthogonality (F-3) and dimensional breathing (F-1) by suggesting both are properties of the *horizontal* mode that should be absent or different in pure-vertical computation.
- **"Teacher-teaching vs teacher-forcing"** — the student isn't forced to reproduce teacher tokens; the teacher *teaches* by exposing hidden states. Useful framing for H-11: 7B doesn't need to verbalize its CoT for 1.5B to imitate it — 1.5B can imitate the *hidden-state targets* directly.
- **Mind-Reading / Thought Emulation as separable stages** — splits "having access to teacher's reasoning" from "predicting teacher's reasoning from input alone". Maps onto F-2 / F-3: prefill DoM is the "predict-from-input" half; the gap between prefill DoM (0.7731) and final-token DoM (0.7186) tracks what the "Thought Emulator" half adds.
- **Reasoning pathways as mixture components** — each multi-step problem may admit multiple valid paths; averaging them is geometrically wrong. Direct framing for F-7 (D-bucket): D-bucket may be problems whose teacher state averages two pathways into a degenerate point.

## Implementation details worth capturing

- Models: GPT-2 Small (12 layers) and GPT-2 Medium (24 layers), pretrained, finetuned on synthetic train set.
- Diagonal extraction with first intermediate token always being a special separator token (footnote 1).
- For predicting first answer token, only the teacher state `z_{LL}` is used; lower-layer states `z_{ll}, l < L` are accessible only from the second answer token onward via attention. Workaround: prepend a special token to the answer separating reasoning and output (footnote 2).
- Hidden-state normalization is layer-norm without trainable params.
- LSTM-with-self-attention as the emulator architecture for predicting vertical hidden states.
- Linear projection on top of emulator hidden states to predict mixture component distribution.
- Concatenate `h_l` with embedding of mixture component `c_l`, then process with one-layer MLP to compute `f(h_l, c_l)`.
- Mixture used for GSM8K-Aug; **not** used for multiplication (intermediate steps unique by construction).
- Couple-and-Optimize uses softmax temperature 0.05.
- Throughput numbers (Table 3): Implicit CoT ~0.66–0.73× No-CoT speed; Explicit CoT ~0.08–0.17× — Implicit is ~5× faster than Explicit despite per-problem speedups varying.
- Code: https://github.com/da03/implicit_chain_of_thought
- Public data and pretrained models released.
