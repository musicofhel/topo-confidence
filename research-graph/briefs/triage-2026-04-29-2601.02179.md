# Triage brief — 2601.02179 — Confidence Estimation for LLMs in Multi-turn Interactions

Source: https://arxiv.org/abs/2601.02179
Triaged: 2026-04-29

## Refutations

1. **Refutes F-2 / H-12 (the L19 DoM is the strongest available correctness predictor; label-free probes are untested).**
   - *Mechanism*: P(SUFFICIENT) is a **purely logit-based, label-free** binary probe — `Pr[A | prompt, answer; "is the current information sufficient to entail this answer is the only correct one?"]`. It requires no supervised classifier, no per-layer DoM extraction, no held-out fold. On Llama3.1-70B, it hits InfoECE = 5.27 on GUESS and Kendall's τ = 86.55 against ground-truth answers. If the same prompt template, applied to a single-shot MATH-500 setting on Qwen-2.5-1.5B, reaches AUROC ≥ 0.7731 (the OOF L19 prefill DoM number from `pathway11_h100/prefill_gated_compute/results.json`), then F-2's headline claim — that supervised hidden-state probing at L19 is the load-bearing source of correctness signal — is overstated; a zero-training logit probe extracts a comparable signal.
   - *Falsifiable experiment*: append the P(SUFFICIENT) prompt template to each MATH-500 problem on Qwen-2.5-1.5B's K=1 greedy answer, compute softmax(A), evaluate AUROC vs cached `correctness` labels. Compare against 0.7731. ~30 min H100.

2. **Refutes F-3 (prefill / final-token DoM directions are orthogonal because they encode different geometric facts about the same content).**
   - *Mechanism*: the multi-turn vs single-turn-summary experiment (§5.4) shows accuracy is essentially preserved (mean |Δ| < 1) but P(SUFFICIENT) confidence collapses: Qwen2.5-7B 20Q drops 63.13 → 13.23, Llama3.1-70B 20Q drops 34.80 → 15.30. The same content presented in different prompt structure produces wildly different confidence with the same answer correctness. If hidden-state-derived confidence (DoM) shares this property, then F-3's "orthogonality of prefill and final-token DoM" may be re-explained as **two different prompt-structure encodings of the same correctness fact** rather than as two semantically distinct representations of input vs output. The cos = 0.046 number could survive while the underlying interpretation flips.
   - *Falsifiable experiment*: rerun the 1024-tok extraction with a "summary" reformulation of each MATH-500 problem (e.g. paraphrase + remove the standard prompt scaffolding). If prefill DoM stays approximately constant under reformulation but P(SUFFICIENT)-style logit probes change radically, F-3's geometric story holds. If both move together, prefill DoM is largely a prompt-structure artifact.

3. **Refutes H-12 specifically (semantic-entropy / label-free probes can replace supervised DoM for refusal). The paper actively contradicts the framing — but in our favour, in a way that should be taken as a refutation of the *implicit* assumption that a logit probe like P(TRUE) cleanly captures what supervised hidden-state probing captures.**
   - *Mechanism*: §5.3 (Table 3, placebo experiment) shows P(TRUE) **rises under uninformative placebo hints** on GUESS — Llama3.1-8B + 11.75 (p < 10⁻¹²), Qwen2.5-72B + 14.61 (p < 10⁻⁶). P(TRUE) is confounded by turn count / prompt length, not just by information. If the L19 prefill DoM signal is in part a length-position-context confound (and Kadavath-style P(TRUE) is its closest single-token analogue), then F-2's AUROC = 0.7731 may inherit the same confound and be inflated relative to what a length-controlled experiment would show.
   - *Falsifiable experiment*: subset MATH-500 prompts to a tight prompt-length band (e.g. 800–1024 tok within the 1024-tok regime), recompute prefill L19 DoM AUROC on length-matched correct vs incorrect pairs. If AUROC drops materially (say below 0.74), F-2 is partly a length confound; if it holds, F-2's signal is content-driven.

4. **Refutes F-8 (selective prediction at 50% coverage achieves 71.6% answered accuracy — and is the right operating point).**
   - *Mechanism*: P(SUFFICIENT) on Llama3.1-70B GUESS achieves InfoECE = 5.27 with τ-on-current-answer = 60.85 → near-monotone confidence. If the multi-turn evaluation framework is recast for math (each "turn" = one CoT step or a partial draft of length k), the same probe could yield calibrated *step-wise* abstention, which dominates the single-shot 50%-coverage operating point of F-8 (e.g. abstain at step k vs commit at k=K). Falsifiable by running multi-turn P(SUFFICIENT) on partial-CoT slices of MATH-500 and comparing the selective-accuracy curve against F-8's 71.6% @ 50%.

## Direct connections to F-N / H-N

- **F-2** (prefill L19 DoM AUROC = 0.7731, OOF 5-fold) ↔ this paper's **P(SUFFICIENT)** is a label-free, logit-only correctness predictor in the same problem class (predict-correctness-of-an-answer). Direct head-to-head comparator.
- **F-8** (selective prediction at coverage 0.5 → 71.6% answered accuracy, K=2.5) ↔ paper's per-turn calibration framework (InfoECE, Kendall τ) is the multi-turn analogue of selective prediction; both rely on calibrated confidence + a coverage knob.
- **H-12** (semantic-entropy / label-free probes replace supervised DoM) ↔ this paper's P(SUFFICIENT) is essentially the strongest contender to date for label-free probing — InfoECE 5.27 on Llama3.1-70B GUESS is a calibration win, not just a ranking win.
- **H-1** (per-position DoM steering) — weaker connection: paper does no steering, but its placebo experiment is a clean ablation template the H-1 design should imitate (insert a no-information turn, measure ΔAUROC, ΔAccuracy).

## Methodologies extracted

- **P(SUFFICIENT) probe** — append template "is the current information sufficient to entail that `<answer>` is the only correct answer? (A) True (B) False" to the prompt, force single-token uppercase output, take softmax(A) as confidence. Replicable on any HF causal-LM with logit access.
  *Replication cost*: 30 min H100 on cached MATH-500 prompts (one extra forward pass per problem with the binary probe template appended). No training, no labels needed.
  *We'd plausibly run this*: **yes** — direct comparator to F-2's L19 DoM AUROC, and the closest existing implementation of H-12.

- **InfoECE (length-normalized ECE)** — bin (d,i) pairs by `s_{d,i} = i/L_d` into B equal-width or equal-mass bins; standard ECE per bin; average. Replicable from any per-step (correctness, confidence) trace.
  *Replication cost*: 20 min CPU.
  *We'd plausibly run this*: **maybe** — most useful only when we go multi-turn (currently single-turn MATH-500), but trivially adaptable to per-CoT-step traces.

- **Kendall's τ for monotonicity over turns** — concordant minus discordant pair fraction over confidence sequence within each dialogue, averaged across dialogues. Captures "does confidence rise as evidence accumulates."
  *Replication cost*: 20 min CPU.
  *We'd plausibly run this*: **yes** — adaptable as a partial-CoT monotonicity metric (does confidence rise as the model writes more of the proof?).

- **Hinter–Guesser dataset construction** — LLM A holds a secret, LLM B guesses + flags uniqueness, dialogue continues until correct + unique; only successful trajectories retained.
  *Replication cost*: significant (per-paper ~thousand dialogues, 70B-tier model).
  *We'd plausibly run this*: **no** — too far from MATH-500 / hidden-state pipeline to justify the build cost.

- **Placebo-turn ablation** — replace an informative turn with a content-free filler (e.g. "Q: Is this a valid hint? A: Yes."), compute Δconfidence. Distinguishes information-tracking from turn-count artifact.
  *Replication cost*: 30 min H100 (one extra forward pass per problem with a known-uninformative prefix appended).
  *We'd plausibly run this*: **yes** — drop-in length-confound test for F-2 / F-3 / F-8 (does prefill DoM rise just because the prompt is longer?).

- **Multi-turn vs single-turn-summary control** — same evidence, two presentations; compare both accuracy and confidence. Decouples content from prompt structure.
  *Replication cost*: 30 min H100.
  *We'd plausibly run this*: **yes** — direct test for F-3's "prefill structure vs content" interpretation (refutation #2).

## Approaches & framings

- **"Confidence as identifiability" rather than "confidence as correctness"** — P(SUFFICIENT) explicitly disentangles "my current guess is correct" from "the evidence makes the correct answer uniquely determinable." This is a useful lens for our D-bucket / B-bucket distinction in F-7: a model that gets K=1 right but K=8 wrong is one whose evidence is *insufficient* for identifiability even though one sample landed correctly.
- **Joint desiderata: per-turn calibration + monotonicity** — the framing that confidence over an interaction must be both well-calibrated *and* non-decreasing as evidence accumulates. F-8's selective-prediction is implicitly the static special case (one turn, one threshold). Adopting both desiderata would tighten claims about F-8 — currently we report accuracy@coverage but not calibration of the underlying scores.
- **"Logit probes ≠ hidden-state probes"** — P(TRUE) (logit-based) is shown to be confounded by length where SC and P(SUFFICIENT) are not. This is a cautionary frame for our work: a logit-probe baseline (Kadavath) is *not* a substitute for, nor a clean upper bound on, supervised DoM probing — they fail on different axes.

- **20Q (this paper, Hinter–Guesser variant)** — 1,848 turns / 226 entities. License: code+data released on github.com/caiqizh/multi-turn-conf. Accessibility: public. Applicable? **no** — open-domain entity guessing, not math/CoT-style reasoning.
- **GUESS / Guess-my-City (this paper, Hinter–Guesser variant of Abdulhai et al. 2023)** — 1,625 turns / 223 entities. Public. Applicable? **no** — same reason.

- **TRICKME (Wallace et al. 2019, quizbowl)** — adversarial QA. Public. Applicable? **no** — same.

The paper's data is structurally a poor match for the 1024-tok MATH-500 / hidden-state pipeline. The methods, however, transfer; the datasets do not.

## Implementation details worth capturing

- Models: Llama3.1-8B/70B-Instruct, Qwen2.5-7B/72B-Instruct. Temperature 1 for sampling, 0 otherwise. Self-Consistency uses m = 20 samples.
- P(TRUE) and P(SUFFICIENT) prompts force single-token uppercase output; confidence = softmax probability of "A". Exact prompt templates in Appendix A.
- Code/data: https://github.com/caiqizh/multi-turn-conf
- For InfoECE: bin into B bins along the normalized turn axis s = i/L_d; either equal-width or equal-mass. Default equal-width is implicit in their figures.
- "Placebo" turns are constructed as `Q: Is this a valid hint? A: Yes.` — minimal-info filler that preserves dialogue structure without injecting new content.

## Replicable intermediates

- **P(SUFFICIENT) AUROC on cached MATH-500 (1024-tok regime)**: pull the 500 K=1 prompts from `pathway11_h100/prefill_gated_compute/`, append the binary "is this answer the only correct one?" template, run one forward pass on Qwen-2.5-1.5B, compute softmax(A), correlate with cached correctness labels → AUROC. Compare directly to F-2's 0.7731. Script lives in `pathway11_h100/`; reuse the existing prompt-loading utilities. ~30 min H100.
- **Kendall τ over partial-CoT slices**: take the K=1 generation per problem from the same cache, slice at 25/50/75/100% of generation length, run P(SUFFICIENT) at each slice, compute τ per problem and mean. Tests whether confidence rises monotonically as the proof unfolds — a multi-turn-style sanity check on existing single-turn data. ~1 h H100.
- **Placebo-prefix ablation on prefill L19 DoM**: prepend the placebo string `"<irrelevant filler> "` to each MATH-500 prompt (length-matched padding), recompute L19 prefill DoM AUROC. If AUROC stays at 0.7731 ± noise, F-2 is content-driven; if it shifts materially, F-2 has a length confound that mirrors P(TRUE)'s. ~1 h H100.

## Proposed PAPER_INDEX.md classification

## 2601.02179 — Confidence Estimation for LLMs in Multi-turn Interactions (Zhang, Yang, Zhu, Li, Hu, Dong, Yang, Collier — Cambridge / Fudan, 2026)

**Relevance:** First systematic study of confidence estimation across multi-turn dialogues. Methodologically, the paper is the closest existing implementation of the H-12 program ("label-free probe can replace supervised DoM for correctness prediction"): their P(SUFFICIENT) is a binary logit probe — `Pr[A | "is the current information sufficient to entail this answer is the only correct one?"]` — that beats verbalized confidence, self-consistency (m=20), and Kadavath-style P(TRUE) on calibration in two of four datasets, with InfoECE = 5.27 on Llama3.1-70B GUESS (vs typical 40–80 for verbalized methods). The paper also documents that P(TRUE) — the closest existing logit-probe analogue to F-2's hidden-state DoM signal — suffers a length / turn-count confound (placebo lifts up to +14.61, p < 10⁻⁶), suggesting the supervised L19 DoM AUROC = 0.7731 may inherit a similar artifact. Datasets (20Q, GUESS, GRACE, TRICKME) are open-domain QA and not directly applicable to the MATH-500 / 1024-tok regime, but the method (P(SUFFICIENT)) and the controls (InfoECE, Kendall τ, placebo turn ablation) all transfer cleanly to the existing P11 cache.

**Key claim we tested:** A purely logit-based, training-free probe ("is the evidence sufficient to uniquely entail this answer?") can match or exceed the calibration of supervised hidden-state probes for correctness/identifiability prediction.

**Our result:** **TO TEST** — H-72 (P(SUFFICIENT) on MATH-500 vs F-2's L19 DoM, ~30 min H100) and H-73 (placebo-prefix length confound on prefill DoM, ~1 h H100) are the two refutation-grade tests. P11-FE72/FE73/FE74 instantiate them.

**Related experiments:** P11-FE72, P11-FE73, P11-FE74; H-72, H-73; F-2, F-3, F-8; H-12.

**Status:** TO TEST
