# Triage brief — 2605.26713 — Transformers Can Learn Posterior Predictive Distributions In-Context

Source: https://arxiv.org/abs/2605.26713
Triaged: 2026-06-14

> **Read note.** Full paper text (155.7 KB markdown, incl. appendices/proofs) read in chunks
> via the converted arxiv file. Theory paper (stat.ML/cs.LG, ICML 2026): PFNs / GP-regression,
> a constructive proof that transformer self-attention implements an iterative (Richardson/GD)
> solver for the GP posterior predictive **mean and variance**, an MLP head that maps those
> moments to a **binned (piecewise-constant) predictive density**, error bounds in attention
> depth `L` and bin width `|Γ|`, and a spectral analysis showing attention *normalization* is
> what enables generalization beyond the pretraining context size (`n`-generalization).
> It is **off-core** for topo-confidence (no reasoning-correctness, no residual-stream geometry,
> no MATH). Refutations below are abstract method-transfer arguments, not direct hits.

## Refutations

1. **Against H-957 (a test-time spectral-radius / convergence-rate statistic is the dynamical
   quantity the L19 prefill DoM reads out).** The paper's central mechanism is that the in-context
   solver's error contracts as `exp(−η(λ_n(G)+σ²)L)` — the relevant convergence rate is governed by
   the eigenvalues of the **Gram/kernel matrix `G` over samples** (an `n×n`, sample-by-sample
   object), *and* by attention **normalization** (Theorem 5.1): without normalization the solver
   diverges outside the pretraining range. H-957/the cov-spectrum probe (FE881, 0.7928) read the
   spectrum of the **feature covariance** (a `1536×1536`, dim-by-dim object) of static L19
   activations. If the convergence rate that actually carries correctness signal lives in the
   *normalized attention-score / sample-Gram* spectrum, then a static feature-covariance readout is
   measuring the wrong matrix and H-957's mechanism is misattributed. *Mechanism:* convergence rate
   set by `λ(G_sample)` not `λ(Σ_feature)`. *Falsifiable:* build the `500×500` sample-Gram of cached
   L19 prefill activations, extract its eigenvalue-spread features, and test whether they beat the
   feature-cov-spectrum 0.7928 (FE881) — if Gram-spectrum ≫ cov-spectrum, H-957 reframes.

2. **Against F-9 (CoE-60 trajectory features are redundant with single-layer L19 DoM) and the
   single-layer F-2 ceiling (0.7731).** The paper proves PPD approximation error decreases
   *monotonically with depth* `L` (Theorem 3.1/4.1, Figure 2): quality is an iterative refinement
   distributed across layers, not concentrated in one. If correctness signal is the trajectory's
   *contraction rate* across layers (how fast the residual converges to its fixed point), then a
   single-layer L19 snapshot must be strictly dominated by an across-layer convergence-rate feature
   — contradicting F-9's "single layer captures it all." *Mechanism:* depth-distributed iterative
   refinement vs single-layer readout. *Falsifiable:* compute a per-sample across-layer contraction
   rate from cached multi-layer activations and test whether it exceeds 0.7731 / makes CoE-60
   non-redundant.

3. **Against F-8 (selective prediction via prefill DoM, 71.6% answered acc @ 50% coverage).** The
   paper's whole point is that a transformer head can emit a **calibrated full predictive
   distribution** (binned PPD with near-nominal coverage, Figure 1) rather than a point statistic.
   F-8's selective rule thresholds a single supervised-DoM scalar — a point-estimate proxy. If a
   binned/Riemann-distribution head over L19 features yields a better-calibrated correctness
   distribution, the DoM-threshold selective rule is sub-optimal at matched coverage. *Mechanism:*
   distributional (binned-density) confidence vs scalar-threshold confidence. *Falsifiable:* train a
   small piecewise-constant ("Riemann") head on cached L19 features predicting a binned confidence,
   compare ECE and answered-accuracy@coverage against F-8's DoM rule.

4. **(Extra) Against H-959 (looped recurrence reproduces STARS's peak-then-collapse curve; peak-depth
   stability proxy beats static DoM) and H-958 (asymmetric collapse = fixed-point convergence vs
   divergence).** With attention normalization, the paper's iterative solver converges *monotonically*
   with depth — no peak-then-collapse — and divergence is exactly the *unnormalized* failure mode.
   If Qwen's normalized residual trajectory is a well-conditioned iterative solver, the
   peak-then-collapse curve H-959 predicts should be absent (monotone instead), and H-958's
   "incorrect = divergence" story would require an *unnormalized* regime that LayerNorm/RMSNorm
   removes. *Mechanism:* normalization ⇒ monotone contraction, no peak. *Falsifiable:* check
   monotonicity-in-depth of the DoM-readable quantity on cached per-layer activations.

## Direct connections to F-N / H-N

- **H-957 / FE881 cov-spectrum probe (AUROC 0.7928, PC1-residualized top-20 log-eigvals).** The
  paper makes "eigenvalue spectrum governs approximation/convergence quality" a *theorem*, but over
  the sample-Gram `G`, not the feature covariance. Direct methodological adjacency: both reduce a
  matrix to its spectrum to predict quality; the paper says *which* matrix matters and that
  normalization gates it.
- **F-2 single L19 prefill direction, AUROC 0.7731** and **F-9 (CoE-60 redundant with single-layer
  DoM).** The depth-monotone error-decrease theorem is the cleanest external argument that a
  multi-layer trajectory feature *should* beat a single-layer readout — directly in tension with the
  0.7731 single-layer ceiling and F-9's redundancy claim.
- **F-8 selective prediction (71.6% @ 0.5 coverage, K=2.5 avg).** The binned-PPD / calibrated-coverage
  framing is an alternative confidence-head design competing with the scalar DoM threshold.
- **H-958 / F-4 asymmetric collapse** and **H-959 looped recurrence.** The paper's
  monotone-contraction-under-normalization result is a direct, testable counter-prediction to the
  peak-then-collapse and "incorrect = divergence" dynamics framings.

## Methodologies extracted

- **In-context iterative (Richardson / preconditioned-GD) solver readout** — treat the L-layer stack
  as an iterative solver and measure its per-sample contraction rate / fixed-point residual across
  layers. *Replication cost*: 20–40min CPU on cached multi-layer activations (if cached; L19-only
  cache insufficient). *We'd plausibly run this*: yes — directly feeds H-957/H-958/H-959 and the
  trajectory-vs-single-layer question.
- **Sample-Gram eigenvalue-spread feature** — eigen-decompose the `n×n` Gram of cached activations
  (vs the `d×d` feature covariance the project already uses) and use the spectrum (`λ_max/λ_min`,
  log-eigvals) as a probe. *Replication cost*: ~10min CPU on the cached `500×1536` matrix.
  *We'd plausibly run this*: yes — cheapest direct cross-check against FE881's 0.7928.
- **Binned / piecewise-constant ("Riemann") predictive-density head** — MLP head mapping features to
  `C` bin logits → softmax → piecewise-constant density, trained with truncated NLL; gives calibrated
  coverage. *Replication cost*: ~20min CPU to train on cached L19 features. *We'd plausibly run this*:
  yes — alternative confidence head for F-8.
- **Total-variation distance for distributional approximation error** — `TV(p_n, q*) = O(|Γ|)+ε` bin-
  width error decomposition. *Replication cost*: trivial (a metric). *We'd plausibly run this*: maybe
  — only if we adopt a distributional confidence head.
- **Attention-score-matrix spectral / normalization analysis** — eigenvalues of the (normalized)
  attention score matrix as the generalization gate. *Replication cost*: needs attention maps →
  fresh forward pass (H100) or cached attention. *We'd plausibly run this*: no for now — out of the
  static-activation budget.

## Approaches & framings

- **"ICL = iterative GD/Richardson solver in the forward pass."** Reframes the residual trajectory as
  optimization dynamics with a quantifiable contraction rate; intersects H-957/H-958/H-959 squarely
  and supplies the formal vocabulary (convergence rate, fixed point, conditioning) those hypotheses
  are reaching for informally.
- **"Distributional (PPD) vs point prediction."** Reframes correctness estimation as emitting a
  *distribution* (binned density with coverage guarantees) rather than a scalar AUROC threshold;
  intersects F-8 and any conformal/calibration hypothesis.
- **"Normalization is the generalization gate."** Spectral argument that attention normalization is
  what keeps the solver stable beyond the training regime; a lens on why LayerNorm/RMSNorm geometry
  (the project's "breathing", F-1/F-5) might matter for stable readouts rather than being incidental.

## Implementation details worth capturing

- Architecture for the proofs: `L` masked self-attention blocks `Z^{(l+1)} = Z^{(l)} + S^{(l)}Z^{(l)}
  + Attn(...)` (residual + learnable skip + attention) followed by an MLP head emitting `C` bin
  logits; token = `[xᵀ, y]`, query token has masked label.
- Convergence requires step size `η^{(l)} < 2/(λ₁(G)+σ²)` with `Σ η^{(l)} = ∞`; error contracts as
  `exp(−η(λ_n(G)+σ²)L)`.
- Output discretization: partition `Γ = {γ₁<…<γ_{C+1}}` of `(a,b]` with tail mass `ε`; bin-width
  error `O(|Γ|)` in TV.
- LayerNorm / multi-head / embeddings treated as expressivity refinements, not needed for the core
  construction — useful caveat: their proofs are single-head, LN-free.
- No public code link surfaced in the text; experiments are simulations (Figures 2,4,5,10) plus the
  Sacramento illustration.

## 2605.26713 — Transformers Can Learn Posterior Predictive Distributions In-Context (Kang, Lee, Cheng, 2026)

(Richardson/preconditioned-GD) solver for the posterior-predictive mean *and variance*, that an MLP

calibrated confidence design competing with F-8's scalar DoM threshold.
