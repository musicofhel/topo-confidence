# Triage brief — 1802.04443 — On Characterizing the Capacity of Neural Networks using Algebraic Topology

Source: https://arxiv.org/abs/1802.04443
Triaged: 2026-04-29

## Refutations

1. **F-10's null might be testing the wrong space.** Guss & Salakhutdinov apply persistent homology to the *input data* and to the *support of the positive decision region of a trained classifier*, **not** to the trained residual stream cloud aggregated across all examples. F-10 ran PH on the latter and got a Gaussian null. The paper's framework would predict that the relevant non-trivial homology lives in `H(X^+_correct) ⊂ L19 prefill cloud` vs `H(X^-_incorrect)` — i.e. *per-class supports* of the correctness label, not the unlabelled cloud. **Falsifiable experiment:** Re-run giotto-tda on the L19 prefill activations from `pathway11_h100/prefill_gated_compute/`, splitting by correct/incorrect MATH-500 labels and computing β₀ and β₁ separately for each class support against matched-rank Gaussian baselines. If either class support has β_p ≠ Gaussian null, F-10's "PH is null on residual streams" statement needs scoping to "null on the *unlabelled aggregate* cloud."

2. **F-2's AUROC 0.7731 ceiling could be a topological-expressivity ceiling, not a noise ceiling.** The prefill DoM probe is a linear projection on R^d (a single hyperplane), so by construction its support homology is `H_S(DoM) = (Z, 0, 0, ...)` — one half-space, zero loops. Theorem 3.1 of the paper says: if `H_S(f) ≠ H(X^+)` then there exists a non-empty `A ⊂ X^+` that f misclassifies *for every f in the family*. **Mechanism by which refutation fires:** if the correct-answer support in the L19 prefill cloud has β₀ > 1 (multiple disjoint clusters of "correct" — e.g. one for arithmetic, one for algebra, one for geometry) or β₁ > 0 (a hole — e.g. an annular region of difficulty), no linear probe can match its homology, and a fixed misclassification subset exists. The 22.69 percentage-point AUROC gap from perfect could be exactly that subset. **Falsifiable experiment:** fit a 2-layer MLP probe on the same L19 features and the same 5-fold OOF split. The paper predicts a *topological phase transition* — a discontinuous AUROC jump at h_phase, not a smooth ceiling. If MLP at h₀ ∈ {2,4,8,16,32,64,128} all converges to AUROC ≈ 0.77, the topological-ceiling story is refuted (the gap is noise/Bayes-irreducible, not capacity).

3. **F-7 D-bucket fragility could be a β₁ artifact of the probe, not a property of the model.** F-7 says D-bucket has a distinctive *collective* geometric signature. The paper's Theorem 3.1 + the depth-dependent capacity bound `max β₀(f) ∈ Ω(h^ℓ)` predicts that linear probes (ℓ=1, β₀≤2) cannot distinguish a class with disconnected support; D-bucket items might form a small connected component in the L19 prefill cloud that is topologically separated from the main "correct" mass. **Falsifiable experiment:** compute β₀ on the L19 prefill activation cloud restricted to the 36 D-bucket items vs the 243 correct items; if D-bucket sits in its own persistence-barcode connected component (lifespan > 2σ) that is *not* contained in the correct-mass component, F-7 has a topological mechanism. If the D-bucket points are interleaved with correct-mass points in the persistence diagram, F-7 fragility is something else (sampling temperature, RoPE rotation, etc).

## Direct connections to F-N / H-N

- **F-10 (PH on residual streams = Gaussian null, AUROC 0.7731 reference; EXP-026 PH-under-null):** This paper *is* the foundational reference for PH-on-NN-data, and our F-10 result was framed as refuting the broader topological-capacity program. The paper does not actually study residual stream clouds — it studies decision-region homology and input-data homology. So F-10 should be reframed: it kills *one specific instantiation* (PH on aggregate trained activations) of the broader Guss/Salakhutdinov framework, but leaves intact the version that operates on labelled class supports.

- **F-2 (Prefill L19 DoM AUROC 0.7731 OOF 5-fold):** Theorem 3.1 implies a structural reason for any AUROC < 1.0 ceiling on a linear probe: support-homology mismatch. Provides falsifiable mechanism for the 22.69 pp gap.

- **F-7 (D-bucket distinctive collective geometric signature):** β₀-on-class-support test is a direct, cheap probe for whether D-bucket is a topologically isolated component vs an interleaved subset.

- **H-7 (density-based outlier detection finds D-bucket):** Persistent homology with lifespan > 2σ filtering is a *topology*-based outlier detector for the same target — natural complement / contrast with H-7's density-based approach.

- **H-16 (Marchenko-Pastur bias correction preserves breathing magnitude; from 2509.26560):** The PH-on-class-supports test would benefit from the same finite-sample bias-correction philosophy — if β₀ counts are inflated by sample size, we get spurious "topology" the same way we get spurious dimensionality. Worth coupling.

## Methodologies extracted

- **Persistent homology on point clouds via Vietoris–Rips filtration** — grow ε-balls around each point, track when β_p features (connected components, loops, voids) are born and die. Authors used Dionysus; we'd use giotto-tda or ripser.
  *Replication cost*: 5–10 min CPU for 1000-point clouds at d=R³; scales as O(N²) in samples and explodes in ambient dimension.
  *We'd plausibly run this*: **yes** — direct test of refutation #1, on cached L19 prefill cloud.

- **LLE embedding to R³ before PH** (K=120 neighbors) — necessary preconditioning for high-D point clouds (CIFAR was 3072→3, here L19 is 1536→3).
  *Replication cost*: ~20 min CPU on 500–1000 sample MATH-500 prefill cloud.
  *We'd plausibly run this*: **yes** — but with care, since LLE distorts large-scale geometry; UMAP+ripser is the modern stack.

- **Persistence barcode lifespan filtering (>2σ from mean)** — well-defined statistical test for topological-feature significance; authors use it on OpenML/UCI.
  *Replication cost*: ~free given a persistence diagram.
  *We'd plausibly run this*: **yes** — needed to separate signal from noise on real data.

- **Topological phase-transition analysis** — sweep h ∈ {1,...,500} hidden units, plot min-error vs h, look for discontinuity at h_phase. Indicates a homology-expression threshold.
  *Replication cost*: ~2 h CPU sweep over MLP probe widths on cached features.
  *We'd plausibly run this*: **yes** — sharpens H-7 / H-19 capacity estimates.

- **Empirical h_phase regression** `ĥ_phase(β₀, β₁) ≥ β₁ · ℓ√β₀ + 2` — multilinear fit predicting minimum hidden units from input-data homology.
  *Replication cost*: needs h_phase calibration on known-homology synthetic mixtures, which we'd have to generate.
  *We'd plausibly run this*: **no** — too speculative for our regime; the formula was fit on 2D synthetic and doesn't claim to extrapolate to LLM hidden-state geometry.

- **Decision-region homology via Heaviside-step filtration on output difference** — compute persistence diagram of `f⁻¹((0,∞))` directly to characterize what the trained network expresses.
  *Replication cost*: needs decision boundary access; for our DoM probe it's trivial (a hyperplane).
  *We'd plausibly run this*: **no** — DoM's support homology is known a priori (one half-space), so this method is degenerate for our current probe; only useful if we move to non-linear probes.

## Approaches & framings

- **Data-first architecture selection** — flip the architecture-search question: instead of asking "which network maximizes accuracy on dataset D?", ask "what is H(D), and what's the smallest architecture whose `H_S(f)` family can express it?". For us this maps to: probe-complexity selection (linear vs MLP-1 vs MLP-2 over L19) should be driven by `H(X⁺_correct)` of the prefill cloud, not by grid search.

- **Topological phase transition as a learning concept** — error vs hidden-units shows a *discontinuity* at h_phase, not a smooth curve. If true for our probe, "linear is enough" (HYPOTHESES historical: XGBoost over ABC-44 killed) needs to be re-examined: did we sit *below* h_phase, get a flat null, and conclude "signal is linear"?

- **Topological vs differential-geometric duality** — paper notes (with Poole et al. 2016 / Bianchini et al. 2014) that exponential differential expressivity allows networks to "bypass homological constraints at the cost of adversarial sets." Frames the trade-off: deep nets hide topology mismatch in adversarial vulnerability rather than in classification error. Relevant to H-1 (DoM steering) — if steering exploits a differential-geometric workaround for an underlying topological mismatch, it should be brittle to adversarial input perturbation.

## Implementation details worth capturing

- Dionysus Python library is the original; giotto-tda or ripser are modern alternatives.
- Vietoris–Rips complex on N=1000 points → 20.8M simplices, 4.3 min generation + 8.4 min PH on i7 single-thread (2018 numbers).
- LLE preprocessing: K=120 neighbors, target d=3; documented to "roughly preserve" homology of small-error embeddings (Theorem 2.2 reference).
- Lifespan filter threshold: 2σ above mean lifespan, per homological dimension separately.
- Adam, lr=0.01, increasing-batch-size schedule (Smith et al. 2017) — standard.
- N=100 random initializations per architecture for the probability tables (Figure 6).
- Width sweep h₀ ∈ {1, 3, ..., 99} odd values, depth ℓ ∈ {1,2,3,4}.
- No code repo found in the paper; reference implementation must be reconstructed.
