# Triage brief — 2402.00865 — Towards Optimal Feature-Shaping Methods for Out-of-Distribution Detection

Source: https://arxiv.org/abs/2402.00865
Triaged: 2026-04-29

## Refutations

1. **Simple ID-only feature shaping might match the supervised L19 DoM probe (refutes F-2's "supervised labels needed for AUROC 0.7731").**
   Mechanism: Zhao et al. derive a closed-form, OOD-label-free shaping vector
   `θ* = sqrt(K)/||E[I(z)]|| · E[I(z)]` from ID activations alone, where I(z) is the
   Interval-Specific Feature Impact (per-interval contribution to the max-logit).
   Applied to Qwen-2.5-1.5B prefill L19 representations, this yields a *label-free*
   correctness scorer that uses only the model's own logit-weight vector and ID statistics.
   F-2's central claim is that an OOD-fit (i.e., label-supervised) DoM direction beats
   the final-token DoM at AUROC 0.7731. If the closed-form ISFI vector — fit on no
   correctness labels at all — reaches AUROC ≥ 0.74 on the same fold split, the
   "supervised contrast" framing collapses to "any reasonable rescaling of penultimate
   features works."
   Falsifiable by: extract Qwen L19 prefill features on the cached
   `pathway11_h100/prefill_gated_compute` activations, build ISFI bins (K=100) using
   the unembedding `W_U` row for the actual answer token as `w^max`, compute θ* via
   Eq. 14, score test fold, compare AUROC against the 0.7731 OOF probe number.

2. **The "K=10 intervals captures most of the gain" finding refutes H-7's premise that density-based outlier detection adds value over simple percentile thresholding.**
   Mechanism: Section 4.2 shows OOD-detection AUC plateaus by K≤10 — i.e., the optimal
   shaping function is essentially "clip and rescale at ~10 percentile bins of feature
   value." H-7 proposes density-based outlier detection (Local Outlier Factor,
   isolation forest) on prefill activations to identify D-bucket. Zhao et al.'s K-curve
   suggests that *any* dense estimator is doing fundamentally the same thing as a
   coarse 10-bin histogram clip — with much higher cost. Specifically, if D-bucket
   problems concentrate in extreme tails of L19 activations (F-7's "collective"
   geometric signature), then a one-shot 0.1/99.9 percentile clip from training-set
   ID statistics should isolate them at parity with LOF.
   Falsifiable by: run 10-bin ISFI clipping (no training, no labels) against the 36
   D-bucket vs 207 A-bucket prefill activations from `pathway11_h100`. If the AUROC
   matches Pareto-frontier of LOF/IsolationForest within ±0.02, density estimators
   are computational waste.

3. **The "feature-shaping helps on ImageNet but is ineffective on CIFAR" architecture/scale dependence refutes F-1's claim of universality.**
   Mechanism: Table 2 shows feature-shaping methods *underperform* baselines on
   CIFAR10/100 even when the same methods dominate on ImageNet-1k. The mechanism
   they propose (intervals are too narrow when feature diversity is low) is
   structurally analogous to "small models / short reasoning chains have insufficient
   activation diversity to surface a stable DoM direction." If the prefill L19 DoM
   that scores 0.7731 on Qwen-2.5-1.5B MATH-500 falls to chance on (a) shorter
   prompts or (b) smaller models like Qwen-0.5B, then F-1's "dimensional breathing
   is universal across architectures and scales" is overclaimed: it's universal
   *given enough scale and context*, with a sharp threshold below which the geometry
   degenerates.
   Falsifiable by: re-extract prefill L19 on Qwen-0.5B (or Qwen-2.5-0.5B-Instruct)
   on MATH-500 and recompute the DoM AUROC. If AUROC drops below ~0.6, F-1 needs a
   "scale-thresholded" qualifier.

## Direct connections to F-N / H-N

- **F-2 (Prefill L19 DoM AUROC 0.7731 on Qwen-1.5B):** Zhao et al.'s ISFI machinery is
  a *label-free* alternative to fitting a logistic probe; if it reaches comparable
  AUROC, the "supervised" contrast in F-2 is decorative. The maximum logit is
  computed from `W_U @ z` — exactly the operation that defines the unembedded
  next-token distribution at L19 (with intermediate norm/projection).
- **F-7 (D-bucket distinctive collective signature) + H-7 (density-based outlier
  detection):** Zhao et al.'s closed-form θ* via ISFI provides a baseline (no
  training, no hyperparameters beyond K) that H-7 must beat to justify density
  estimators. Their K-curve (Fig. 4c, K≤10 captures most gain) is a strong prior
  that H-7's gains will be modest.
- **F-8 (selective prediction at 50% coverage = 71.6% acc):** Their Energy-score +
  feature-shaping construction is structurally identical to "use shaped logit
  confidence as the abstain score." Their numbers (FPR95 ~ 40 on ResNet50,
  AUC ~ 88) suggest a 1.0× rescaling baseline before any learned probe is even
  considered — F-8's 71.6% should be benchmarked against a vanilla MLS+ISFI
  scorer on the same K=2.5 budget.
- **F-3 (prefill/final DoM orthogonal, cos 0.046):** Zhao et al. explicitly
  manipulate *penultimate-layer* features and assume `w^max` is fixed across the
  shaping. In transformer-LLM terms, "penultimate" = pre-unembed residual = final
  token of last layer. Their finding that feature-shaping breaks on transformers
  unless tuned per-architecture echoes F-3's finding that the prefill direction is
  geometrically unrelated to the final-token direction — different layers carry
  different decision geometry.

## Methodologies extracted

- **Interval-Specific Feature Impact (ISFI)** — partition penultimate-layer
  features into K=100 equal-width bins between the 0.1 and 99.9 percentiles
  of the training set; the per-bin contribution to the max-logit is
  `I_[a,b](z) = sum_{i: a≤z_i<b} w_i^max · z_i`. Aggregated over an ID set,
  E[I(z)] is a K-dim vector summarizing how each feature-value bin contributes
  to the model's confidence.
  *Replication cost*: 30min CPU on cached Qwen-1.5B L19 prefill activations.
  *We'd plausibly run this*: yes — drop-in ID-only baseline for F-2 / F-8.

- **ID-only closed-form shaping vector (Eq. 14)** —
  `θ* = sqrt(K) / ||E[I(z)]|| · E[I(z)]`. No labels, no OOD samples, no probe.
  Outputs a K-dim rescaling that is then applied per-bin to test-time features
  before computing MLS/Energy/MSP.
  *Replication cost*: 30min CPU once ISFI vectors are in hand.
  *We'd plausibly run this*: yes — directly tests Refutation #1.

- **Piecewise constant element-wise shaping `θ(z)`** — replaces ReAct (clip),
  BFAct (smooth clip), VRA-P (zero-low / clip-high) with a learned
  step function across K bins. Authors show ReAct/BFAct/VRA-P all approximate
  this optimal step function (Fig. 2).
  *Replication cost*: trivial once ISFI is implemented.
  *We'd plausibly run this*: yes — useful for F-7 D-bucket isolation.

- **Sign-flipping low-value features** — unlike VRA-P which zeros below-threshold
  features, their optimal solution often sets θ_k < 0 for low-z bins, "flipping
  the sign to better utilize them." This is a non-obvious empirical move worth
  testing on negative-tail prefill activations associated with incorrect
  reasoning trajectories.
  *Replication cost*: 1h CPU on cached activations.
  *We'd plausibly run this*: yes — possible mechanism for F-4's asymmetric collapse.

## Approaches & framings

- **"OOD detection ≡ rescaling penultimate features for max-logit divergence."**
  Reframes confidence-calibration not as probe-fitting but as a per-bin
  reweighting of which feature magnitudes the unembedding should trust.
  Maps onto our F-2/F-8 lens: instead of asking "what direction in residual
  space predicts correctness?", ask "what value-range of L19 activations
  should be amplified or suppressed before logit readout?"
- **"Existing methods (ReAct, ASH, BFAct, VRA-P) are all approximating a
  single optimal piecewise step function."** Suggests our DoM probe family
  (final-DoM, prefill-DoM, CoE-60) might similarly all be approximations
  of a single underlying ID-statistic — which would unify F-2, F-3, F-9
  under one formulation.
- **"Hard OOD ≈ ID directionally; easy OOD ≈ small magnitude."** Their
  geometric justification for dropping the OOD-expectation term applies
  directly to the correct/incorrect distinction in MATH-500: incorrect
  answers are *not* a separate distribution but a directionally-similar,
  magnitude-attenuated version of correct answers. This matches F-4's
  "asymmetric collapse" framing exactly.

## Implementation details worth capturing

- Code: https://github.com/Qinyu-Allen-Zhao/OptFSOOD (PyTorch).
- K=100 equal-width bins between [0.1th, 99.9th] percentile of training-set
  feature values.
- Constraint `||θ|| = sqrt(K)` rather than `||θ|| = ||1||` is load-bearing
  (their App A.2 notes this; effectively normalizes scale).
- Two scoring variants: "Ours (V)" uses MLS, "Ours (E)" uses Energy. Energy
  marginally better on ImageNet, MLS marginally better on transformers.
- Single RTX 4090 for all experiments — tractable hyperparameter search.
- Hyperparameters per architecture in Appendix A.1 — they explicitly note
  ASH/ReAct/VRA-P need re-tuning per backbone, which is part of the paper's
  pitch (their method does not).

## Replicable intermediates

- **ID-only ISFI closed-form on Qwen L19 prefill (Refutation #1):** load
  `pathway11_h100/prefill_gated_compute/*.npz` (cached prefill L19 activations
  for MATH-500 1.5B run), compute K=100 ISFI vectors using the model's
  unembedding row for each problem's gold answer token (or top-predicted
  token) as `w^max`, average to get E[I(z)] on training fold, derive θ* via
  Eq. 14, apply to test fold, score AUROC. **Cost: ~30min CPU.** Compare
  against 0.7731.
- **K-curve replication for D-bucket (Refutation #2):** same activations,
  restricted to the 36 D-bucket + 207 A-bucket subset. Sweep K ∈ {1, 2, 5,
  10, 20, 50, 100}, plot AUROC vs K. If plateau at K≤10 reproduces in our
  domain, H-7's density-estimator complexity isn't worth it.
- **Sign-flipping check on incorrect-trajectory activations:** examine the
  distribution of L19 activations for problems with incorrect answers vs
  correct, restricted to z < 0 entries. If the optimal θ for these bins is
  negative (their "flip the sign" finding), it suggests negative-magnitude
  features carry usable correctness signal currently being thrown away by
  ReAct-style positive-clipping baselines.

θ* = sqrt(K)/||E[I(z)]|| · E[I(z)] on the same 5-fold split as F-2. Score test
folds via shaped MLS/Energy. Compare AUROC against 0.7731.
**Requires:** ~30min CPU on cached `pathway11_h100/prefill_gated_compute` NPZs.
