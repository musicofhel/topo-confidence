# Triage brief — 2602.05943 — Orthogonal Model Merging

Source: https://arxiv.org/abs/2602.05943
Triaged: 2026-05-06

## Refutations

**R1 — F-3 (prefill/final DoM orthogonality) may be a trivial weight-space rotation artifact, not a structural computation.**
OrthoMerge decomposes weight matrices W_ft = R·W₀ + ρ via the orthogonal Procrustes problem, showing that inter-layer maps are well-approximated by an orthogonal rotation R plus a small residual ρ. If the L19→L20 weight matrix of Qwen-2.5-1.5B has an orthogonal component R whose principal rotation axes mechanically rotate prefill representations into the final-token subspace, the cos(prefill_DoM, final_DoM) = 0.046 could be explained by weight-geometry rather than content-dependent computation. Falsifiable experiment: extract R via Procrustes for the L19 attention/MLP weight matrices, compute R·DoM_prefill, and measure cosine with DoM_final — if cos(R·DoM_prefill, DoM_final) >> 0.046, the orthogonality is mechanically explained by a single rotation.

**R2 — F-2 (L19 DoM AUROC 0.7731) may be degenerate with weight-space spectral structure, not a learned correctness signal.**
OrthoMerge's key insight is that orthogonal transformations preserve spectral norms: ||W_merged||₂ = ||W₀||₂. If the L19 weight matrix's orthogonal component already separates inputs by difficulty (because OFT-style adaptations preserve angular relationships between neurons), then the DoM direction could be recoverable purely from weight-space principal rotation axes without any activation data. This would reframe F-2 from "the model computes a correctness signal" to "weight geometry mechanically separates inputs by a difficulty-correlated axis." Falsifiable: compute the top-k rotation axes of the skew-symmetric Q = (R − I)(R + I)⁻¹ for L19 weights; project cached activations onto these axes and measure AUROC. If AUROC ≥ 0.77, the supervised DoM is redundant with weight geometry.

**R3 — F-1 (dimensional breathing universality) could be a mechanical consequence of orthogonal inter-layer structure, not a content-dependent computation.**
OrthoMerge shows that the orthogonal component of layer weight matrices preserves hyperspherical energy (angular relationships between neurons). If inter-layer maps are predominantly orthogonal (small ρ relative to R), then participation ratio changes across layers (breathing) would be constrained by the rotation structure of the weight matrices — the "breathing" pattern might be determined by the sequence of rotations R₁, R₂, ..., R_L, not by what the model is computing about the input. Falsifiable: compute ||ρ||_F / ||R·W₀||_F for each layer's weight matrix; if this ratio is small (<0.1) across all layers, and the per-layer participation ratio profile is predictable from the R sequence alone (without any input), then breathing is mechanical, not content-dependent.

## Direct connections to F-N / H-N

**F-2 (L19 DoM AUROC 0.7731):** OrthoMerge's Procrustes decomposition W = R·W₀ + ρ provides a principled way to decompose L19's weight matrix into an orthogonal rotation and a residual. The DoM direction found by supervised probing could be compared against the principal rotation axes of R — if they align, this constrains what the AUROC is measuring (weight structure vs. computed signal).

**F-3 (cos(prefill_DoM, final_DoM) = 0.046):** The Lie algebra framework for orthogonal matrices (skew-symmetric Q parameterizing rotations) gives a natural language for characterizing how much inter-layer rotation contributes to the prefill/final orthogonality. The rotation angle ||Q||_F and rotation plane of the L19 weight's orthogonal component can be directly compared with the angular gap between DoM directions.

**F-10 (PH-at-null):** If weight matrices are approximately orthogonal (preserving distances and angles), this would explain why residual-stream point clouds look Gaussian — orthogonal transformations of a Gaussian are Gaussian. The ||ρ||/||R·W₀|| ratio per layer would quantify how much non-orthogonal structure exists to generate non-Gaussian topology.

**H-4 (Breathing ↔ Sharpness Dimension):** OrthoMerge's spectral norm preservation (||R·W₀||₂ = ||W₀||₂) relates to how sharpness propagates through layers — if the orthogonal component dominates, sharpness is conserved across layers, which intersects the Tuci et al. EoS framework.

## Methodologies extracted

- **Orthogonal Procrustes decomposition of weight matrices** — Given W_ft and W₀, solve R = argmin ||W_ft − R·W₀||_F s.t. RᵀR = I via SVD of W_ft·W₀ᵀ. Decomposes any weight change into rotation R + residual ρ.
  *Replication cost*: 20min CPU (SVD of 1536×1536 matrix per layer is trivial).
  *We'd plausibly run this*: yes — directly tests whether L19 weight structure explains DoM.

- **Inverse Cayley transform to Lie algebra** — Map R → Q = (R − I)(R + I)⁻¹ to get a skew-symmetric matrix whose eigenvalues give rotation angles and eigenvectors give rotation planes.
  *Replication cost*: 5min CPU (matrix inverse + subtraction on 1536×1536).
  *We'd plausibly run this*: yes — gives rotation-plane decomposition of inter-layer maps.

- **Magnitude-corrected averaging** — Scaling factor c = (Σ||Qᵢ||_F) / ||ΣQᵢ||_F compensates for cancellation when averaging rotations. Could be applied to averaging DoM directions across folds or models.
  *Replication cost*: trivial (norm computation on vectors).
  *We'd plausibly run this*: maybe — relevant if we ever merge DoM directions across models (H-45 cross-architecture).

- **Orthogonal-residual decoupling with conflict detection** — Column-level cosine similarity identifies "conflicting" neurons where task vectors point in opposite directions. Could be applied to identify which neurons in L19 carry the correctness signal vs. noise.
  *Replication cost*: 15min CPU.
  *We'd plausibly run this*: no — designed for multi-task merging, not single-model analysis.

- **Loss landscape visualization via Gram-Schmidt orthonormalization** — Constructs 2D parameter-space plane through base model and merged models, evaluates loss on grid.
  *Replication cost*: 2h H100 (many forward passes).
  *We'd plausibly run this*: no — not directly relevant to activation-space geometry.

## Approaches & framings

**Weight change = orthogonal rotation + residual.** Any fine-tuning-induced weight change can be decomposed into an isometry (distance-preserving) and a non-isometric residual. This reframes "what did fine-tuning change?" as "how much is rotation vs. distortion?" — directly applicable to understanding why L19's geometry carries a correctness signal while other layers don't (F-2). If L19 has an unusually large or structured orthogonal component, the DoM direction might align with a rotation axis.

**Lie algebra as a linearized rotation space.** Mapping SO(d) → 𝔰𝔬(d) via Cayley/log makes rotations additive, enabling averaging. For our project, this provides a coordinate system for the space of possible inter-layer rotations — the skew-symmetric basis elements of 𝔰𝔬(1536) give d(d−1)/2 independent rotation planes. The DoM direction could be expressed in this basis to test whether it aligns with a few dominant rotation planes.

**Spectral norm invariance under orthogonal transformation.** The preserved ||W||₂ = ||W₀||₂ means that if inter-layer maps are mostly orthogonal, then the spectral properties of activations are inherited from the input distribution, not from the weights. This connects to F-10's Gaussian null: orthogonal transformations of Gaussian data remain Gaussian.

## Implementation details worth capturing

- Cayley parameterization: R = (I + Q)(I − Q)⁻¹ is numerically stable and differentiable, avoids the exp/log on SO(d) which is O(d³) and numerically fragile.
- Block-diagonal structure with 32-dimensional blocks reduces SVD cost from O(d³) to O(d·32²).
- Procrustes solution via SVD: R = U·Vᵀ where U·Σ·Vᵀ = SVD(W_ft · W₀ᵀ). For 1536×1536, this is a few seconds on CPU.
- The skew-symmetric Q is stored as upper-triangular elements only (d(d−1)/2 parameters for d×d rotation).
- Conflict-aware decoupling uses per-column cosine similarity threshold (cos < 0) to identify neurons with opposing task gradients.
- Code: project page at spherelab.ai/OrthoMerge/ (license CC BY 4.0).
