# Triage brief — 2405.10928 — The Local Interaction Basis: Identifying Computationally-Relevant and Sparsely Interacting Features in Neural Networks

Source: https://arxiv.org/abs/2405.10928
Triaged: 2026-04-29

## Refutations

1. **Refutation of F-2's "single direction" framing via the superposition pivot.** The paper's central negative result is that LIB — a Jacobian-SVD-aligned, importance-rescaled rotation of the residual stream — fails on GPT2-small and TinyStories-1M. The authors attribute the failure to superposition: LMs have more features than dimensions, so a non-overcomplete linear basis cannot decompose them. If that diagnosis transfers to Qwen-2.5-1.5B, then prefill L19 DoM (AUROC 0.7731, F-2) is *not* a single computational direction but a coarse linear projection that sums over many superposed sparse correctness features. *Mechanism*: SAE-decode L19 prefill activations → enumerate features whose firing rates correlate with K=1 correctness → check whether removing any single top-K feature drops AUROC ≪ 0.7731 (single-direction prediction) or whether AUROC is robust to single-feature ablation but degrades smoothly as K features are knocked out (refutes single-direction framing). *Falsifiable* by training a TopK SAE on the cached `pathway11_h100` L19 prefill NPZ (~24h H100) and running the ablation sweep.

2. **Refutation of F-3's orthogonality interpretation (cos=0.046).** The paper makes explicit that linear-basis cosines on superposed representations carry no computational meaning — two basis-orthogonal directions can share substantially overlapping sparse features. F-3 currently treats cos(prefill_DoM, final_DoM)=0.046 as evidence of *orthogonal computation*. *Mechanism*: in a SAE basis, decompose both prefill_DoM and final_DoM as sparse-feature vectors; compute Jaccard / cosine between their top-K active SAE feature sets. If the SAE-feature overlap is large (say >0.4) despite raw-cosine ≈ 0, F-3's "two distinct circuits" reading collapses into "one shared sparse population, two different linear summaries." *Falsifiable* by the same SAE training above plus a few CPU-minutes of analysis.

3. **Refutation of F-9 CoE-60 redundancy in a Jacobian-importance basis.** F-9 declares CoE-60 trajectory features redundant with single-layer L19 DoM. That redundancy is a claim *in the raw activation basis*. The LIB paper formalizes how Jacobian-SVD rescaling (Λ^(1/2)V^T) makes downstream-relevant directions explicit; directions with low Λ are computationally inert regardless of their variance. *Mechanism*: compute a between-layer Jacobian Gram matrix between L18→L19 on the cached residuals and project both CoE-60 features and L19 DoM into the rescaled basis. If CoE-60's mass concentrates on high-Λ directions disjoint from L19 DoM's high-Λ projection, the redundancy claim is basis-artefactual. *Falsifiable* with cached P11 residuals + ~6h CPU for stochastic-sources Jacobian estimation per their algorithm.

4. **Refutation of F-10 PH-at-null as evidence of "no geometry."** If LM residual streams are sparse-feature superpositions, the random Gaussian null *is exactly the expected PH outcome* — random projection of a sparse code looks Gaussian by central limit. F-10 currently reads as "no topology"; the LIB framing reads it as "raw-basis PH is the wrong observable." *Mechanism*: re-run PH on SAE-decoded representations (sparse high-d feature vectors) rather than raw 2048-d residuals. *Falsifiable*: if SAE-decoded PH still matches Gaussian null, F-10's strong reading survives; if it shows persistent H₁ bars, F-10 has to be narrowed to "PH on raw activations is uninformative" rather than "no topology exists."

5. **Refutation of H-13's Jacobian-attribution program.** H-13 plans head-level attribution of prefill vs final-token circuits. The LIB paper is precisely a Jacobian-based attribution exercise that *the authors themselves report fails on LMs*. If we pursue H-13 with a similar gradient/Jacobian-times-activation primitive without first decomposing into sparse features, we should expect the same null result the LIB authors got: 80–95% of pairwise interactions ablatable with no interpretability gain. *Falsifiable* / actionable: condition H-13's design on first running an SAE pass; otherwise expect interpretation collapse.

## Methodologies extracted

- **Local Interaction Basis (LIB)** — two-step rotation Cˡ = Λˡ^(1/2) Vˡ (Dˡ^(1/2))⁺ Uˡ Hˡ: PCA-center, drop near-zero variance directions (threshold <10⁻¹⁵ via pseudoinverse), then rotate into right-singular vectors of the layer-to-layer Jacobian Gram matrix, scaled by Λ^(1/2).
  *Replication cost*: ~6h CPU (or 1h H100) per layer-pair on cached residuals using stochastic-sources approximation; full pipeline + Leiden modularity clustering ~1 day.
  *We'd plausibly run this*: yes — narrow scope (only L18→L19, only on prefill activations) to test refutations 1 and 3 above.

- **Stochastic-sources approximation for transformer Jacobians** — replaces O(d⁴) full Jacobian with a randomized sketch tractable for transformer hidden-state widths.
  *Replication cost*: low (algorithm fully specified in paper appendix).
  *We'd plausibly run this*: yes if we ever pursue Jacobian-based attribution; otherwise no.

- **Jacobian Gram matrix Mⱼⱼ'^l = (1/|𝒟|) Σₓ Σᵢ J_ij^l(x) J_ij'^l(x)** — quantifies which input directions matter for the next layer's outputs in expectation over data.
  *Replication cost*: ~30min CPU on 500 sequences from cached residuals.
  *We'd plausibly run this*: yes — gives a simple "which L19 directions actually drive L20" report, directly testable against where prefill DoM lives.

- **Leiden modularity clustering on the interaction graph** (γ=1 default) — bins LIB features into computational modules.
  *Replication cost*: trivial CPU.
  *We'd plausibly run this*: probably no unless we already built the LIB graph.

- **Edge-ablation interpretability proxy** (loss tolerance: 0.1 cross-entropy / 0.1pp accuracy) — measures fraction of pairwise feature interactions ablatable below tolerance; reported as 80–95% for LIB on LMs.
  *Replication cost*: O(d²) ablations per layer; expensive (1 H100-day for L19 alone).
  *We'd plausibly run this*: only if we want a direct head-to-head against the paper.

## Approaches & framings

- **Superposition as the explanation for "feature directions are not single directions."** Reframes our F-2 / F-3 narrative from "one direction predicts correctness" to "one *projection over a sparse code* predicts correctness." This is a non-trivial framing shift because it would change how we describe the result in any writeup — the AUROC stays, the mechanistic claim weakens.
- **Jacobian-SVD as the canonical importance metric.** Replaces variance-based (PCA) with computation-based (Λ from Mˡ). Useful framing for asking which subspaces of L19 actually matter for next-layer compute, distinct from which directions vary most.
- **Linear-basis MI as a preconditioning step for SAEs, not a substitute.** The paper's negative-result framing ("non-overcomplete assumption is wrong") is itself a strong narrative move worth importing into PERSPECTIVES.

## Implementation details worth capturing

- Cˡ = Λˡ^(1/2) Vˡ (Dˡ^(1/2))⁺ Uˡ Hˡ — the transform composes as PCA-center → PCA-rotate → drop-low-variance → Jacobian-SVD-rotate → importance-rescale.
- Pseudoinverse threshold < 10⁻¹⁵ for dropping near-zero directions; in practice this drops ~half of dimensions on residuals of width 768.
- Loss-tolerance for edge ablation: 0.1 nats cross-entropy increase (LM) / 0.1 pp accuracy (CIFAR-10) / 99.9% accuracy floor (modular addition).
- Leiden resolution γ=1 default (γ=0.5 reported as cherry-picked example, signals authors' own caveat).
- They explicitly report 80–95% of LIB interactions on LMs are ablatable with no interpretability gain — this is the diagnostic to copy if we want to assess any candidate basis.
