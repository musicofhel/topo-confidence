# Triage brief — 2602.04521 — C-ΔΘ: Circuit-Restricted Weight Arithmetic for Selective Refusal

Source: https://arxiv.org/abs/2602.04521
Triaged: 2026-04-29

## Refutations

1. **Refutes F-3 (prefill/final-token DoM orthogonality, cos = 0.046) if the two positions sit on the same EAP-IG circuit.**
   Mechanism: F-3 currently treats the near-zero cosine between prefill-L19 DoM and final-token-L19 DoM as evidence of *two different computations*. C-ΔΘ shows that a single sparse circuit (<5% of params) can implement a behaviour whose representation-direction at different sequence positions need not be aligned in residual-stream coordinates — orthogonal directions can be the *same* underlying circuit's projections at two compute stages. If EAP-IG on correctness logits returns a single circuit whose edges drive *both* the prefill L19 DoM read-out and the final-token L19 read-out, F-3's "two-mechanism" framing is wrong; orthogonality would be a coordinate artefact, not evidence of independence.
   Falsifiable test: run EAP-IG (or any edge-attribution method) on the correctness logit using cached Qwen-2.5-1.5B activations on MATH-500, label the top-k edges driving prefill-L19 DoM read and the top-k driving final-token L19 read, and measure overlap. If Jaccard ≳ 0.3, F-3's interpretation is undermined.

2. **Refutes H-13 (head-level attribution) by demonstrating the technique while predicting a different answer.**
   H-13 currently treats prefill and final-token correctness circuits as *attribution-distinguishable*. C-ΔΘ's specific claim — that refusal is concentrated in a sparse mid-to-late circuit that can be edited without harming MMLU/GSM8K capability — provides a sharp methodological precedent for what such an attribution looks like *and* a sharp prediction: if one runs the same EAP-IG pipeline on *correctness* (rather than refusal) logits, the resulting circuit may overlap the GSM8K-utility circuit (since correctness on math *is* utility), making the correctness signal much less surgically separable than refusal. That refutes H-13's implicit assumption that prefill correctness has a clean head-level circuit at all.
   Falsifiable test: EAP-IG on Qwen-2.5-1.5B for MATH-500 correctness, measure circuit sparsity. If the attributed circuit covers >30% of MLP/attention edges (vs. <5% for refusal), correctness is distributed and H-13's "find the correctness heads" frame fails.

3. **Refutes H-1 (per-position DoM steering) by offering a cleanly superior baseline.**
   H-1 hypothesises that per-position activation steering with the prefill DoM moves MATH-500 accuracy. C-ΔΘ's central thesis is that *runtime activation hooks are the wrong abstraction* — sparse weight edits Δθ_C produce equivalent or stronger behavioural effects without inference cost. If a circuit-restricted weight edit on Qwen-2.5-1.5B's L19 area (built from the prefill DoM rank-1 update) moves MATH-500 K=1 accuracy more than per-position activation steering with the same DoM, H-1's framing as a *steering* hypothesis is refuted in favour of a static-edit hypothesis. If both fail, the prefill DoM is correlational only and the entire refuse-and-spend agenda (F-8) loses causal grounding.
   Falsifiable test: small-scale: apply rank-1 weight update on W_O of L19 attention output along the prefill DoM direction (negative for incorrect-leaning inputs at inference), measure ΔAccuracy on a held-out 100-problem MATH-500 subset, compare to per-position L19 activation steering with the same magnitude.

4. **Refutes the F-7/H-21 "D-bucket has a distinctive signature" framing if D-bucket is just a noisy slice of the refusal/uncertainty circuit.**
   Mechanism: C-ΔΘ argues refusal has a *sparse, identifiable* circuit. If running EAP-IG on D-bucket-vs-A-bucket discrimination returns a circuit that overlaps the refusal circuit (i.e. D-bucket problems are ones the model is *internally uncertain about and partially refusing*), F-7's claim that D-bucket has its own collective geometric signature would reduce to "D-bucket is mild internal refusal" — not a separate phenomenon.
   Falsifiable test: EAP-IG on D-bucket vs. A-bucket logit margin on the 36 D + 207 A problems. If the recovered circuit edges overlap >50% with the refusal circuit (independently localised on harm-prompts), F-7 is downgraded from "novel collective signature" to "rebadged refusal direction".

## Methodologies extracted

- **EAP-IG (Edge Attribution Patching with Integrated Gradients)** — circuit localisation via attribution scoring on edges (attention-head-output → next-layer-input + MLP edges). Returns a sparse set of edges whose ablation drops the target logit most.
  *Replication cost*: 1 H100 day to set up EAP-IG on Qwen-2.5-1.5B with MATH-500 correctness as target. Existing TransformerLens / EAP-IG implementations (Hanna 2024) are open source.
  *We'd plausibly run this*: **yes** — directly tests F-3's two-circuit assumption and unlocks H-13.

- **Circuit-restricted weight update Δθ_C** — given a localised circuit C, build the constrained low-rank update on circuit edges only (mask-and-solve on circuit weight matrices) such that it implements the activation-steering effect statically.
  *Replication cost*: ~3 days H100 once EAP-IG is in place; roughly equivalent to fitting a low-rank LoRA but with edge-mask constraints.
  *We'd plausibly run this*: **yes for H-1 alternative**, no if EAP-IG step shows correctness circuit is non-sparse.

- **Capability-retention evaluation harness** — pre/post edit on MMLU + HellaSwag + GSM8K to verify utility preservation.
  *Replication cost*: ~2 hours per checkpoint on H100.
  *We'd plausibly run this*: **yes** — if we ever do *any* weight edit (H-1 static variant, F-8 baked-in selective prediction), this is the standard guard.

- **Category-targeted selectivity protocol** — different harm categories yield different circuits; selective ablation per category. Analogue for our project: different *failure modes* (D-bucket vs. B-bucket) might have different correctness sub-circuits.
  *Replication cost*: depends on bucket count; ~2× single-circuit cost.
  *We'd plausibly run this*: **maybe** — useful only if the F-7 D-bucket signature survives the Refutation-4 test.

## Approaches & framings

- **"Move the cost from runtime to a one-time offline update."** — frames activation steering as a workaround for inability to do constrained weight editing. Direct intersection with H-1: per-position steering (runtime) vs. circuit-restricted weight edit (offline) is a real methodological fork.
- **"Sparse circuit is the unit of behaviour, not direction."** — refines the Arditi 2406.11717 single-direction-of-refusal story by adding *which weights compute that direction*. For our F-2/F-3, the analogous refinement is: instead of "L19 prefill DoM is the direction", ask "which sparse circuit *computes* the prefill DoM, and is it the same circuit that computes the final-token DoM?" That reframes F-3's orthogonality from a representational claim to a circuit claim.
- **"Selectivity = per-category sub-circuits, not a master switch."** — for our refuse-and-spend agenda (F-8), this suggests *not* a single confidence threshold but per-bucket (A/B/C/D) confidence circuits with different operating points.

## Implementation details worth capturing

- EAP-IG concentrates attribution on **mid-to-late transformer layers** (consistent with our L19 of 28 in Qwen-2.5-1.5B sitting in the same band).
- Circuit sparsity threshold: **<5% of parameters** edited. Use this as the order-of-magnitude expectation when running EAP-IG on correctness — anything ≥30% means correctness is distributed, not circuit-localised.
- Specific attention heads + MLPs are both flagged; no MLP-only or attention-only methodology.
- Closely related prior method: **CAST (Lee et al. 2025)** — circuit-restricted weight arithmetic; should be added to the graph if not present.
- Code: not stated as released in the abstract / available pages; check authors' GitHub before relying on a public implementation. Hanna 2024 EAP-IG implementation is the public fallback.
