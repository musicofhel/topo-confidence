# Triage brief — 2605.04344 — Perturbation is All You Need for Extrapolating Language Models

Source: https://arxiv.org/abs/2605.04344
Triaged: 2026-05-09

## Refutations

1. **Refutes stability assumption behind F-2 (L19 prefill DoM AUROC 0.7731).**
   The paper's core theory (Theorem 3, Assumption 2) states that a well-chosen perturbation maps any out-of-support prefix to a semantically equivalent in-support prefix, making the model's internal processing identical for both. If this holds, then the L19 prefill direction-of-maximum-variance (DoM) we measure on MATH-500 prefills should be *invariant* under the paper's synonym-insertion perturbations — since the model is explicitly trained to produce identical next-token distributions for original and perturbed prefills. This means DoM is measuring something that the perturbation framework considers a nuisance (exact token identity) rather than a fundamental feature. If a perturbation-trained model collapses semantically equivalent prefills to the same internal representation, the DoM direction would lose its discriminative power, since correct and incorrect problems with similar semantic content would map to the same residual-stream geometry.
   *Mechanism:* Perturbation-trained models homogenize residual-stream geometry across semantic neighbors → DoM direction loses per-problem correctness signal.
   *Falsifiable test:* Fine-tune Qwen-2.5-1.5B with the paper's perturbation procedure on a math corpus, re-extract L19 prefill activations on MATH-500, measure DoM AUROC. If AUROC drops significantly (< 0.70), perturbation training has destroyed the correctness-predictive geometry.

2. **Refutes the prefill/final orthogonality finding F-3 (cos = 0.046).**
   The paper argues (Section 2.1, Algorithm 2) that perturbation during inference introduces a stochastic pre-processing step before each next-token prediction. This means the "prefill" phase no longer has a fixed, deterministic input — it receives a perturbed variant. If inference-time perturbation is applied, the prefill hidden state becomes a *stochastic function* of the input rather than a deterministic one. The near-zero cosine between prefill DoM and final-token DoM (F-3) was measured under deterministic prefill encoding. Under perturbation, the prefill DoM direction would itself become a random variable with non-trivial variance. The orthogonality result could be an artifact of the deterministic encoding, and perturbation-induced variance in the prefill direction could reveal that prefill and final-token geometry are actually aligned when averaged over the perturbation distribution.
   *Mechanism:* Inference-time perturbation adds noise to prefill encoding → measured prefill DoM becomes a random variable → mean perturbation-averaged DoM may have higher cosine with final-token DoM.
   *Falsifiable test:* Apply random synonym insertion (intensity α=0.025) to MATH-500 prefills 50 times each, extract L19 prefill activations for each perturbation, compute DoM on the averaged activations, measure cosine with final-token DoM. If cos > 0.3, F-3's orthogonality is fragile to input perturbation.

3. **Challenges the selectivity stack F-8 (71.6% at 50% coverage) via extrapolation uncertainty bounds.**
   Proposition 1 gives an explicit bound on extrapolation uncertainty under synonym replacement: U ≤ (1−β)^δ, where β is perturbation intensity and δ is Hamming distance from training support. This bound implies that for sufficiently perturbed inputs, model predictions become *uniformly uncertain* regardless of the input. If the DoM-based selective prediction stack (F-8) encounters prompts that are δ > 5 tokens away from training support (likely for novel MATH-500 problems), the perturbation framework predicts that *any* confidence signal, including DoM, should degrade at a known rate. The selective-prediction stack assumes DoM is a reliable confidence proxy across the input space; the extrapolation uncertainty bound suggests it should fail gracefully on out-of-support problems, but in a way that the abstention threshold cannot distinguish from genuinely hard in-support problems.
   *Mechanism:* Extrapolation uncertainty bound predicts DoM reliability degrades with Hamming distance from training support → selective prediction at 50% coverage should show coverage-dependent AUROC degradation.
   *Falsifiable test:* Partition MATH-500 into quintiles by estimated Hamming distance from Qwen-2.5-1.5B's training data (via perplexity proxy). Compute selective-prediction accuracy at 50% coverage within each quintile. If accuracy degrades monotonically by >10pp from lowest to highest perplexity quintile, the extrapolation uncertainty mechanism is operating.

## Direct connections to F-N / H-N

- **F-2 (Prefill L19 DoM AUROC 0.7731):** The paper's perturbation framework directly tests whether the L19 DoM signal is robust to input variation. Their perturbation types (synonym replacement, random insertion, random deletion — Section 2.2) provide a structured protocol for stress-testing DoM stability. The extrapolation uncertainty bound (Proposition 1, U ≤ (1−β)^δ) could quantify how many perturbation samples we need to estimate DoM variance, which connects to the 5-fold OOF validation structure behind the 0.7731 number.

- **F-5 (Breathing is content-dependent, not AR-mechanics):** The paper distinguishes perturbation effects from AR mechanics by showing that perturbation at inference time (not just training time) is necessary for extrapolation (ablation in Section 4.3, Figure 3). This directly parallels our distinction between content-dependent breathing and AR artifacts. If perturbation-trained models still show breathing patterns, it would strengthen F-5; if breathing disappears, it would suggest breathing is partly an artifact of exact-token conditioning.

- **F-10 (PH adds negative signal beyond covariance — topology null):** The paper's framework operates entirely in the embedding/hidden-state space without any topological structure. The perturbation operator T(·|X) acts on token sequences, not on geometric properties of residual streams. This is consistent with F-10's conclusion that topology doesn't add signal: the paper's theoretical framework achieves extrapolation guarantees using purely distributional (TV distance) and linear-algebraic (feature map spanning, RKHS) machinery, with no topological component needed.

- **H-1 (Per-position DoM steering moves accuracy):** The paper's perturbation-at-inference procedure (Algorithm 2) is a form of input-space steering. If input perturbation can improve extrapolation (their main claim), then it provides a complementary mechanism to H-1's activation-space steering. The two could be tested jointly: perturb the input AND steer the residual stream.

## Methodologies extracted

- **Perturbed autoregressive training** — Train LLM by randomly perturbing prefixes (synonym replacement, random insertion, random deletion at intensity α) before next-token prediction, optimizing E_T[log P_θ(X_t|X̃_<t)]. Perturbation applied at both train and inference time.
  *Replication cost*: 1-2 GPU days to fine-tune Qwen-2.5-1.5B with perturbation on a math corpus.
  *We'd plausibly run this*: no — requires retraining the base model, which is outside our analysis-only pipeline.

- **Extrapolation uncertainty quantification via TV distance** — Measure model class extrapolability by computing sup_{X': d(X',X)≤δ} sup_{P,P': TV_X(P,P')=0} TV_{X'}(P,P'). Provides finite-sample bounds on how far predictions can drift for unseen inputs.
  *Replication cost*: 20min CPU to compute TV-based bounds on cached probability distributions.
  *We'd plausibly run this*: yes — could adapt the uncertainty bound to quantify DoM stability. We have per-problem correctness predictions; we could compute Hamming-distance-stratified AUROC to test the bound empirically.

- **Perturbation ablation protocol** — Compare four conditions: NoPerturb, TrainPerturb-only, TestPerturb-only, BothPerturb. Tests whether a signal arises from training augmentation or inference-time robustness.
  *Replication cost*: 30min CPU to apply perturbation ablation to cached features (at inference-analysis level only, without retraining).
  *We'd plausibly run this*: yes — we could apply structured perturbations to MATH-500 prefills at inference time only (TestPerturb variant) and measure effect on DoM without retraining.

## Approaches & framings

- **Pre-post-additive noise model for LLMs.** The paper formalizes LLM generation as Y = f(X+η) + ε (Section 1.2), adapting the engression framework (Shen & Meinshausen 2025) from regression to language modeling. This offers a clean framing for our DoM work: the "pre-additive noise" (input perturbation) tests whether the DoM signal is robust to X+η, while the "post-additive noise" (sampling stochasticity) is what we already control via K=1 greedy decoding. The decomposition could formalize which part of DoM's predictive power comes from input-sensitivity vs. intrinsic model geometry.

- **Extrapolability as interpolation via perturbation (Theorem 3, Assumption 2).** The key theoretical insight: perturbation transforms extrapolation into interpolation by mapping unseen inputs to seen ones. For our project, this reframes the question of whether DoM generalizes to unseen problems: if a perturbation exists that maps novel MATH-500 problems to training-set-similar problems while preserving DoM, then DoM is measuring an interpolation signal, not an extrapolation signal. This distinction matters for H-5 (problem familiarity vs. decomposability).

## Implementation details worth capturing

- Perturbation intensity α=0.025 works best in their real-data experiments (Figure A2), with performance degrading at higher intensities.
- Random insertion outperforms synonym replacement and deletion marginally (Table A3), but differences are small.
- They use m=1 perturbation sample at inference time (single perturbation per prefix) for efficiency, vs. m=2 during training.
- AdamW optimizer, lr=5e-5, linear scheduler, batch size 32, max input length 256 tokens during training.
- Code not released; datasets available via HuggingFace and GitHub (see Section D.3).

## 2605.04344 — Perturbation is All You Need for Extrapolating Language Models (Cen, Zhu, Shen, Shi, 2026)

**Relevance:** Introduces a perturbation-based training/inference framework for LLMs with theoretical extrapolation guarantees. The extrapolation uncertainty bounds (Proposition 1) provide a testable prediction about how DoM-based correctness signals should degrade with input novelty. The perturbation operator framework offers a structured protocol for stress-testing DoM robustness via synonym replacement, random insertion, and random deletion at controlled intensities.

**Key claim we tested:** Perturbation-trained models should be robust to out-of-support inputs, with extrapolation uncertainty bounded by (1−β)^δ where β is perturbation intensity and δ is Hamming distance from training support.

**Our result:** **TO TEST** — the theoretical framework generates two concrete predictions about our DoM signal: (1) DoM AUROC should be robust to input perturbation at low intensity, and (2) DoM AUROC should degrade with distance from training support. Neither has been tested experimentally.

**Related experiments:** P11-FE670, P11-FE671, H-810, H-811

**Status:** TO TEST
