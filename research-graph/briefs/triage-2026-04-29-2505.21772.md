# Triage brief — 2505.21772 — Calibrating LLM Confidence by Probing Perturbed Representation Stability (CCPS)

Source: https://arxiv.org/abs/2505.21772
Triaged: 2026-04-29

## Refutations

1. **CCPS would refute F-2 ("prefill L19 DoM is a stronger correctness predictor than final-token")**
   F-2's headline ordering — prefill AUROC 0.7731 > final-token AUROC 0.7186 on Qwen-2.5-1.5B —
   uses a single linear direction at the last position. CCPS extracts a rich
   feature bundle (Jacobian L2 norm, ε-to-flip, PEI, KL/JS trajectories across
   S=5 perturbation steps, perturbed-state probability/entropy/margin stats) **purely from final-token hidden states**
   and reports AUROC 77–83% on MMLU-Choice and 66–77% on MMLU-OE across 8B–32B Llama/Qwen/Mistral —
   ranges that meet or exceed our prefill DoM number on a different benchmark.
   *Mechanism*: if CCPS's final-token feature bundle, run on the same Qwen-2.5-1.5B / MATH-500
   pipeline, lands AUROC ≥ 0.77 (≥ F-2 prefill), then "prefill > final" is an artifact of
   under-engineered final-token features, not a geometric truth.
   *Falsifiable test*: extract CCPS features at the last layer of Qwen-2.5-1.5B from the cached
   P11 H100 generations, train an MLP with 5-fold OOF, compare AUROC against F-2's 0.7731
   prefill-DoM number on the same 500 problems.

2. **CCPS would refute F-3 ("prefill and final-token DoM are orthogonal, encoding different signal subspaces")**
   F-3 reads cos(prefill_DoM, final_DoM) = 0.046 as evidence the two layers carry
   *different* correctness information. CCPS gets its strongest features (epsilon-to-flip,
   PEI, perturbed-state margin) entirely from final-token logits — no prefill access — and
   matches/exceeds prefill-DoM AUROC. If concatenating CCPS final-token features with our
   prefill DoM does *not* lift AUROC above the CCPS-only number, the two subspaces are
   redundant rotated copies of the same scalar correctness axis, not orthogonal carriers
   of complementary signal.
   *Mechanism*: rich final-token dynamic features saturate the available correctness
   information; prefill DoM is a low-rank projection of the same signal.
   *Falsifiable test*: stack [CCPS-final-features, prefill_DoM_projection] and refit; if
   ΔAUROC < 0.005 the orthogonality claim's interpretive load collapses.

3. **CCPS would refute F-8 ("selective-prediction via prefill DoM = 71.6% accuracy at 50% coverage")**
   F-8 is the headline applied result. CCPS reports MMLU-Choice ACC 80–84% with AUROC 77–83%,
   which back-of-envelope implies selective accuracy >80% at 50% coverage on those benchmarks.
   If a CCPS classifier on Qwen-2.5-1.5B / MATH-500 produces selective accuracy at coverage 0.5
   above 71.6%, the F-8 number — and the recommendation to use prefill DoM as the abstention
   gate — is dominated by a final-token method we have not yet tried.
   *Mechanism*: dynamic perturbation features carry strictly more signal than a single linear
   projection; selective accuracy curves should shift up everywhere.
   *Falsifiable test*: same CCPS extraction; plot selective-accuracy vs coverage curves
   alongside the prefill-DoM curve from `scratch/pathway10_temporal_and_verifier_results.json`.

4. **CCPS would refute F-9 / H-6 ("CoE-60 trajectory features are redundant with single-layer L19 DoM")**
   F-9 concluded the 60-dim CoE trajectory feature family adds nothing beyond a single L19
   direction. CCPS shows that *engineered* trajectory features (in the perturbation-energy
   space, not the temporal-residual-stream space CoE operates in) dominate baselines that
   are themselves trajectory-style (LitCab, CT, SAPLMA). If CCPS features beat single-layer L19
   DoM by ≥ 3 AUROC points on MATH-500, the equivalence class "trajectory features ≡ DoM"
   is wrong: it depends on *which* trajectory parameterization, not on whether trajectories
   carry signal.
   *Mechanism*: F-9's null was conditioned on temporal CoE specifically, not on perturbation-
   response features in logit space.
   *Falsifiable test*: AUROC(L19 DoM) vs AUROC(CCPS-final), 5-fold OOF on MATH-500.

5. **CCPS contextualizes F-10 ("PH on residual streams is at the Gaussian null") — not refuted, but its scope is narrower than the project narrative implies**
   F-10's killing of persistent homology is often paraphrased as "residual-stream geometry
   doesn't predict correctness." CCPS shows that *dynamic perturbation responses* of those
   same residual streams — KL/JS divergences, ε-to-flip, PEI — carry strong signal. F-10
   stays intact for static topological summaries, but the broader framing needs softening:
   it's static residual-stream PH that's at null, while perturbation-driven trajectory
   features in logit space are not.
   *Mechanism*: dynamic vs static is a different geometric object; PH null does not
   generalize to all residual-stream-derived features.
   *Falsifiable test*: compute PEI/ε-to-flip on same residual streams used in EXP-026; if
   AUROC > 0.6, F-10's narrative scope must be tightened in PROJECT_RECORD §1d.

## Methodologies extracted

- **Token-level Jacobian-direction adversarial perturbation** — for each generated token
  t_i, compute J^(i) = ∇_{H_0^(i)} (-log P(t_i | H_0^(i))), normalize to unit direction
  d^(i), step S=5 times along d^(i) with ε_max=20 total radius.
  *Replication cost*: 30min H100 per (model × benchmark) for Jacobian + perturbation
  forward passes; cheap because LM_Head is just one matmul once H_s^(i) is constructed.
  *We'd plausibly run this*: yes — Jacobian direction at L=last is the natural final-token
  analogue of our prefill DoM, and we already have all the infrastructure for L19 hidden
  states on Qwen-2.5-1.5B/7B for MATH-500.

- **Perturbation Energy Integral (PEI)** — single scalar summarizing the trajectory
  ∫ log P(t_i | H_s^(i)) ds across s ∈ {0,...,S}.
  *Replication cost*: trivial post-processing (CPU minutes).
  *We'd plausibly run this*: yes — could become a candidate scalar correctness signal,
  comparable to prefill DoM projection magnitude.

- **Epsilon-to-flip** — perturbation magnitude required for argmax(Z_s^(i)) ≠ t_i.
  *Replication cost*: trivial (binary search over s).
  *We'd plausibly run this*: yes — gives a natural per-token "decisiveness" signal that
  could feed into H-19 C_exact routing.

- **Comparison features (KL, JS, cosine) between original and perturbed distributions** —
  full statistical summary (mean/std/min/max across S steps).
  *Replication cost*: 1h CPU once perturbed logits are cached.
  *We'd plausibly run this*: yes — the perturbed-state divergence trajectory is a richer
  signal than CoE's per-layer cosine, and could revisit F-9's null.

- **Max-Margin contrastive pre-training of feature projection** — pairs (correct, incorrect)
  embeddings pushed apart with margin γ, before joint cross-entropy fine-tuning.
  *Replication cost*: 30min H100 per training run.
  *We'd plausibly run this*: yes if the simple-classifier results are positive — common
  with LitCab; portable training trick.

- **Adaptive 1D CNN encoder for variable-length OE answer feature sequences** —
  E_OE = Conv1D + adaptive_pooling + MLP head.
  *Replication cost*: 30min training.
  *We'd plausibly run this*: maybe — only relevant if we generalize from MC-style MATH-500
  greedy answers to longer free-form generation.

## Approaches & framings

- **Internal-stability-as-confidence** — the conceptual move that "robustness of the
  internal state to gradient-direction perturbation" is the right operationalization of
  confidence. This is a different framing from F-2's "directional probe" and from F-4's
  "asymmetric collapse"; both of those are *static* observations on the residual stream,
  while CCPS makes the *response to controlled stress* the signal. Maps onto our project
  if we reinterpret F-4 (asymmetric collapse) as a *static* signature of which trajectories
  *would* be CCPS-stable and which would not.

- **Adversarial-but-not-attack** — the paper carefully delimits "adversarial perturbation"
  as gradient-informed stress for the purpose of probing, distinct from misclassification
  attacks or robustness training. This is a useful framing if we ever publish, since
  reviewers conflate the two; F-4 / F-8 narratives could borrow it.

- **Calibration vs discrimination as separable objectives** — CCPS's story is that prior
  methods trade off ECE against AUROC, and its dual strength is that it does both. Our
  project mostly reports AUROC; we have not engaged with calibration (ECE/Brier). If the
  research-graph is going to be honest about applied selective prediction (F-8), we owe
  an ECE number.

## Implementation details worth capturing

- ε_max = 20.0, S = 5 steps; chosen as practical upper bound where output distribution
  degrades to "gibberish" across all models (their words) — useful sanity check
  hyperparameter when we replicate.
- AdamW, lr=1e-4, batch_size=32, weight_decay=0.1.
- 5,000 steps contrastive pre-training of E_MC/E_OE, then 5,000 steps joint cross-entropy.
- 5-shot exemplars in input prompt P throughout.
- Classification head outputs 2-dim logits (incorrect vs correct), final score via softmax —
  matches Kapoor 2024b architecture.
- Code: https://github.com/ledengary/CCPS — should be cloneable for direct replication.
- Public HF feature dataset: https://huggingface.co/datasets/ledengary/CCPS — saves us
  the Jacobian compute if we just want to validate their classifier on their features.

## Replicable intermediates

- **Smallest cross-check**: on the cached P11 H100 final-token hidden states for
  Qwen-2.5-1.5B on MATH-500 (`pathway11_h100/prefill_gated_compute/results.json` and
  associated NPZ), compute per-token (a) Jacobian L2 norm, (b) ε-to-flip via 5-step linear
  search, (c) PEI integral, (d) KL divergence to original at s=S/2. Pool over the answer
  span (MATH-500 is short numeric answers — usually 1–10 tokens). Train 5-fold OOF
  logistic regression; compare AUROC to 0.7186 (F-2 final-token DoM) and 0.7731 (F-2
  prefill DoM).
  *Cost*: 1h CPU once Jacobian is cached. The Jacobian itself is cheap because we only
  need ∂ log P(t_i)/∂ H_0^(i) — one backward pass per token through the LM_Head only
  (the rest of the network is frozen and the chain rule terminates at H_0^(i)).
- **Even smaller**: pull the public HF features dataset
  (huggingface.co/datasets/ledengary/CCPS), train their MLP, sanity-check we reproduce
  Table 1 ECE/AUROC numbers before doing any new compute.

## 2505.21772 — Calibrating LLM Confidence by Probing Perturbed Representation Stability (Khanmohammadi et al., 2025)

recent literature and operates entirely on the same object (final-token hidden state)
that our F-2 final-token DoM AUROC of 0.7186 was computed on. The method extracts a rich
feature bundle (Jacobian-direction adversarial perturbation along negative-log-likelihood
gradient with ε_max=20, S=5 steps; per-token features include Jacobian L2 norm,
epsilon-to-flip, Perturbation Energy Integral, KL/JS divergences, and perturbed-state

Mistral models — at or above our prefill-DoM AUROC of 0.7731 on Qwen-2.5-1.5B MATH-500.
Code (github.com/ledengary/CCPS) and a HuggingFace feature dataset
(huggingface.co/datasets/ledengary/CCPS) are public, making replication cheap.

**Key claim we tested:** Final-token internal-stability features under targeted Jacobian-
direction perturbation match or exceed AUROC numbers achievable from a single linear probe
direction — without using any prefill information.
