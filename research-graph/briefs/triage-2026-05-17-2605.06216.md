# Triage brief — 2605.06216 — TIDE: Every Layer Knows the Token Beneath the Context

Source: https://arxiv.org/abs/2605.06216
Triaged: 2026-05-17

## Refutations

1. **Refutes F-2 (L19 DoM as correctness predictor) if token-identity leakage confounds the signal.** TIDE demonstrates that token identity persists (or fails to persist) in hidden states across layers in a frequency-dependent way. If the L19 prefill DoM direction is substantially aligned with a token-frequency or token-identity axis rather than a genuine "problem-difficulty" or "correctness-relevant" computation, then the 0.7731 AUROC could be partially explained by rare-token confounding: MATH problems with rare mathematical symbols (integrals, Greek letters) are both harder AND less well-represented in the residual stream. The refutation fires if regressing out per-position token-frequency features from L19 prefill activations significantly degrades DoM AUROC.

   *Falsifiable experiment:* Compute mean token frequency (log unigram probability) per prompt position for all 500 MATH-500 samples. Train a logistic probe on L19 activations with and without partialing out the token-frequency projection. If AUROC drops >0.03 after removal, the token-identity confound is non-negligible.

2. **Refutes F-3 (prefill/final DoM orthogonality) if contextual collapse explains the cos=0.046 as a trivial geometric artifact.** TIDE's contextual collapse analysis (Figure 2) shows hidden states become near-indistinguishable for many token pairs across most layers. If L19 prefill activations are dominated by token-identity signal (which collapses before final layers), and final-token activations reflect the post-collapse contextual signal (where identity has been erased), then the orthogonality between prefill_DoM and final_DoM is an artifact of the identity→context transition rather than evidence of two structurally independent correctness signals. The refutation would fire if projecting out the TIDE-style "token-identity subspace" from prefill activations causes cos(prefill_DoM, final_DoM) to rise substantially (>0.3).

   *Falsifiable experiment:* Estimate a token-identity subspace from the embedding matrix E (top-k PCs of E[tokens_in_prompt]). Project L19 prefill activations onto the complement of this subspace. Recompute DoM in the residualized space. If cos(residualized_prefill_DoM, final_DoM) > 0.3, the orthogonality was an identity-vs-context artifact.

3. **Refutes F-7 (D-bucket collective geometric signature) if D-bucket membership correlates with rare-token density.** TIDE shows tokens in the "rare zone" (bins 0-2) have systematically different hidden-state geometry: lower norms, wider distributions, collapse-prone representations. If MATH-500 problems that land in the D-bucket (the hardest stratum) systematically contain more rare tokens (domain-specific math symbols, unusual LaTeX, uncommon entity names), then F-7's "distinctive collective geometric signature" could be a downstream consequence of token-frequency statistics rather than problem-level difficulty encoding.

   *Falsifiable experiment:* For each of the 500 MATH-500 problems, compute the mean log-frequency of constituent tokens (using a reference corpus like Wikitext-103 + LLaMA tokenizer). Test whether D-bucket membership is predicted by mean token rarity above chance (logistic regression, AUROC > 0.6). If yes, F-7's geometric signature may be confounded.

4. **Refutes H-5 (prefill signal encodes problem familiarity vs decomposability) via an alternative explanation.** TIDE's gradient-starvation theory provides a more parsimonious explanation for why prefill geometry predicts correctness: problems with familiar (high-frequency) tokens have better-trained embeddings that produce more structured residual streams, while problems with rare tokens have noisy, under-trained embeddings. This is "familiarity" in a shallow token-frequency sense, not a deep semantic sense. H-5 posits the signal encodes decomposability — TIDE suggests it might just encode token training quality.

   *Falsifiable experiment:* Take the 500 MATH-500 problems, split into tertiles by mean token frequency. Within each tertile (controlling for token frequency), check if DoM still predicts correctness (AUROC > 0.65 within each tertile). If the signal vanishes within frequency-matched subgroups, the token-training-quality explanation wins over the decomposability hypothesis.

## Direct connections to F-N / H-N

- **F-2 (Prefill L19 DoM AUROC 0.7731):** TIDE's token-identity persistence analysis directly questions what information the L19 prefill direction encodes. The paper shows token identity is injected once and then "permanently discarded" — so L19 is operating on a contextual mixture where rare tokens are poorly represented. The DoM direction might partially capture variance in embedding quality rather than (or in addition to) a genuine "confidence" computation.

- **F-4 (Correct trajectories collapse harder — asymmetric collapse):** TIDE's "contextual collapse" phenomenon (Figure 2) shows hidden-state distances between token pairs diminish across layers. This is structurally analogous to F-4's "asymmetric collapse" observation — correct answers collapsing to a shared representation. TIDE suggests this convergence is partly driven by the residual stream's loss of token-discriminative signal at depth, which could provide a mechanistic explanation for why correct trajectories converge more (they've successfully resolved the context, so token identity no longer matters).

- **F-10 (PH null — topology adds nothing beyond covariance):** TIDE's finding that hidden states become near-indistinguishable across layers (contextual collapse) provides independent evidence that residual-stream geometry is dominated by low-rank structure (first few PCs), not higher-order topological features. If representations collapse to low-dimensional manifolds by mid-depth, PH would see only the Gaussian-like covariance structure — aligning with F-10.

- **H-4 (Breathing ↔ Sharpness Dimension / EoS correspondence):** TIDE's depth-conditioned router learns layer-specific routing weights that vary by token frequency. This "depth conditioning" on token identity is a form of per-layer specialization that could be compared to the "breathing" (expansion/contraction) pattern across layers. The router's NULL-bank weight increasing from 0.530 (rare) to 0.889 (common) at the last layer suggests rare tokens need more identity reinforcement at depth — potentially explaining why "breathing amplitude" differs by difficulty.

- **Contextual Collapse distance measurement** — Compute mean ℓ₂ distance ∥h_u^(ℓ) - h_v^(ℓ)∥ between hidden states of confusable token pairs across all layers, using template sentences that isolate single-token differences.
  *Replication cost*: 2-4h GPU (requires forward passes on template sentences through Qwen-2.5-1.5B).
  *We'd plausibly run this*: no — requires new forward passes we can't do on CPU, and the insight is available via cheaper proxy on cached data.

- **Token-frequency binning + per-bin probe analysis** — Partition vocabulary into deciles by corpus frequency, measure per-bin metrics (embedding norm, gradient accumulation, probe performance) to detect frequency-dependent effects.
  *Replication cost*: 20min CPU (can be computed from tokenizer statistics + cached activations).
  *We'd plausibly run this*: yes — directly applicable to MATH-500 token statistics + L19 DoM analysis.

- **Depth-conditioned softmax routing analysis** — Linear router at each layer produces a (K+1)-way softmax over memory banks + null bank. The routing statistics reveal which token-identity signals each layer needs.
  *Replication cost*: N/A (architectural — requires training from scratch).
  *We'd plausibly run this*: no — architectural training modification.

- **Embedding norm as undertrained-token proxy** — Mean L2 norm of embedding vectors correlates monotonically with token frequency; low-norm embeddings are "under-trained."
  *Replication cost*: 5min CPU (just read the embedding matrix from Qwen-2.5-1.5B).
  *We'd plausibly run this*: yes — trivial to extract and correlate with DoM scores.

- **Per-decile loss decomposition** — Stratify held-out cross-entropy by token frequency bin to reveal where models fail differentially.
  *Replication cost*: 1-2h GPU (requires inference on held-out set).
  *We'd plausibly run this*: no — requires new forward passes.

## Approaches & framings

- **Single-injection assumption critique:** The paper frames standard transformers as having a structural deficiency: token identity is injected once and never recovered. This reframes any probe reading hidden states at depth (including our L19 DoM) as reading a signal that has been progressively contaminated by context and deprived of token-specific grounding. Intersects F-2/F-3: the prefill DoM might encode what remains of token identity at L19, not a novel "correctness computation."

- **Lipschitz-bounded FFN as information bottleneck:** The formalization that FFNs cannot separate collapsed representations (Prop 2.2) provides a theoretical lens on why certain layers might be better for probing than others. Layers where collapse hasn't occurred yet (earlier layers) retain more token-specific signal; layers after collapse (deeper layers) have contextual signal only. This could explain the L19 specificity of our correctness signal — L19 may be a "sweet spot" before final collapse.

- **K-pathway gradient amplification as probe diversity:** The idea that K independent pathways into token representations prevent gradient starvation could be abstracted to probing: instead of a single DoM direction, K independent linear probes trained on different subsets/views of the activation space might capture complementary correctness signals (similar in spirit to F-9's CoE-60 vs single-layer comparison).

## Implementation details worth capturing

- Model scales: 350M, 750M, 1B, 3B (LLaMA-style architecture).
- EmbeddingMemory: K ∈ {2, 4, 8, 16, 24} independent blocks, each db-dimensional per token.
- Memory blocks use RMSNorm on embeddings before injection.
- Router: per-layer linear Wr^(ℓ) ∈ R^{(K+1)×d} producing softmax weights.
- NULL bank at slot K+1 = zero vector, learned "off switch."
- Training: 200B tokens, batch size 8, sequence length 2048.
- Key insight: K=2 already delivers ~55% of the total rare-token improvement at K=24.
- VRAM: effectively same as LLaMA-Base-1B (1.03 GB in 8-bit); extra memory goes to SSD.
- Cosine distance between primary embedding E and MemoryBlocks: 0.65–0.99 (blocks learn distinct subspaces).
- NULL-bank weight: 0.530 (rarest decile) to 0.889 (most common decile) — rare tokens get more memory injection.
