# Triage brief — 2502.06884 — Learning Conformal Abstention Policies for Adaptive Risk Management in Large Language and Vision-Language Models

Source: https://arxiv.org/abs/2502.06884
Triaged: 2026-04-29

## Refutations

1. **F-8 selective-prediction at 50% coverage (71.6% acc, K=2.5 avg) is threshold-suboptimal.**
   *Mechanism*: F-8's number is produced by a fixed prefill-DoM threshold tuned on the operating-point sweep. CAP shows that swapping a fixed conformal threshold for a REINFORCE-tuned (α, β) pair lifts AUARC by 20–50 percentage points (e.g., Llama2-7B avg AUARC 0.418 → 0.893) on the *same* underlying softmax scores. If the same machinery is applied to L19 DoM scores from `pathway11_h100/prefill_gated_compute/results.json`, the cov=0.5 / 71.6% number probably understates achievable selective-prediction performance — i.e., F-8's headline reads as a *lower bound* on what threshold-only methods can do, not as a ceiling justifying a richer probe.
   *Falsifiable test*: train a CAP-style 2-threshold REINFORCE policy on cached prefill-DoM scores (CPU, hours), holding model + signal fixed. If AUARC ≥ 0.94 emerges on MATH-500, F-8's "50% coverage" framing needs revising; if not, F-8 is robust.

2. **F-2 prefill L19 DoM AUROC 0.7731 may not exceed a properly-thresholded softmax baseline.**
   *Mechanism*: CAP's nonconformity score is the bare-bones softmax confidence `s(x) = 1 − max_i p_i(x)` — no probe, no residual-stream geometry. The paper reports AUROC 0.7165 on Llama2-7B (5-task avg) and 0.7724 on CosmosQA from this score alone after CAP threshold learning. AUROC is threshold-invariant, but the paper's *baseline* APS/LAC AUROCs (0.46–0.55 avg) reveal that AUROC can be inflated when "hallucination detection" is operationalised via prediction-set membership rather than top-1 correctness. If F-2's 0.7731 comparator is computed against an analogous set-membership target rather than top-1 correctness, the DoM advantage shrinks or evaporates.
   *Falsifiable test*: compute (i) raw softmax-confidence AUROC on Qwen-2.5-1.5B MATH-500 (cached generations in P11 H100 outputs), (ii) DoM AUROC under the *same* correctness label. If softmax matches DoM within 0.02, F-2 is unsupported as written.

3. **H-12 (label-free semantic-entropy probes substitute for supervised DoM at refusal) becomes harder to defend.**
   *Mechanism*: CAP achieves its 22.19% AUROC and 21.17% AUARC gains *only* because it consumes labelled calibration data and a labelled reward signal in REINFORCE. Its strength is direct evidence that calibration-time labels carry substantial information that label-free SEPs cannot recover. If CAP-trained thresholds beat any plausible label-free abstention pipeline by ≥10% AUARC under matched signal, H-12's premise (label-free is competitive) is contradicted.
   *Falsifiable test*: ablate CAP's reward by replacing ground-truth labels with SEP-derived pseudo-labels. If SEP-pseudo-label CAP collapses to APS-baseline AUARC, H-12 is contradicted as a hypothesis worth investing in.

4. **H-19 (C_exact verification routing beats C_infer scaling at matched compute) faces a cheaper non-verification baseline.**
   *Mechanism*: H-19 motivates an expensive self-verification pass (P11-FE19) per problem to drive K=1 vs K=8 routing. CAP demonstrates that learnable threshold-only routing on softmax scores plus a stochastic three-regime policy reaches AUARC ≈ 0.95 on standard benchmarks. If the same RL machinery on prefill-DoM scores gives competitive routing on MATH-500 *without* any verification call, the verification machinery in H-19 is paying for capability already obtainable from threshold-tuning alone.
   *Falsifiable test*: at matched avg-K, compare (a) CAP-trained α/β routing on prefill DoM with (b) verification-routing planned in P11-FE19. If (a) ≥ (b) on accuracy@compute, H-19's verification arm is redundant.

## Methodologies extracted

- **CAP — Conformalized Abstention Policy with REINFORCE** — policy network πθ outputs Gaussian (μ_α, σ_α, μ_β, σ_β); samples α, β as actions; computes two conformal thresholds q̂_predict and q̂_abstain on calibration scores; runs decision rule on test set; uses scalar cost as negative reward.
  *Replication cost*: ~4h CPU on cached softmax / DoM scores, no GPU needed.
  *We'd plausibly run this*: yes — folds directly into P10-FE2 as the "learnable" arm and gives a new selective-prediction baseline for F-8.

- **Three-regime stochastic decision rule (single / set / abstain)** — sigmoid-mapped action probabilities `p_single = σ(−c·(s − q̂_predict))`, `p_abstain = σ(c·(s − q̂_abstain))`, `p_set = 1 − p_single − p_abstain`; sample one action per query.
  *Replication cost*: trivial wrapper over existing scoring functions.
  *We'd plausibly run this*: maybe — set-prediction regime has no clear analogue for free-form MATH-500 (no fixed answer set), but reformulates naturally for K-shot answer-distribution sampling.

- **Cost function `C(α, β) = (1 − acc) + λ₁·avgSet + λ₂·abstention − λ₃·coverage − λ₄·div`** — multi-objective scalarisation with entropy-balance term `div` to prevent collapse to single regime.
  *Replication cost*: trivial (5 lines).
  *We'd plausibly run this*: yes — reusable as the reward design for any RL-based threshold tuner we build.

- **Softmax nonconformity score `s(X, Y) = 1 − p_Y(X)`** — vanilla 0-margin baseline; not novel, but used here as the *only* signal source.
  *Replication cost*: free on cached MATH-500 generations.
  *We'd plausibly run this*: yes — needed as the F-2 / F-8 softmax-AUROC sanity check.

- **LAC and APS conformal baselines** — Least Ambiguous Classifier (set = {Y' : 1 − p(Y') ≤ q̂}) and Adaptive Prediction Set (cumulative softmax mass).
  *Replication cost*: free (off-the-shelf in `mapie` or 20 lines).
  *We'd plausibly run this*: yes — standard comparators we're missing.

## Approaches & framings

- **Abstention-as-RL-policy framing** — recasts the static "calibrated threshold + abstain-if-above" pipeline as a Markov decision process with thresholds-as-actions. Intersects F-8 directly: F-8's 50% coverage is a fixed operating point on a *deterministic* policy; this paper says the relevant object is the *policy*, not the operating point.

- **Three-regime decision (single / set / abstain) replacing binary (predict / abstain)** — adds a middle regime that admits epistemic ambiguity without paying the abstention cost. For MATH-500 this would manifest as "report top-K candidate answers" — a plausible but currently absent output mode in the project.

- **Distribution-free coverage as a *constraint* rather than a *guarantee*** — paper softens the conformal coverage guarantee to a soft target enforced via reward shaping (λ₃·coverage). This is a meaningful theoretical retreat (no longer distribution-free) that the paper does not loudly acknowledge — relevant if anyone wants to *cite* CAP as "conformal" in our docs.

## Implementation details worth capturing

- Code: `https://github.com/sinatayebati/vlm-uncertainty` — reference REINFORCE implementation with policy network architecture and cost-function defaults.
- Policy network: small MLP mapping current calibration-score vector → (μ_α, σ_α, μ_β, σ_β); Gaussian action distribution.
- Action sampling: clip α, β to (0, 1); enforce α < β so q̂_predict < q̂_abstain.
- Sigmoid scaling constant `c` in stochastic action probabilities controls policy smoothness — paper does not tabulate sweep but it's a knob.
- Reward computed on a *separate test split* from calibration; without that split CAP overfits the calibration set.
- Coverage target enforced via λ₃ = 1.0 in paper's experiments; other λs are not tabulated in main text — likely tuned per dataset.
- 90% coverage is the headline target across all reported experiments — must be stated whenever citing CAP numbers, since LAC/APS use the same target.

## Proposed PAPER_INDEX.md classification

## 2502.06884 — Learning Conformal Abstention Policies for Adaptive Risk Management in LLMs/VLMs (Tayebati et al., 2025)

**Relevance:** Proposes CAP (Conformalized Abstention Policy), a REINFORCE-trained policy that learns two conformal thresholds (q̂_predict, q̂_abstain) over softmax-derived nonconformity scores, partitioning each query into single-prediction / set-prediction / abstention regimes. Method is signal-agnostic — it operates on any score function — so it slots cleanly above prefill-DoM, CoE, or any other correctness-predictor we hold. Directly relevant to F-8 (selective prediction) and as an ablation for F-2's softmax-vs-DoM AUROC comparison.

**Key claim we tested:** Learnable thresholds substantially outperform fixed conformal thresholds (LAC, APS) on AUARC, AUROC, ECE, and accuracy at fixed 90% coverage, using only softmax-derived scores.

**Our result:** **TO TEST.** Paper's improvements (AUARC up to +21pp, ECE 70-85% reduction, AUROC up to +22pp on hallucination detection) are reported on multi-choice QA benchmarks (MMLU, CosmosQA, HellaSwag, HaluDial, HaluSum) and VLM benchmarks (MMBench, OODCV-VQA, ScienceQA, SEEDBench, AI2D). They do not transfer trivially to free-form MATH-500. P10-FE53 will run CAP on cached Qwen-2.5-1.5B prefill-DoM scores under MATH-500 1024-tok labels; outcome determines whether F-8's 71.6% at coverage 0.5 understates achievable selective-prediction performance.

**Related experiments:** P10-FE2 (static conformal abstention, TRIGGERED), P10-FE53 (CAP on prefill DoM, READY), P10-FE54 (softmax-AUROC sanity check, READY), P11-FE68 (CAP routing vs verification routing, READY blocked by P11-FE19), H-93, H-94.

### Methodologies
- CAP: REINFORCE policy network outputting Gaussian (α, β) actions over two conformal thresholds.
- Three-regime decision rule with sigmoid-mapped action probabilities (single / set / abstain).
- Cost function `C(α, β) = (1 − acc) + λ₁·avgSet + λ₂·abstention − λ₃·coverage − λ₄·div`.
- Softmax nonconformity `s(X, Y) = 1 − p_Y(X)`.
- LAC and APS conformal baselines.

### Approaches
- Abstention-as-RL-policy reframing.
- Three-regime decision replacing binary predict/abstain.
- Coverage as soft-constraint via reward shaping (loses formal distribution-free guarantee).

### Datasets
- LLM: MMLU, CosmosQA, HellaSwag, HaluDial, HaluSum.
- VLM: MMBench, OODCV-VQA, ScienceQA, SEEDBench, AI2D.
- All multi-choice. Only MMLU is plausibly applicable to text reasoning; none are MATH-500 substitutes.

### Implementation
- Code at `github.com/sinatayebati/vlm-uncertainty`.
- Models tested: LLaVA-v1.6 (7B/13B/34B), MoE-LLaVA-Phi2 (2.7B), Yi-VL-6B, Monkey-Chat-7B, InternLM-XComposer2-VL-7B, CogAgent-VQA-7B, MobileVLM-v2-7B, mPLUG-Owl2-7B, Qwen-VL-Chat-7B, Qwen-7B/14B, Yi-34B, Llama-2-7B/13B.
- Coverage target 1 − α = 0.90 across all reported experiments.
- λ₃ = 1.0 for coverage; other λ values not tabulated in main text.

- Static LAC/APS baselines on same scores: ~30min CPU.
