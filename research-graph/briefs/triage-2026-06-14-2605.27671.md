# Triage brief — 2605.27671 — Evolving and Detecting Multi-Turn Deception using Geometric Signatures

Source: https://arxiv.org/abs/2605.27671
Triaged: 2026-06-14

Authors: Surender Suresh Kumar, Mary L. Cummings (George Mason University, 2026). Categories: stat.ML, cs.LG.

One-line: generates multi-turn "indirectly harmful" question sets via NSGA-II evolutionary prompt optimization, then detects coordinated deceptive intent from a *set* of sentence embeddings using three hand-engineered geometric features (angular coverage, distance ratio, linearity) + 4 pairwise-similarity stats fed to a tiny 3-layer MLP. Test F1 0.74–0.86, recall ~0.89, robust to rewording and 3-turn truncation.

## Refutations

The paper is about deception detection in *sentence-embedding* space, not residual-stream correctness — so refutations come through **method transfer**: its three set-level geometric descriptors are well-defined on any cloud of vectors, including our cached L19 activations. The descriptors are genuinely outside our current feature family (angular coverage and distance ratio are *not* covariance-spectrum or DoM quantities), so they are a fair adversarial probe of our parsimony findings.

1. **Refutes F-10 (shape stats = Gaussian null).** F-10 concluded that topological/shape summary statistics on residual streams are indistinguishable from a matched Gaussian null. The paper's **angular coverage** (`1 − max_{i,j} cos(e_i−t, e_j−t)`) and **distance ratio** (`min_i‖e_i−t‖ / max_i‖e_i−t‖`) encode angular *configuration* relative to a reference point — a quantity a covariance-matched Gaussian does not in general reproduce (a Gaussian fixes second moments but not the min/max angular spread of a finite sample). *Mechanism:* if these descriptors, computed on the cached L19 per-token / per-problem cloud, separate correct-vs-incorrect (or A- vs D-bucket) above the F-10 Gaussian-null permutation floor, then "shape adds nothing over a Gaussian" is false for this descriptor family. *Falsifiable:* compute the 3 features on the cached NPZ, run the exact F-10 permutation/Gaussian-null baseline, compare.

2. **Refutes the cov-spectrum ceiling implicit in F-2 / F-9 (AUROC 0.7928 is the geometry ceiling).** Our headline story is that the correctness geometry collapses to one direction (DoM≈PC1, cos 0.9216) plus the covariance log-eigenvalue spectrum, ceiling 0.7928 (cov-spectrum top-20). The paper's angular coverage and distance ratio are *invariant to eigenvalue magnitudes* — they encode relative configuration, not variance scale — so they are linearly independent of the cov-spectrum feature. *Mechanism:* concatenating angular coverage + distance ratio to the cov-spectrum probe; if AUROC exceeds 0.7928 out-of-fold, "the covariance spectrum is the ceiling" is refuted. *Falsifiable:* one logistic-regression fit on cached features, OOF 5-fold, vs the 0.7928 anchor in `cov_spectrum/pc1_resid_cov_spectrum_results.json`.

3. **Refutes F-4 (asymmetric collapse) via the paper's own metric.** F-4 claims correct trajectories collapse harder than incorrect at the final token. The paper's **linearity** feature `(λ1−λ2)/(λ1+ε)` is exactly a covariance eigengap / anisotropy measure — a clean operationalization of "collapse." *Mechanism:* compute linearity on the correct-group vs incorrect-group final-token clouds; if the two groups are statistically indistinguishable on linearity (or ordered opposite to F-4's prediction), the asymmetric-collapse claim does not survive this specific, well-defined collapse metric. *Falsifiable:* two-sample test on cached final-token activations split by correctness.

4. **(Weaker) Refutes the sufficiency framing of F-8 (supervised DoM needed for selective prediction).** F-8 builds the 50%-coverage / 71.6%-answered selective predictor on the supervised prefill DoM score. The paper shows a **label-light** geometric detector (the 3 features need no correctness labels) that stays robust under truncation (3-turn F1 0.744). *Mechanism:* if an unsupervised shape-feature selective curve matches the DoM-based curve at coverage 0.5, then DoM supervision is not necessary, weakening F-8's framing. *Falsifiable:* build a selective curve from unsupervised shape features and compare to F-8's at matched coverage.

## Direct connections to F-N / H-N

- **F-7 (D-bucket collective, not per-problem, geometric signature; peak PR 67/88).** The paper's central thesis is identical in spirit: deceptive intent is a *set-level* property invisible per-question and only "becomes clear in context" (their deception proxy D divides the whole-set similarity by the mean per-question similarity). This is the deception-detection analogue of F-7's collective-vs-per-problem signature — strong conceptual corroboration and a ready-made set-level featurization to test F-7 with.
- **F-2 (single L19 prefill DoM, AUROC 0.7731) / cov-spectrum 0.7928.** These are the comparison targets for any correctness-prediction transfer of the paper's features.
- **F-3 (prefill/final DoM orthogonality, cos 0.046).** The paper's linearity feature measures whether a set of embeddings is dominated by one axis; applied to per-token trajectories it bears on how "one-directional" the residual path is, intersecting the F-3 orthogonality picture.
- **F-10 (PH/shape = Gaussian null) and F-9 (CoE-60 redundant with L19 DoM).** The paper supplies a *new* shape-descriptor family (angular coverage, distance ratio) not covered by PH summaries or CoE trajectory features — the cleanest available adversary to the parsimony verdict.

## Methodologies extracted

- **Angular coverage** — `1 − max_{i,j} cos(e_i − t, e_j − t)`; how thoroughly a set of vectors "surrounds" a reference/target point t in embedding space.
  *Replication cost*: ~20min CPU on cached NPZ.
  *We'd plausibly run this*: yes — a configuration descriptor genuinely outside our DoM/cov-spectrum family.
- **Distance ratio** — `min_i‖e_i − t‖ / max_i‖e_i − t‖`; spread of nearest-to-farthest distance from the reference.
  *Replication cost*: ~10min CPU.
  *We'd plausibly run this*: yes — eigenvalue-magnitude-invariant, complements cov-spectrum.
- **Linearity (covariance eigengap)** — `(λ1 − λ2)/(λ1 + ε)` on the centered set covariance; dominance of the top PC.
  *Replication cost*: ~10min CPU (we already compute λ-spectra; this is a 1-line derived stat).
  *We'd plausibly run this*: yes — a direct re-test of F-4 collapse asymmetry with the paper's metric.
- **Pairwise cosine-similarity stats (mean/std/min/max)** — 4 scalar summaries of the within-set similarity matrix.
  *Replication cost*: trivial, minutes.
  *We'd plausibly run this*: yes — cheap to bolt onto any cached cloud.
- **7-feature → 3-layer MLP detector (7,16,12,1), ReLU, dropout p=0.5, AdamW, focal loss γ=4, Platt scaling, 70/30 split.**
  *Replication cost*: minutes on CPU once features exist.
  *We'd plausibly run this*: yes, but on n=500 a logistic head is the honest comparator; an MLP risks overfitting at our sample size.
- **NSGA-II multi-objective evolutionary prompt optimization with co-evolving mutation operators (Outlines constrained generation, Pareto deception-vs-adherence trade-off).**
  *Replication cost*: needs new generative pipeline + LLM calls.
  *We'd plausibly run this*: no — off-topic for correctness geometry; the data-generation half of the paper has no bearing on our pipeline.
- **Frozen sentence-embedding (all-MiniLM-L6-v2, 384-d) set-level featurization** — embed each item, derive set geometry rather than train end-to-end.
  *Replication cost*: n/a (we use residual activations, not sentence embeddings).
  *We'd plausibly run this*: no for text embeddings; yes as a design pattern (engineer cheap geometry, fit a small head).

## Approaches & framings

- **Set/collective geometry as the unit of analysis.** Treat the *configuration* of a group of vectors (not any single vector) as the signal. Intersects F-7 directly (collective D-bucket signature) and offers a concrete featurization to operationalize it.
- **Label-light, explainable geometry over end-to-end black boxes.** Hand-engineer a handful of transparent geometric scalars, then fit a tiny head. Intersects F-9/F-10 parsimony debate — a competing claim that *engineered* (not topological) geometry carries robust signal.
- **Invariance-as-evidence ("stable geometric footprint").** A signal that survives rewording and turn-truncation is argued to be semantic, not surface. This is the same robustness-test logic we apply to truncation confounds; useful framing for arguing a residual-stream signal is content- rather than length-driven (touches H-5 familiarity-vs-decomposability and the 256-tok truncation lessons).

## Implementation details worth capturing

- Detector input is a fixed **7-dim** vector (3 geometric + 4 pairwise stats); MLP is tiny (7→16→12→1) with dropout 0.5 and **focal loss γ=4** to handle class imbalance, then **Platt scaling** for calibration, early stopping on F1.
- Features are **well-defined for set size ≥ 3** — the truncation robustness test simply recomputes them on the first 3 of 5 turns. Directly relevant: our per-token/per-problem clouds far exceed size 3, so all features are computable.
- Geometry is referenced to a **target/topic embedding t** (the "task"); for our use we'd substitute t = group mean, final-token state, or the supervised DoM endpoint.
- `ε` guard in linearity to avoid divide-by-zero; cosine *distance* `S=1−cos` used as the similarity proxy.
- Small-n caveat from the authors themselves: deceptive set is tiny, padded with out-of-distribution negatives — the reported F1s likely overstate; treat as a method demo, not a benchmark.

## Replicable intermediates

- **Linearity (eigengap) on cached L19 clouds vs F-4.** We already compute covariance eigenvalues for the cov-spectrum probe (`pathway11_h100/cov_spectrum/pc1_resid_cov_spectrum_results.json`); `(λ1−λ2)/(λ1)` is a one-line derived stat — compute per correct/incorrect group on the cached `pathway11_h100/prefill_gated_compute/` NPZ and two-sample test against F-4's asymmetric-collapse prediction. Minutes.
- **Angular coverage + distance ratio on cached NPZ vs F-10 Gaussian null.** Compute both descriptors on the 500×1536 cached L19 activations (t = group mean), run the existing F-10 Gaussian-null permutation baseline, compare. ~30min CPU.
- **Concatenation lift vs 0.7928.** Append angular coverage + distance ratio to the cov-spectrum feature set, refit logistic OOF 5-fold, compare to the 0.7928 anchor. ~30min CPU.
