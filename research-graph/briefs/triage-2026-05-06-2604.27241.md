# Triage brief — 2604.27241 — Root-to-Leaf Path Random Walks, Normalized Hodge Laplacians, and Cheeger Inequalities on Simplicial Complexes

Source: https://arxiv.org/abs/2604.27241
Triaged: 2026-05-06

## Refutations

1. **Potential refutation of F-10 (PH-at-Gaussian-null via summary statistics):** F-10 established that persistent homology summary statistics on residual streams are indistinguishable from a Gaussian null. The normalized Hodge Laplacian spectral gap (the quantity 1 − λ_max(Δ^up_{k−1})) is a fundamentally different topological invariant from PH Betti numbers or persistence diagrams — it characterizes the "near-coherence" of the simplicial complex rather than counting holes. If one built Vietoris-Rips complexes on L19 prefill activations for correct vs incorrect groups and found that normalized Hodge spectral gaps differ significantly between groups while PH summary statistics do not, this would refute F-10's implicit claim that *all* topological summary statistics are at the Gaussian null. The test: build VR complexes at matched filtration radii, compute the normalized up-Laplacian Δ^up_0 and Δ^up_1, extract spectral gaps, compare correct vs incorrect groups vs Gaussian control. Falsifiable by: spectral gaps matching the Gaussian null distribution just as PH did.

2. **Potential refutation of H-35 (F-10's PH-null is summary-statistic-bound, not topology-bound):** H-35 hypothesizes that F-10's null result is an artifact of using summary statistics (Betti numbers, persistence entropy) rather than a genuine absence of topological signal. The Cheeger constants h^up_k and h^down_k defined in this paper provide a different entry point: they are isoperimetric ratios measuring how far a simplicial complex is from having a coherent component — a topological property related to balanced vs unbalanced orientations, orthogonal to homological information captured by PH. If Cheeger constants also show no correct/incorrect separation, this would strengthen F-10 and weaken H-35: the null extends beyond PH summary statistics to spectral-isoperimetric invariants. Falsifiable by: Cheeger constants showing significant correct/incorrect separation.

3. **Potential refutation of H-47 (zigzag PH on trajectories beats static VR-PH):** H-47 proposes that the PH null (F-10) can be broken by using zigzag persistence on residual-stream *trajectories* across tokens rather than static point clouds. The root-to-leaf path random walk framework in this paper offers a competing alternative: rather than tracking homological persistence across a filtration, one could build a graded signed graph from the layer-wise residual stream (grading = layer index, signature = orientation from boundary operators) and analyze the spectral decomposition of the induced random walk. If this spectral approach separates correct/incorrect better than zigzag PH, it would refute H-47's premise that dynamic-filtration PH is the right tool. Falsifiable by: zigzag PH outperforming Hodge spectral features on the same data.

## Direct connections to F-N / H-N

- **F-10 (PH at Gaussian null, AUROC ≤ chance):** This is the primary connection. The paper introduces normalized Hodge Laplacian spectra as a *different* spectral characterization of simplicial complexes. The Cheeger inequalities bound spectral gaps in terms of combinatorial/topological Cheeger constants that capture "near-coherence" — a property distinct from homological holes that PH measures. In principle this provides a new feature extraction pathway for simplicial complexes built from L19 prefill activations (500 × 1536, AUROC 0.7731 DoM baseline).

- **H-23 (persistence-landscape two-sample test rejects F-10's Gaussian null):** Both H-23 and this paper target the same question — can we extract non-trivial topological signal from residual streams? H-23 uses persistence landscapes; this paper would use Hodge spectral gaps. They are complementary, not redundant.

- **H-35 (F-10's PH-null is summary-statistic-bound):** The normalized Hodge spectral gap is explicitly *not* a PH summary statistic — it comes from the Laplacian of the coboundary operator, not from a persistence module. This makes it a useful test case for H-35.

- **F-1 (dimensional breathing) / F-4 (asymmetric collapse):** The Cheeger constant framework characterizes "how far a simplicial complex is from having a bipartite / coherent structure." If correct-group activations produce complexes that are closer to coherent (lower Cheeger constant) while incorrect-group complexes are not, this would connect to F-4's asymmetric collapse via a topological mechanism.

## Methodologies extracted

- **Normalized Hodge Laplacian spectral gaps** — Given a simplicial complex (e.g. VR complex from point cloud), compute the normalized up-Laplacian Δ^up_k = I − δ_k^T δ_k (with the paper's root-to-leaf-path normalization). Extract λ_max and λ_max−1; the gap 1 − λ_max−1 quantifies near-coherence.
  *Replication cost*: 2-4h CPU for implementation from scratch on cached 500×1536 activations (need to build VR complex, compute boundary operators, normalize, diagonalize). No existing off-the-shelf library implements this specific normalization.
  *We'd plausibly run this*: no — the implementation cost is moderate but the expected signal is very low given F-10's PH null already covers VR complexes on the same data, and spectral gaps of a null VR complex would likely also be null.

- **Cheeger constant computation** — For a simplicial complex, compute the up-Cheeger constant h^up_k = min_{Y ⊂ X_k} ω(Y, X_k\Y) / min(μ(Y), μ(X_k\Y)). This is an NP-hard optimization but can be approximated via the eigenvector of Δ^up_k associated with λ_max−1 (analogous to spectral clustering for graphs).
  *Replication cost*: 1-2h CPU for VR complex + spectral approximation.
  *We'd plausibly run this*: no — same reasoning as above; unlikely to beat the F-10 null.

- **Conditional random up-/down-walks on simplicial complexes** — The paper defines random walks that move between adjacent faces of different dimensions, with transition probabilities weighted by root-to-leaf path counts. The convergence rate of these walks characterizes topological connectivity in a way distinct from PH.
  *Replication cost*: 2-3h CPU for implementation.
  *We'd plausibly run this*: no — pure theory; the random walk on a VR complex built from activations is a very indirect way to probe correctness.

## Approaches & framings

- **Random walks on simplicial complexes as a normalization device:** The paper's central insight is that root-to-leaf path random walks on double covers of graded signed graphs provide a *natural* normalization of the coboundary operator and Hodge Laplacians. This is a more principled normalization than ad hoc choices. Intersects our F-10 framing: if the PH null is partly a normalization artifact (e.g. non-normalized PH features being dominated by degree/scale effects), the paper's normalization could help — but this is speculative.

- **Coherent components as topological structure:** The paper defines "coherent-up-components" and "coherent-down-components" — subsets of faces whose orientations are compatible. This generalizes bipartiteness from graphs to simplicial complexes. No direct intersection with our F-N/H-N framings, but conceptually adjacent to the idea that correct/incorrect activation clouds might differ in their simplicial "balance."
