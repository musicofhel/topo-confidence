# Triage brief — 2312.03813 — Improving Activation Steering in Language Models with Mean-Centring

Source: https://arxiv.org/abs/2312.03813
Triaged: 2026-04-29

## Refutations

1. **Mean-centring may yield a label-free direction that matches or beats supervised L19 DoM, refuting F-2's framing as "the supervised contrast is what matters."**
   - **Mechanism**: Jorgensen et al. show that for an arbitrary target dataset *D_target*, `f ≈ µ_target − µ_training` extracts a usable steering direction without any contrastive label. If we let *D_target* = MATH-500 prompts that the 1.5B model historically gets correct (as a soft-label proxy) and *D_training* = OpenWebText activations, the resulting unsupervised direction at L19 may match the AUROC=0.7731 number. F-2 currently rests on a *supervised* DoM (mean(correct) − mean(incorrect)); if the unsupervised mean-centred direction equals or exceeds it, F-2's framing as "labels carry the predictive signal" is wrong — the predictive signal is mostly the prompt-conditioned mean offset from generic text.
   - **Falsifiable test**: at L19, compute `f_mc = µ(prefill activations on MATH-500 problems) − µ(OpenWebText activations cached at L19)`; project the 500 1.5B prefill activations on `f_mc`; report AUROC against the 1024-tok correctness labels and compare to 0.7731. If AUROC(f_mc) ≥ 0.74, F-2 must be re-stated.

2. **Mean-centring decomposition predicts F-3 (cos(prefill_DoM, final_DoM)=0.046) is partly anisotropy-bias artifact, not "genuinely orthogonal computations."**
   - **Mechanism**: per Eq. 1 of the paper, every activation decomposes as `x_i = α_i·f + b + v_i`, with the bias **b** dominating magnitude and being position-dependent at non-final-layer blocks. Our prefill DoM and final-token DoM are each `mean(correct) − mean(incorrect)` — counterbalanced subtractions, which the paper *conjectures* implicitly perform mean-centring. But the paper never proves this for *position-conditioned* contrasts. If the prefill bias **b**_prefill and the final-token bias **b**_final differ substantially, residual bias leakage in each DoM could push them toward orthogonality irrespective of the underlying functional directions.
   - **Falsifiable test**: at L19 on cached 1.5B activations, compute the position-conditional bias `b_prefill = µ(prefill, all problems)`, `b_final = µ(final, all problems)`. Then compute `DoM_prefill_centred = (µ(correct,prefill) − b_prefill) − (µ(incorrect,prefill) − b_prefill)` (which is identical to the raw DoM, so the residual cross-position bias only matters when comparing across positions). The honest test is: project `b_prefill − b_final` onto `DoM_prefill` and `DoM_final` separately. If both projections are large (>0.5 cosine) and the *residuals* `DoM_prefill − proj_b(DoM_prefill)` and `DoM_final − proj_b(DoM_final)` are *no longer orthogonal* (cos > 0.3), F-3's "orthogonal computations" claim is refuted.

3. **The paper's Llama-2 anisotropy plots (Fig. 5) refute F-1's "universal breathing" framing if the breathing curve is dominated by anisotropic-bias growth, not genuine PR change.**
   - **Mechanism**: Appendix A shows GPT-2 XL anisotropy *grows* across the first few layers, then again in the last few. F-1 reports breathing (PR rises mid-CoT, falls at end) is universal across 1.5B/7B. But the participation ratio is computed on the full activation cloud, including the bias **b**. If we re-compute PR after subtracting the per-layer-per-position training bias `b_{l,t}`, breathing may flatten — meaning the inflation is partly a Pinheiro/Cai-style anisotropy artifact, not a content-conditioned widening of the representational manifold (F-5).
   - **Falsifiable test**: re-extract per-token L19 activations from the 1.5B Stage-2 NPZs, subtract OpenWebText-conditioned `b_{l,t}` (cached or freshly computed on 50 OWT samples per token position), recompute the participation ratio per token. If the temporal PR peak shrinks by >50% relative to the raw breathing curve, F-1's "universal breathing" claim is refuted as anisotropy-driven; if it shrinks by <10%, F-1 stands and the paper's anisotropy concern doesn't extend to PR.

## Methodologies extracted

- **Mean-centred distillation vector** — `f = µ(activations on a target dataset) − µ(activations on a generic training distribution)`, applied at a single layer at the final-token position via `x_l ← x_l + λ·f`.
  *Replication cost*: 30 min CPU on already-cached L19 prefill NPZs, plus a one-time 1h pass to cache OpenWebText activations at L19 (or re-use any existing OWT cache).
  *We'd plausibly run this*: yes — it's the cheapest possible label-free probe and directly tests F-2 + H-12.

- **Logit-lens distillation-vector inspection** — project the extracted vector through the unembedding matrix and read top-5 tokens; mean-centred vectors yield genre-relevant words (enchanted, mystical) while non-centred vectors yield generic-frequency words (unthinkable, enormous, massive).
  *Replication cost*: 5 min CPU on Qwen-2.5-1.5B once we have a steering vector candidate.
  *We'd plausibly run this*: yes — for each candidate L19 direction (DoM, mean-centred f, CoE-60 leading singular vector), report logit-lens top-5. A weak interpretability sanity check we should already be doing.

- **Function-vector extraction on in-context-learning prompts** — for a task `T`, take K few-shot prompts demonstrating `T`, average the residual-stream activation at the last token position, then mean-centre against generic activations; add at layer 15 of GPT-J-6B (or L19 equivalent of Qwen).
  *Replication cost*: 2h CPU per task on cached activations; needs few-shot ICL prompts for whatever task we want to steer (e.g., "verify the answer to this MATH problem").
  *We'd plausibly run this*: yes — H-1 currently lacks a clear target behavior. "Function vector for self-verification" is a concrete proposal: take K paired (problem, correct-answer-with-explanation) ICL examples, mean-centre, see if it lifts MATH-500 K=1 accuracy from 48.6% baseline.

- **Hyperparameter sweep on `(l, λ)` minimising target-side metric** — Appendix D.2; sweep layer index and steering scale, pick best on held-out subset to fairly compare methods.
  *Replication cost*: included in any steering experiment we run; ~grid of 6×6 = 36 forward passes per problem if exhaustive.
  *We'd plausibly run this*: yes — required for any honest H-1 evaluation; matches our existing convention of "hyperparameter sweep before headline claim."

- **Per-layer anisotropy diagnostic via average pairwise cosine similarity** — for each layer, sample N activations, compute pairwise cos sim, plot mean across layers; reveals where bias **b** dominates.
  *Replication cost*: 30 min CPU on cached 1.5B activations across all 28 layers.
  *We'd plausibly run this*: yes — this is the missing diagnostic for refutation 3 above and would inform whether breathing is bias-driven.

## Approaches & framings

- **Anisotropy-as-bias decomposition** (`x_i = α_i·f + b + v_i`): a clean three-term model of residual-stream activations. Maps onto our setup as: `x = α·DoM + b_position + (PH/CoE-60 fluctuation)`. Suggests we should always report DoM AUROC alongside a **bias-corrected** AUROC; failure to do so is a known confound (Cai 2021, Ethayarajh 2019). Directly intersects F-1, F-2, F-3 and re-frames the breathing curve.

- **"Counterbalanced subtraction implicitly performs mean-centring" (paper §5)**: a *conjecture* the paper does not prove. Our DoM is a position-conditioned counterbalanced subtraction; if the conjecture fails for our setting, it would explain why per-position DoM steering (H-1) hasn't yet yielded a clear effect — the residual bias would still rotate the steering vector off the true f.

- **Label-free direction extraction via "target dataset only"**: shifts the framing of probing from supervised contrast to "any sufficiently coherent dataset has a centroid that, after bias removal, captures its essence." If true, our H-12 roster expands and supervised labels become a fallback rather than the canonical method.

## Implementation details worth capturing

- Mean-centred steering applied **at the final token position only**, single layer (paper §2.2 explicit assumption). Our H-1 design should respect this constraint or note the deviation.
- Llama-2 7B genre steering: `l=25, λ=3` (Table 2). Llama-2 7B layer 25 of 32 ≈ 78%-depth; for Qwen-2.5-1.5B (28 layers), 78%-depth ≈ L22, slightly above our L19.
- Story-continuation hyperparams: `l=3, λ=60` (Fig. 3 caption) — early-layer steering with very high scale; suggests the optimal layer for "stylistic" steering differs from "function" steering, and ours (correctness) may be in yet another regime.
- Function vectors: GPT-J-6B layer 15 of 28 ≈ 53%-depth = mid-layer; this is closer to our L19/28 = 68%.
- Anisotropy diagnostic uses 50 OpenWebText samples × first 100 tokens per sample for the larger models — small enough that we can replicate in <1h on a 2060.
- The paper does NOT release code (no GitHub link in the references); reimplementation needed. Algorithm 1 is fully specified, ~30 lines.

## Replicable intermediates

- **OWT-bias-subtraction sanity check on existing L19 prefill cache**: load Stage-2 1.5B prefill NPZ at L19 (already cached, see DATA_MANIFEST), compute `µ_correct`, `µ_incorrect`, `µ_all_500` = approx of `µ_target` for "correct on MATH" if we use accuracy ≥ 0.5 threshold; compute `µ_OWT_L19` from a cached or freshly-computed OWT pass; report cosine similarity `cos(DoM, f_mc)` where `f_mc = µ_correct − µ_OWT`. If `cos > 0.9`, our DoM is already mean-centred; if `cos < 0.5`, we've been carrying bias and refutation 1 fires.
- **Position-conditional bias projection**: same NPZs, compute `b_prefill`, `b_final` per the refutation-2 protocol; project onto each DoM; report magnitude of residual orthogonality.
- **Per-layer pairwise cos-sim on Qwen-2.5-1.5B activations**: 50 OWT samples × 100 tokens × 28 layers, plot anisotropy; ~30 min CPU; lets us position Qwen between Llama-2 (low anisotropy) and GPT-2 (high) on the paper's Fig. 5–6 axes.

**Relevance:** Direct method paper on residual-stream steering vector extraction. Proposes `f = µ(target dataset) − µ(training dataset)` as a label-free alternative to ActAdd-style counterbalanced subtraction. The core anisotropy decomposition `x_i = α_i·f + b + v_i` is directly relevant to our F-1/F-2/F-3 analyses; the paper's §5 conjecture that counterbalanced subtraction "implicitly performs mean-centring" is a load-bearing assumption we have not tested for our position-conditioned DoM. Paper does not release code; method is ~30 lines per Algorithm 1.

For our project, the analogous claim is: a label-free L19 direction (correct prompts vs OpenWebText) should match the supervised DoM AUROC of 0.7731.

**Our result:** **TO TEST** — the relevant cross-check (P11-FE81, H-83) has not been run yet. The supervised DoM (mean(correct) − mean(incorrect)) is a counterbalanced subtraction, which the paper conjectures implicitly performs mean-centring; our setting (position-conditioned, correctness-rather-than-style contrast) is outside the paper's tested regimes, so the conjecture must be tested explicitly. P11-FE82 additionally tests whether F-3's orthogonality survives anisotropy-bias correction.

**Related experiments:** P11-FE81 (label-free DoM AUROC), P11-FE82 (F-3 bias correction), P11-FE83 (bias-corrected breathing curve), H-83, H-84.
