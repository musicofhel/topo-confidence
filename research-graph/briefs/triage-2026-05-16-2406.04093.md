# Triage brief — 2406.04093 — Scaling and Evaluating Sparse Autoencoders

Source: https://arxiv.org/abs/2406.04093
Triaged: 2026-05-16

## Refutations

**R1 — F-2 "single direction" may be superposition artifact.**
The SAE framework demonstrates that apparent single directions in activation space are typically superpositions of many sparse features (the paper trains 16M-latent dictionaries to decompose GPT-4 residuals). If L19 prefill DoM (AUROC 0.7731) decomposes into multiple SAE latents with distinct functional roles (e.g., arithmetic familiarity, notation parsing, problem length encoding), then F-2's "single direction predicts correctness" framing is misleadingly simple — the linear probe succeeds because multiple independent features happen to align, not because geometry carries a unified correctness signal. *Falsifiable:* train SAE on L19 Qwen-2.5-1.5B activations over >>500 samples; if ≥3 latents each carry partial correctness signal summing above 0.7731, F-2's single-direction interpretation fails.

**R2 — Cov-spectrum ceiling (0.7928) is artificially low in a PCA basis.**
The paper shows probe-based feature recovery improves monotonically with dictionary overcompleteness. Our PCA basis is constrained to 1536 orthogonal directions. If the true feature count at L19 is >> 1536 (as the paper's scaling laws suggest for transformer residual streams), PCA components are mixtures of features, and the cov-spectrum's top-20 log-eigenvalue AUROC 0.7928 is far from the true ceiling accessible via a sparse overcomplete basis. This would refute the implicit assumption (underlying F-2 and the cov-spectrum work) that PCA-ordered variance captures the informative geometry. *Falsifiable:* compare SAE-latent-based correctness AUROC to cov-spectrum 0.7928 on same L19 data; if SAE ceiling exceeds 0.82, the covariance framing is fundamentally incomplete.

**R3 — F-4 "asymmetric collapse" may be an L0-sparsity effect, not geometry.**
The paper's ablation sparsity metric (L1/L2 ratio of downstream effects) shows that features have sparse causal impact. If incorrect samples at the final token activate fewer SAE latents (lower L0) than correct samples, the observed "collapse" in residual-stream space is better explained as dimensionality reduction in feature space — fewer active features = lower effective rank = apparent geometric collapse. This would reframe F-4 from a geometric finding to a feature-counting one. *Falsifiable:* measure L0 (number of active SAE latents) for correct vs incorrect at final token; if L0(incorrect) < L0(correct) with effect size explaining the collapse magnitude, geometry is epiphenomenal.

**R4 — F-3 orthogonality (cos=0.046) could be mixture-weight artifact.**
Under superposition, prefill and final-token activations share many of the same latent features but activate them in different proportions. If the DoM at each position is a weighted sum of shared features with different coefficients, near-zero cosine between the two DoM vectors is a natural consequence of different mixing weights — not evidence of "structurally different signals." *Falsifiable:* decompose both DoMs into an SAE basis; if ≥50% of latents with high weight in prefill-DoM also appear (with different weight) in final-DoM, the orthogonality is a mixing artifact and F-3's "structural" interpretation weakens.

## Direct connections to F-N / H-N

- **F-2 (L19 DoM AUROC 0.7731):** The SAE evaluation framework uses single-latent logistic probes (weight + bias) to measure feature quality. Our DoM is functionally identical to the best single-direction probe; the paper's scaling laws predict that overcomplete dictionaries will find latents that outperform any single PCA direction (i.e., that 0.7731 is below the sparse-feature ceiling).

- **F-10 (PH null — topology adds nothing beyond covariance):** The SAE perspective offers a clean explanation: if activations are sparse combinations of near-orthogonal features, the point cloud is a union of low-dimensional subspaces, not a manifold with topological structure. PH expects holes/voids from manifold geometry; sparse superposition produces a different kind of structure (high-dimensional polytope corners) that PH wouldn't detect. This aligns with F-10 rather than contradicting it.

- **H-4 (Breathing ↔ Sharpness Dimension):** The paper's "progressive codes" finding — that latent ordering by activation magnitude gives a natural compression hierarchy — connects to dimensional breathing. If breathing is the layer-wise expansion/contraction of active feature count (L0), Sharpness Dimension might measure a related quantity in the SAE basis.

- **F-9 (CoE-60 redundant with L19 DoM):** Under superposition, multi-layer trajectory features (CoE) are mixtures of the same underlying sparse features across layers. If L19 already has high activation magnitude for the correctness-predictive latents, additional layers add only noise — explaining CoE-60's redundancy.

- **cos(DoM, PC1) = 0.9216:** The paper shows SAE latents can align with principal variance directions. If the dominant sparse feature at L19 (the one most active overall) also happens to be correctness-predictive, it would explain why PC1 ≈ DoM — both capture the same latent's axis.

## Methodologies extracted

- **k-Sparse Autoencoder (TopK activation)** — Replace ReLU+L1 with TopK gating: z = TopK(W_enc(x - b_pre)), x̂ = W_dec·z + b_pre. Loss is pure MSE; sparsity is architectural.
  *Replication cost*: 2–4h H100 for a small (8192-latent) SAE on Qwen-2.5-1.5B L19 activations over ~1B tokens; or 20min CPU for a toy 256-latent version on our 500 cached samples (underpowered but directional).
  *We'd plausibly run this*: yes — a pre-trained open-source SAE for Qwen or a small custom one could directly test whether DoM decomposes.

- **AuxK dead-latent loss** — Train dead latents to reconstruct the residual error from main TopK: L_aux = ||e - ê_dead||² with coefficient 1/32. Flags dead if inactive for 10M tokens.
  *Replication cost*: adds ~10% compute overhead to SAE training.
  *We'd plausibly run this*: yes, if we train an SAE.

- **Ablation sparsity metric (L1/L2 ratio)** — Measures how sparsely a feature's downstream effects are distributed: (L₁/L₂)² / (V·T). Applied to logit-level effects of individual features.
  *Replication cost*: 5min CPU if we have cached logit differences; 30min H100 for fresh forward passes with feature ablation.
  *We'd plausibly run this*: yes — can adapt to measure sparsity of DoM's causal effect on output distribution.

- **Progressive codes / Multi-TopK** — Order latents by activation magnitude; measure reconstruction quality as function of k. Multi-TopK trains combined L(k) + L(4k)/8 for smooth progressive behavior.
  *Replication cost*: 10min CPU to apply this idea to PCA components on cached activations.
  *We'd plausibly run this*: yes — immediate analog: plot AUROC(k) as we keep top-k PCA components per sample.

- **Probe-based feature recovery** — Single-latent binary probes (1D logistic regression per latent) against curated ground-truth features. Measures precision and recall.
  *Replication cost*: 5min CPU once we have latent activations.
  *We'd plausibly run this*: yes — directly applicable to comparing SAE latents vs DoM for correctness classification.

- **Downstream loss substitution** — Replace true activations with SAE reconstructions, measure KL divergence to original model output as function of SAE capacity.
  *Replication cost*: 2h H100 (requires full model forward pass with modified activations).
  *We'd plausibly run this*: yes — measures how much geometric information is needed for model behavior.

## Approaches & framings

- **Superposition as default geometry:** The paper assumes residual streams are overcomplete representations where many more features exist than dimensions — the "superposition hypothesis." This reframes our PCA/covariance approach as operating in the wrong basis for feature identification, since PCA captures variance structure while SAEs capture sparse feature structure.

- **Reconstruction vs. downstream faithfulness tradeoff:** The paper separates MSE (how well you reconstruct) from downstream loss (how well the model still works). This distinction maps onto our setup: DoM might be high-variance (high reconstruction importance) without being high-downstream-impact (causally necessary for correctness). The paper's evaluation methodology could disambiguate.

- **Sparsity-interpretability-faithfulness trilemma:** The paper shows increasing L0 improves probe recovery but hurts token-pattern explanability. Applied to our work: the DoM might be "faithful" (captures downstream-relevant signal) but not "interpretable" (it's a mixture) and not "sparse" (it activates for everything). Different evaluation criteria favor different representations.

## Implementation details worth capturing

- Input normalization: subtract running mean, divide by running norm before encoding. Critical for training stability.
- Decoder columns constrained to unit norm after each step (not just at init).
- Learning rate scales as 1/√n (n = dictionary size). Convergence-optimal is 4× smaller than compute-optimal.
- Convergence tokens scale as Θ(n^0.6) — a 4096-latent SAE needs ~few hundred million tokens.
- AuxK coefficient α = 1/32 with k_aux = 512 typically.
- Dead latent threshold: 10M tokens without activation.
- Code released at github.com/openai/sparse_autoencoder (open-source training implementation).

Tests whether correctness signal is sparse in PCA space. Script: adapt `pathway11_h100/pca_covariance/` code.
- **L1/L2 sparsity ratio comparison:** Compute per-sample L1/L2 norm ratio of L19 activations for correct vs incorrect groups. If incorrect samples are sparser (lower L1/L2), this supports the "collapse = fewer features" interpretation. Data: cached `pathway11_h100/` NPZs.
- **Progressive reconstruction AUROC:** Add PCA components in order of eigenvalue magnitude, measure correctness AUROC at each step. We already have 2-feat (PC1, PC9) = 0.7856; this extends the curve to all 1536 components.
