# Triage brief — 2605.26733 — STARS: Stabilizing Recurrent Dynamics for Test-Time Scalable Latent Reasoning in Looped Language Models

Source: https://arxiv.org/abs/2605.26733
Triaged: 2026-06-14

Authors: Xiao-Wen Yang, Ziyu Han, Xi-Hua Zhang, Wen-Da Wei, Jie-Jing Shao, Lan-Zhe Guo, Yu-Feng Li (Nanjing University, 2026). Code: https://github.com/njuyxw/STARS

**One-line:** Looped Language Models (LoopLMs) recur a shared block at test time; their accuracy "peaks at a certain iteration depth and then collapses with further recurrence." STARS reframes reasoning as *uncertainty reduction toward an asymptotically stable fixed point* and trains a **Jacobian Spectral Radius (JSR) regularizer** (spectral radius < 1 ⇒ asymptotic stability, estimated with random loop sampling) so deeper recurrence keeps helping instead of diverging. Tested on Gemma/Llama/Qwen-class models on GSM8K and MATH/NuminaMath.

## Refutations

1. **Refutes the mechanistic account of F-2 (single L19 prefill DoM ⇒ AUROC 0.7731).** STARS's thesis is that the *correctness-relevant* quantity is a **dynamical-systems property** — how fast and how stably a representation converges to a fixed point — not a fixed linear direction in one layer. *Mechanism:* if we treat the transformer's 28-layer residual stack as a discrete iterated map (the Universal-Transformer / iterative-inference view), then a per-problem convergence-rate or spectral-radius statistic should carry the correctness signal, and the L19 DoM projection is merely one scalar shadow of it. *Falsifiable:* compute a layer-as-iteration convergence-rate metric (geometric decay of `||h_{L+1}-h_L||`) on the cached layer-wise residuals and a leading-eigenvalue / spectral-radius proxy on the cached covariance spectrum; if either reaches AUROC > 0.7731 **and** the L19 DoM residualizes away under it, F-2's "single linear direction" framing is mechanistically incomplete.

2. **Refutes the interpretation of F-4 (correct trajectories "collapse harder" at the final token).** STARS holds that *collapse from over-recurrence is the failure mode* and that **stable convergence — not collapse — is what good reasoning looks like**. *Mechanism:* F-4 reads shrinking late-stage geometry as a correctness signature, but STARS predicts the opposite sign — a stable fixed-point approach (residual deltas decaying geometrically, spectral radius < 1, rank preserved) rather than a rank-destroying collapse. If the correct group is in fact *converging* (bounded, stable) while the incorrect group is *diverging/oscillating*, then F-4's "asymmetric collapse" label mis-describes the dynamics. *Falsifiable:* on cached layer trajectories, classify each problem's late-layer dynamics as converging vs collapsing (residual-delta decay ratio + effective-rank trajectory); test whether the correct group is "stable-convergent" rather than "harder-collapsing." (Directly adjacent to the already-queued H-954 eigengap operationalization of F-4.)

3. **Undercuts H-4 (dimensional breathing ↔ Sharpness Dimension / Edge-of-Stability *training* dynamics).** H-4 ties breathing to a **training-time** EoS sharpness signature. STARS supplies a competing **inference-time** stability account: the relevant spectral object is the *test-time* Jacobian spectral radius of the recurrent/iterated map, with no appeal to training sharpness. *Mechanism:* if per-problem breathing amplitude tracks a test-time spectral-radius proxy computed purely from cached activations (no training-loss curvature anywhere), then attributing breathing to training-EoS sharpness is misdirected. *Falsifiable:* correlate cached breathing amplitude (F-1) with the spectral-radius / convergence-rate proxy from Refutation 1; a strong inference-time correlation with no training-time term weakens H-4's EoS framing.

4. **Challenges H-17 (DoM rotation across generation is RoPE-mechanical, not computed).** STARS treats the depth-wise evolution of latent states as a *computed* convergence process toward a fixed point. *Mechanism:* if a fixed-point-convergence model explains the directional rotation better than a RoPE-phase null, the "mechanical, not computed" verdict is contradicted. *Falsifiable:* fit a contraction-map model (`h_{t+1} ≈ A h_t + b`, ‖A‖ < 1) to cached prefill→final trajectories; if convergence-residual predicts correctness and out-explains a RoPE-rotation null, H-17 flips.

## Methodologies extracted

- **Jacobian Spectral Radius (JSR) regularization** — penalize the spectral radius of the recurrent block's Jacobian toward < 1 to guarantee asymptotic stability of the iterated map; estimated via random loop sampling (and, by convention in this literature, power iteration on Jacobian-vector products). *Replication cost:* the *training* regularizer needs an H100 + a looped architecture; but a **read-only spectral-radius proxy** on cached trajectories is ~20–40min CPU. *We'd plausibly run this:* yes (the read-only proxy) — directly tests Refutations 1/3/4 against F-2/H-4.
- **Reasoning-as-uncertainty-reduction metric** — per-iteration uncertainty/convergence signal used to define "converged." *Replication cost:* 15–30min CPU to compute an analogue (entropy or dispersion reduction) on cached prefill→final features. *We'd plausibly run this:* yes — overlaps CoE (F-9) and the selective stack (F-8).
- **Residual / fixed-point distance `||h_{t+1} − h_t||` across recurrence** — convergence diagnostic across loop depth. *Replication cost:* ~10–20min CPU using layer index as the depth axis on cached per-layer residuals. *We'd plausibly run this:* yes — cheap, directly probes F-4.
- **Random loop-depth sampling at train time** — stochastic recurrence count to regularize across depths. *Replication cost:* H100 + looped model. *We'd plausibly run this:* no (training-time, needs looped arch we don't run locally).

## Approaches & framings

- **Reasoning = convergence to an asymptotically stable fixed point.** Recasts "is this answer reliable?" as "did the latent state converge stably or diverge?" — intersects F-2/F-4/F-9 by offering a dynamical-systems generative model for the linear DoM readout we already exploit.
- **Stability–effectiveness trade-off across recurrence depth.** Performance peaks then collapses with depth; the peak-and-collapse curve is itself a per-model signature. Intersects F-4 (collapse) and the test-time-scaling angle of F-8/H-19.
- **Spectral radius as a *control* knob, not just a *diagnostic*.** STARS doesn't only measure stability, it trains for it — reframes our purely observational geometry program (REFUTED premise `dom-causal-lever`) by relocating the causal lever from a *direction* to a *spectral property of the dynamics*. This is the genuinely new framing: our causal-lever refutations targeted directions, not spectral radius.

## Implementation details worth capturing

- Code released: **https://github.com/njuyxw/STARS** — check for the JSR loss implementation, the power-iteration / random-loop-sampling estimator, and the convergence/uncertainty metric definition (the three items the PDF would not surface legibly).
- Architectures: Looped/recurrent-block variants of Gemma, Llama, Qwen2/Qwen3 — our cached data is non-looped Qwen-2.5-1.5B, so the *method* transfers only as a layer-as-iteration analogue, not as a drop-in.
- Spectral-radius estimation: expect power iteration on Jacobian-vector products (autograd `vjp`/`jvp`); "random loop sampling" amortizes the regularizer across recurrence depths to keep training cheap.
- Gotcha: the peak-then-collapse curve means *more recurrence is not monotonically better* without the regularizer — any naive "loop more = better" experiment will see the collapse, which is exactly the phenomenon to measure.
