# Triage brief — 1207.6437 — Statistical Topological Data Analysis Using Persistence Landscapes

Source: https://arxiv.org/abs/1207.6437
Triaged: 2026-04-29

Author: Peter Bubenik. Submitted 2012; published JMLR 2015. Foundational
methodology paper introducing persistence landscapes — a vector-space-valued
summary of a persistence diagram, with stability theorem and Banach-space
LLN/CLT enabling classical hypothesis tests on PH outputs.

## Refutations

1. **F-10 (PH on trained residual streams is at Gaussian null) is power-limited
   rather than substantive.** Mechanism: F-10 / EXP-026 / EXP-018 ruled PH a
   NO-GO using *scalar* persistence-diagram summaries (total persistence, max
   persistence, bottleneck distance to Gaussian). Bubenik shows that mapping a
   diagram to its landscape λ_k(t) produces a Banach-space-valued random
   variable obeying a CLT, so a *functional* two-sample test on landscape
   integrals has strictly higher power than scalar diagram-distance tests.
   Falsifiable experiment: take the cached Pathway 8 layer-wise PH outputs that
   underlie F-10, compute λ_1…λ_5 landscapes per problem, run a permutation
   two-sample test of mean L²-landscape between trained-stream and Gaussian
   samples; if p < 0.01 across ≥ 3 layers, F-10's null is rejected as a
   summary-statistic artifact, not a geometric one.

2. **F-9 (CoE-60 features are redundant with single-layer L19 DoM, AUROC
   0.7731) is refuted if landscape features beat DoM.** Mechanism: the
   pathway-7 / pathway-8 NO-GOs (0.774 < 0.7961, EXP-018; "PH at null", F-10)
   used scalar PH summaries as classifier features, so PH "carrying no signal
   beyond DoM" is conditional on that featurisation. Landscapes vectorise the
   diagram into a functional space amenable to ordinary linear / kernel
   classifiers — the open question is whether a logistic regression on
   landscape-vectorised L19 PH ≥ 0.7731 AUROC on the MATH-500 1.5B
   correct-vs-incorrect split. Falsifiable experiment: λ-vectorise the cached
   L19 PH per problem, fit OOF 5-fold logistic regression vs correctness,
   compare to the 0.7731 prefill-DoM headline. > 0.7731 refutes F-9; ≤ refutes
   the speculative "richer summary helps".

3. **F-7 (D-bucket has a distinctive collective geometric signature) is
   refuted if bucket-level landscape distance is null.** Mechanism: F-7 is
   under-mechanised — we know the four buckets (A/B/C/D) differ collectively
   but not by *what* geometric primitive. Bubenik's λ-CLT lets us run a
   bucket-vs-bucket two-sample test on persistence landscapes derived from
   each problem's residual stream, with valid p-values. If A-vs-D and B-vs-D
   landscape tests fail to reject (p > 0.1), the F-7 signature is *not*
   topological in the persistent-homology / landscape sense and the "collective
   geometric" framing is misleading; if they reject and identify a specific
   homological dimension, F-7 gains the mechanistic explanation it currently
   lacks. Falsifiable in ~2h CPU on cached NPZs.

## Methodologies extracted

- **Persistence landscape λ_k(t)** — for a persistence diagram with bars
  {(b_i, d_i)}, define f_i(t) = max(0, min(t−b_i, d_i−t)) and
  λ_k(t) = k-th largest of {f_i(t)}. Each λ_k is a piecewise-linear function
  on ℝ, concretely representable as a list of (peak, value) tuples. A whole
  diagram becomes the sequence (λ_1, λ_2, …) ∈ L^p(ℝ × ℕ).
  *Replication cost*: < 5 min CPU per layer, given cached PH bars.
  *We'd plausibly run this*: yes — it is the missing featurisation between
  Pathway 8's PH outputs and a downstream classifier.

- **L²-landscape two-sample permutation test** — compute mean landscape
  λ̄_A − λ̄_B from two samples, permute labels B times, compare observed
  L²-norm to permutation null. Direct functional analogue of t-test.
  *Replication cost*: 20 min CPU per (layer × bucket pair) on cached NPZs.
  *We'd plausibly run this*: yes — primary statistic for the F-10 / F-7
  refutation experiments.

- **Mean landscape (functional CLT)** — λ̄_n = (1/n) Σ λ_i converges in
  Banach space; pointwise confidence bands derivable. Useful for visualising
  bucket-level "average" PH signatures.
  *Replication cost*: trivial (< 1 min) once landscapes computed.
  *We'd plausibly run this*: yes — diagnostic plot to ship alongside any
  F-7 / F-10 reanalysis.

- **L^p-distance lower bounds for bottleneck/Wasserstein** — `||λ_A − λ_B||_∞
  ≤ d_B(A, B)` and analogous Lp/Wasserstein chains, so a non-zero landscape
  distance gives a certified lower bound on bottleneck distance without
  computing the (expensive) Hungarian-style matching.
  *Replication cost*: free — by-product of landscape computation.
  *We'd plausibly run this*: yes — replaces the bottleneck-distance compute
  bottleneck that has historically been the slow leg of layer-wise PH.

- **Landscape kernel features for classifiers** — vectorise λ_k on a finite
  grid → R^{K·M} feature; feed into logistic / kernel SVM.
  *Replication cost*: < 10 min on existing P8/P11 H100-cached PH outputs.
  *We'd plausibly run this*: yes — the F-9 refutation experiment.

## Approaches & framings

- **Vector-space summary instead of diagram-space summary.** Reframes PH
  output from "a multiset of bars in ℝ²" (no native arithmetic) to "a function
  in a Banach space" (means, variances, t-tests defined). This intersects
  directly with our F-9 / F-10 work, which currently relies on hand-rolled
  scalar summaries.
- **Functional data analysis as the natural home for TDA pipelines.** Reframes
  TDA + ML as functional regression / functional classification rather than
  ad-hoc scalar feature engineering.
- **Stability via L^∞ landscape distance.** Reframes the stability theorem from
  "diagrams are close in bottleneck" to "landscapes are close in sup-norm",
  enabling certified noise bounds without the bottleneck-matching cost.
- **PH-as-FDA** would re-cast the EXP-018 NO-GO not as "PH carries no signal"
  but as "scalar PH summaries carry no signal beyond DoM" — a much weaker
  claim than the current PROJECT_RECORD §1d graveyard line.

## Implementation details worth capturing

- **λ_k closed form**: from a sorted list of bars, λ_k(t) at any t is computed
  by sorting {f_i(t)} and taking the k-th element — vectorisable in NumPy.
- **Discretisation**: in practice λ_k is sampled on a grid of M points (paper
  uses M = 500–1000 for diagrams of ~100 bars). Memory ~ K · M floats per
  diagram.
- **Existing libraries**: `gudhi.representations.PersistenceLandscape` (Python)
  and `tdatools` / `TDA` (R) implement λ_k and L^p norms directly. We already
  depend on `gudhi` in pathway 8 — the upgrade is one import.
- **Computational gotcha**: landscape arithmetic requires aligning grids
  across diagrams; mismatched t-domains silently cause shape errors. Always
  pre-compute a global grid spanning the union of all (b, d) values before
  vectorising.
- **No code released by Bubenik directly with the 2012 preprint**; reference
  R package `tdatools` (Bubenik 2017) is the canonical author implementation.

## 1207.6437 — Statistical Topological Data Analysis Using Persistence Landscapes (Bubenik, 2012/JMLR 2015)

**Relevance:** Foundational methodology paper introducing persistence
landscapes — a vector-space-valued summary of a persistence diagram with
strong stability theorem and Banach-space LLN/CLT. The paper is the missing
tool between our cached Pathway 8 PH outputs and the kind of *functional*
two-sample test that could discriminate trained-stream PH from Gaussian-PH at
power higher than the scalar diagram-summary tests we have run to date.

**Key claim we tested:** Mapping PH outputs to landscapes preserves the
stability of the diagram (||λ_A − λ_B||_∞ ≤ d_B(A, B)) while making them
classical-statistics-friendly, so functional permutation / t-tests on
landscapes are well-defined and sometimes strictly more powerful than
diagram-distance tests.

applied to our PH outputs. F-10 (PH at Gaussian null), the EXP-018 non-
Euclidean PH NO-GO, and F-9 (CoE-60 redundant with DoM) all rest on scalar
PH summaries — landscape replications (P11-FE71 / FE72 / FE73) are the
necessary refutation tests before promoting F-10 from "PH at null" to "PH at
null even under the strongest available statistic". Until those run, the
paper sits as motivation for H-723 / H-724, not a tested-against citation.
