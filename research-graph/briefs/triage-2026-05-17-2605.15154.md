# Triage brief — 2605.15154 — RoSHAP: A Distributional Framework and Robust Metric for Stable Feature Attribution

Source: https://arxiv.org/abs/2605.15154
Triaged: 2026-05-17

## Refutations

1. **F-2 (single L19 prefill direction predicts correctness at AUROC 0.7731):** RoSHAP's bootstrap-stability framework could reveal that the DoM direction is *unstable* across bootstrap resamples of the 500-sample MATH-500 set. If the 5-fold OOF procedure that produces AUROC 0.7731 has high variance under resampling — i.e., the direction's contribution has high P0 (inactivity on some resamples) or low signal-to-noise (large s_j relative to m_j) — then F-2's headline number may be an overfit artifact of a single partition. Mechanism: compute per-dimension RoSHAP scores for the 1536 L19 features under repeated bootstrap logistic-regression probes; if the DoM-aligned dimension ranks poorly on RoSHAP (high instability), the "single direction" framing overstates robustness. Falsifiable via: 200-bootstrap RoSHAP scoring of all 1536 dimensions — if DoM-dimension stability ranks outside top-20, refutation fires.

2. **F-8 (selective prediction at 50% coverage, 71.6% accuracy):** RoSHAP's distributional view implies that threshold-based abstention built on an unstable feature attribution will produce unstable coverage-accuracy tradeoffs. If the DoM-based confidence score used for selective prediction has high between-resample variance (i.e., different bootstrap probes yield coverage=0.5 accuracy spread ≥±3%), then F-8's reported 71.6% is poorly calibrated. Mechanism: bootstrap the entire probe-then-threshold pipeline; measure the standard deviation of accuracy-at-50%-coverage across 100+ resamples. Falsifiable via: if SD(accuracy@50%) > 3% absolute, refutation fires.

3. **cos(DoM, PC1) = 0.9216 alignment may reflect instability ceiling:** RoSHAP's framework distinguishes features that are "consistently active" from those that appear strong by chance in single runs. If the supervised DoM direction jitters substantially across resamples (high SHAP variance), while unsupervised PC1 is deterministic (zero variance by construction from full-sample PCA), then the cos=0.9216 alignment is an artifact of DoM being pulled toward PC1 by noise rather than reflecting a deep structure (CAST PC1 ≈ supervised DoM). Mechanism: compute bootstrap distribution of cos(DoM_b, PC1) across B resamples. Falsifiable via: if SD(cos) > 0.15, the "structural alignment" claim in F-2 weakens substantially.

## Direct connections to F-N / H-N

- **F-2 (AUROC 0.7731, cos(DoM,PC1)=0.9216):** RoSHAP's (1−P0)·m²/s metric directly quantifies whether the DoM direction's predictive power is "active, strong, AND stable." Our current evaluation uses only magnitude (AUROC) without a stability dimension. RoSHAP adds the missing robustness axis.

- **F-7 (D-bucket collective geometric signature):** The D-bucket finding relies on aggregated geometry over a subpopulation of problems. RoSHAP's distributional framework could test whether the D-bucket signature is stable under bootstrap subsampling of the ≈30% difficulty-bucket problems, or whether it's driven by a few outlier problems.

- **F-10 (PH null vs Gaussian):** RoSHAP's Lyapunov CLT result (aggregated feature attribution → Gaussian) is conceptually aligned with F-10's finding that residual-stream summary statistics are Gaussian-like. Both point toward "high-dimensional aggregates converge to Gaussian" as a null model.

- **H-5 (prefill signal encodes problem familiarity vs decomposability):** If RoSHAP-ranked features partition into "familiarity-encoding" vs "decomposability-encoding" subsets with different stability profiles, this would operationalize H-5's distinction.

## Methodologies extracted

- **Bootstrap-based SHAP distribution estimation** — Resample data B times, refit model, compute SHAP values on OOB samples; collect per-feature empirical distribution of attribution scores.
  *Replication cost*: 20–40min CPU (500 samples × 1536 dims × logistic regression probe × 200 bootstrap runs).
  *We'd plausibly run this*: yes — direct application to cached activations with sklearn + shap libraries.

- **RoSHAP metric: (1−P0)·m²/s** — Composite score combining activity (proportion of nonzero attributions), strength (median nonzero magnitude), and stability (inverse coefficient of variation). Rank features by this metric rather than single-run absolute SHAP.
  *Replication cost*: 5min CPU once SHAP distributions are computed.
  *We'd plausibly run this*: yes — trivial formula applied to bootstrap SHAP outputs.

- **Zero-inflated Gaussian modeling of SHAP values** — Decompose T_ij = (1−B_ij)·H_ij where B is Bernoulli(w) indicator of zero attribution and H is nonzero magnitude. Separates sparsity from magnitude.
  *Replication cost*: 10min CPU.
  *We'd plausibly run this*: yes — useful for understanding which L19 dimensions are "always active" vs "sometimes active" for correctness prediction.

- **Lyapunov CLT for feature-level aggregation** — Under mild conditions (no single observation dominates variance), aggregated feature-level attributions are asymptotically Gaussian → justifies mean+SD summary without full KDE.
  *Replication cost*: 5min verification (check conditions on our data).
  *We'd plausibly run this*: yes — if conditions hold, can reduce bootstrap from 200→10 runs for equivalent confidence.

## Approaches & framings

- **Distributional view of attribution as stochastic variable** — Treats feature importance not as a point estimate but as a distribution over data randomness. This reframes our single-direction AUROC from "ground truth" to "one draw from a distribution we haven't characterized." Intersects F-2: the stability of the DoM direction itself has never been formally tested.

- **Activity/Strength/Stability trichotomy** — Decomposes feature quality into three independent axes. Our current evaluation collapses all three into "AUROC of a probe." Applying this decomposition to our 1536 features could reveal that some low-AUROC dimensions are extremely *stable* (reliable but weak signals), which could inform ensemble construction for the cov-spectrum probe (F-2, AUROC 0.7928).

- **Golub gene expression** — 72 samples × 7,129 features, binary classification. Small-n high-p regime analogous to our 500 samples × 1536 features. License: public (UCI). Applicable? Weakly — useful as methodological comparison but different domain.

- **CIFAR-10 with ViT patches** — 50 bootstrap × 576 patches × 10 classes. Demonstrates the framework on neural network internal representations. Applicable? No — image patches are not comparable to residual-stream dimensions.

## Implementation details worth capturing

- 200–1000 bootstrap iterations recommended for full stability characterization; 10 iterations sufficient for approximate Gaussian summaries when Lyapunov conditions hold.
- OOB (out-of-bag) SHAP computation: each bootstrap sample covers ~63.2% of observations; SHAP computed on unseen 36.8%.
- TreeSHAP complexity: O(B·T·L·D²) for B bootstraps, T trees, L leaves, D depth — but for our logistic regression probe, SHAP is closed-form (linear model), so bootstrap cost is dominated by model fitting, not SHAP computation.
- Code: https://github.com/Lanxin-Xiang/RobustSHAP (Python, uses shap + sklearn).
