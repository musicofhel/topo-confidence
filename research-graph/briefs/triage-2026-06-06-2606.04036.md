# Triage brief — 2606.04036 — Self-Distilled Policy Gradient

Source: https://arxiv.org/abs/2606.04036
Triaged: 2026-06-06

## Refutations

1. **Refutation of F-2 (prefill L19 DoM AUROC 0.7731):** SDPG replaces GRPO's sparse, sequence-level credit assignment with dense per-token supervision via full-vocabulary on-policy self-distillation (OPD). If this dense signal causes the model to distribute correctness-relevant information across more layers and token positions rather than concentrating it at L19 prefill, the prefill DoM direction could lose predictive power. Mechanism: SDPG's positive-advantage gating (Section 3.5.1) ensures the OPD signal only fires on verifier-endorsed rollouts, creating a tighter coupling between per-token credit and outcome correctness than GRPO's uniform advantage. This might reshape the activation geometry so that correctness information is encoded per-token rather than per-sequence, degrading single-direction prefill probes. Falsifiable: extract L19 prefill activations from a Qwen-2.5-1.5B model trained with SDPG on MATH-500, fit DoM, compare AUROC to 0.7731. AUROC drop > 0.05 confirms; stable AUROC rejects.

2. **Refutation of F-4 (asymmetric collapse):** SDPG explicitly maintains higher actor entropy than GRPO throughout training (Figure 3e: SDPG-UFKL entropy stays ~0.6 vs GRPO's ~0.4 and RLSD's collapse toward 0). The KL regularization against a reference policy prevents the mode collapse that concentrates the model's output distribution. If F-4's asymmetric collapse (correct trajectories collapse harder than incorrect) is a downstream consequence of GRPO's mode-collapsing training dynamics — where the model commits aggressively to a single solution path on "known" problems — then SDPG-trained models with preserved output diversity should show reduced or eliminated asymmetric collapse. Falsifiable: extract per-token L19 participation ratios for correct vs incorrect trajectories from an SDPG-trained model. If the correct/incorrect PR gap shrinks by >50% relative to GRPO-trained model, F-4 is a training-artifact.

3. **Refutation of F-7 (D-bucket collective geometric signature):** H-708 already hypothesizes that D-bucket geometry is caused by GRPO's gradient void at low pass rates (w(p) → 0 when few rollouts are correct). SDPG addresses exactly this failure mode: the warmup-decay schedule for β lets outcome-only learning dominate early training (when D-bucket problems produce mostly incorrect rollouts), then gradually adds OPD only on correct rollouts via positive-advantage gating. This means D-bucket problems — where pass rates are near-zero — never receive the OPD signal at all, but also never experience GRPO's gradient void because SDPG drops the importance-ratio clipping in favor of REINFORCE-style surrogate loss (Section 3.2). If the D-bucket geometric signature disappears under SDPG training, F-7 is reframed as a GRPO-specific training artifact. Falsifiable: train with SDPG, extract L19 prefill activations for D-bucket problems, test whether the collective geometric signature (cluster separability, centroid displacement) persists. Signature loss >2σ from GRPO baseline confirms.

## Direct connections to F-N / H-N

- **F-2 (AUROC 0.7731) / H-707 / H-774:** SDPG introduces a third RL training variant (alongside MaxRL, DGPO) that could rotate or preserve the L19 prefill DoM direction. SDPG is tested on Qwen3-1.7B (Table 2), close to our Qwen-2.5-1.5B. H-707 asks whether DoM rotates under MaxRL; H-774 asks the same for DGPO. SDPG provides a third anchor point: does dense OPD supervision change the DoM direction? cos(DoM_SDPG, DoM_GRPO) < 0.5 would confirm the H-707 family; > 0.8 would strengthen F-2 universality.

- **F-4 (asymmetric collapse) / H-853 / H-854:** SDPG's maintained entropy (Figure 3e) is the inverse of the mode-collapse story in H-853/H-854. The paper's Qwen3-1.7B experiments show GRPO entropy at ~0.45 while SDPG-UFKL stays at ~0.55 after 400 steps. If mode collapse drives asymmetric collapse (F-4), SDPG's diversity preservation should attenuate it.

- **F-8 (selective prediction at 50% coverage / 71.6% accuracy):** If the DoM direction changes under SDPG training, the selective-prediction stack calibrated on GRPO-trained models would need recalibration. The K=2.5 coverage threshold is fitted to GRPO-trained model geometry.

- **H-463 (correctness signal disappears on pure-SFT):** SDPG's OPCD ablation (pure self-distillation without reward, Table 2 and Appendix D.2) shows catastrophic collapse on Qwen3-1.7B — accuracy drops to 0.017 on AIME24 and response length collapses to <300 tokens. This suggests pure distillation without a verifier destroys the model's reasoning ability, which could correspond to destroying the correctness signal in hidden states. Indirect evidence for H-463's prediction that non-RL models lack the signal.

- **H-669 (RLVR degrades DoM in proportion to ECE worsening):** SDPG's better calibration (less entropy collapse) could mean better ECE. If so, SDPG-trained models might preserve the DoM signal better than standard RLVR, providing a positive test case for H-669's ECE-linkage prediction.

## Methodologies extracted

- **Full-vocabulary reverse-KL on-policy self-distillation (OPD)** — The same model provides dense per-token KL targets by conditioning on privileged context (solutions) vs unprivileged (question only). Proposition 3.1 shows this is equivalent to a policy-gradient update with centered log-ratio token advantages.
  *Replication cost*: 8×H100 for 400 steps (~1 day for Qwen3-4B).
  *We'd plausibly run this*: no — requires H100 cluster for training, not applicable to inference-time analysis.

- **Positive-advantage gating** — Gate the OPD loss by m_i = 1[A_out > 0], trusting self-distillation only on verifier-endorsed rollouts.
  *Replication cost*: trivial to implement once training loop exists.
  *We'd plausibly run this*: no — training-time technique, not applicable to cached activations.

- **Warmup-decay distillation schedule** — β(k) = β_base × min(1, k/T_warm) × min(1, (T−k)/T_decay). Warms up OPD after outcome learning has begun finding correct trajectories, then decays to release the student.
  *Replication cost*: trivial scheduling code.
  *We'd plausibly run this*: no — training-time technique. But the conceptual framing (early features are noisy, late features are over-constrained) could inform how we weight per-layer features in multi-layer probes.

- **Unnormalized KL divergence (UKL)** — Adds mass correction term to standard KL to handle sub-vocabulary distributions. Equivalent to Schulman's k3 estimator with lower variance.
  *Replication cost*: 5min implementation.
  *We'd plausibly run this*: no — KL between model distributions, not applicable to activation analysis.

- **Group-relative advantage with normalized standard deviation** — Standard GRPO advantage normalization A = (R − μ) / (σ + ε).
  *Replication cost*: already implemented everywhere.
  *We'd plausibly run this*: no — training-time.

## Approaches & framings

- **Distillation-as-policy-gradient identity:** The gradient of D_KL(p_t || SG[q_t]) is locally identical to a detached-sampling policy-gradient with centered log-ratio advantage A_dist = D̄_t − log(p̄_t(a)/q̄_t(a)). This reframes KL distillation as just another advantage signal, unifying the distillation and RL views. Intersects our framing at a meta-level: if the "correctness direction" in F-2 is best understood as a direction that a verifier-grounded policy gradient pushes the model toward, then different policy gradient formulations (GRPO vs SDPG) should produce different directions — directly testable via H-707/H-774.

- **Privileged-context self-distillation as dense supervision for sparse rewards:** The core insight is that the same model, conditioned on solutions, provides per-token guidance to the version without solutions. Analogous to our setup: the model "knows" the answer (when given the solution) and this knowledge is transferred to the unprivileged version. Our F-2 finding can be read as: the prefill geometry already encodes whether the model will produce this privileged knowledge or not, even before generation begins.

- **Entropy collapse as a mode-collapse diagnostic:** SDPG uses actor entropy decay as a training failure mode indicator (Figure 3e). This framing could be applied to our per-problem analysis: if a problem's L19 activation is "low entropy" (concentrated in few principal components), that might indicate the model has mode-collapsed on that problem, predicting the D-bucket signature (F-7).

## Implementation details worth capturing

- Training on 8×H100, 400 steps, AdamW lr=1e-6, weight decay 0.1, gradient clipping 1.0, global batch 128, 8 responses per prompt, temp 1.0, max prompt 2048 / response 4096.
- SDPG hyperparams: α=1e-3 (KL reg), β_base=1e-3 (OPD), T_warm=50, T_decay=350.
- GRPO baseline uses ε_std=1e-6, clipping (0.2, 0.2), KL coefficient 1e-3.
- Privileged context generated by Gemini 2.5 Pro (solutions for teacher model).
- Framework: verl + vLLM engine.
- Code: https://github.com/lauyikfung/SDPG
