# Triage brief — 2605.28501 — Fitting Unknown Number of Hyperplanes with Manifold Optimization

Source: https://arxiv.org/abs/2605.28501
Triaged: 2026-06-02

## Refutations

**1. vs F-2 (single L19 prefill direction, AUROC 0.7731):**
The paper's Riemannian EM hyperplane fitter discovers K hyperplanes without pre-specifying K, using BIC model selection. If applied to L19 prefill activations (projected to top-k PCA dimensions for non-degeneracy; see implementation note below) and BIC selects K>1 hyperplanes whose union achieves AUROC significantly above 0.7731, then F-2's characterization of the correctness signal as "a single direction" is incomplete — the correctness boundary is actually a piecewise-linear surface (union of hyperplanes) and the DoM direction is merely the dominant component of a mixture. The cos(DoM, PC1) = 0.9216 would then reflect the DoM collapsing a multi-faceted boundary onto its principal axis.

*Falsifiable experiment:* Run their Phase I+II Riemannian EM on the 500×d PCA-reduced L19 activations for d ∈ {10, 20, 50}. Compute K_BIC and per-hyperplane AUROC contributions. F-2 is refuted if the multi-hyperplane classifier's 5-fold CV AUROC exceeds the single-direction AUROC 0.7731 by ≥ 0.02 (i.e., ≥ 0.793, which would also match or exceed the cov-spectrum probe's 0.7928).

**2. vs F-9 (CoE-60 redundant with single-layer DoM):**
If the multi-hyperplane model discovers K>1 separating surfaces in L19 activation space, each hyperplane normal defines a distinct direction. CoE-60 trajectory features aggregate across 60 layers and could implicitly capture *which* hyperplane a sample is nearest, encoding information about *which failure mode* is active. This information is invisible to a single DoM projection. F-9's redundancy claim would be refuted if: (a) K>1 hyperplanes are found, and (b) the hyperplane-assignment variable (argmin distance to which hyperplane) is predictable from CoE features but not from the scalar DoM projection.

*Falsifiable experiment:* After fitting K hyperplanes, compute per-sample assignment labels. Train a classifier from CoE-60 features to predict assignment. If CoE-60 predicts assignment at accuracy >> chance (1/K) while DoM score does not, CoE-60 carries non-redundant information.

**3. vs F-7 (D-bucket collective geometric signature):**
F-7 identifies the difficulty bucket (D-bucket) as having a "distinctive collective geometric signature." The multi-hyperplane model could reveal that the D-bucket signature is a trivial consequence of multi-hyperplane geometry — i.e., D-bucket problems cluster near one hyperplane while easy-correct problems cluster near another. If the D-bucket's "collective" signature reduces entirely to assignment to one hyperplane in a K-hyperplane mixture, then F-7's characterization is over-stated: there is no distinctive *collective* signature, just a selection effect in a hyperplane mixture.

*Falsifiable experiment:* Fit K hyperplanes. Compute per-problem hyperplane assignment. Chi-squared test D-bucket membership vs hyperplane assignment. F-7 is complicated if the association is strong (p < 0.01) and D-bucket assignment is fully mediated by hyperplane membership.

## Direct connections to F-N / H-N

- **F-2 (AUROC 0.7731, cos(DoM,PC1)=0.9216):** The paper's core theorem (A.7) proves that hard-refinement hyperplane fitting on S^{dim-1} converges to the minimum eigenvector of the covariance matrix — which *is* PC1 for the K=1 case. So for a single hyperplane, the method would literally rediscover PC1/DoM. The interesting test is K>1.

- **H-664, H-671, H-829 (multi-directional signal):** These hypotheses predict the L19 correctness signal might not be rank-1. The paper provides the first principled, BIC-guided method to test this without pre-specifying K. A K=1 result would confirm F-2; K>1 would support H-664/H-671/H-829.

- **Cov-spectrum probe (AUROC 0.7928):** The top-20 log-eigenvalue probe beats single-direction DoM by ~0.02. If the multi-hyperplane model also achieves ~0.79 with K≈2–3 hyperplanes, this would provide a geometric explanation for the cov-spectrum advantage: the eigenvalue features implicitly encode projections onto multiple hyperplane normals.

- **F-10 (PH null vs Gaussian):** This paper's method is geometric, not topological. Even if it finds multi-hyperplane structure, this does not contradict F-10 (which specifically addresses PH summary statistics). It would, however, narrow the scope of the "no non-linear geometry matters" reading of F-10 — hyperplane mixtures are piecewise-linear, which PH is known to miss.

## Methodologies extracted

- **Riemannian EM with inverse-square kernel** — two-phase optimization on S^{dim-1}: Phase I uses soft posterior weights w_ij = (1/|n_j·x_i - d_j|²) / Σ_k(1/|n_k·x_i - d_k|²) with Riemannian gradient descent (tangent-space projection + retraction); Phase II switches to hard assignment and converges to eigenvectors of within-cluster covariance.
  *Replication cost*: 30min CPU (for our 500-sample × 50-PCA-dim data). Code at https://github.com/aaronworry/HyperplanesFitting.
  *We'd plausibly run this*: yes — cheap, code available, directly tests H-664/H-671/H-829.

- **Projected density initialization** — samples M candidate normal vectors on S^{dim-1} via angular coordinates, projects all data onto each candidate, finds the highest-density window of width W=2δ–4δ along each projection, selects the hyperplane with most inliers, removes assigned points, and repeats.
  *Replication cost*: Initialization is the bottleneck; in high-dim (1536) the uniform sphere sampling is degenerate (random vectors nearly orthogonal). Practical only after PCA reduction to ~20–50 dims.
  *We'd plausibly run this*: yes, but only in PCA-reduced space (bypassing their sphere-sampling init in favor of domain-informed initialization using known directions like DoM, PC1, PC9).

- **BIC model order selection for Laplace-distributed residuals** — BIC criterion: 2n·ln(2/n·Σr_i) + 2n + (m(dim+1)-1)·ln(n), where r_i = distance to nearest hyperplane. Iterates m from 1 to ⌊n/dim⌋.
  *Replication cost*: trivial once fitting runs.
  *We'd plausibly run this*: yes — directly answers "how many hyperplanes does BIC prefer?" on our data.

## Approaches & framings

- **Hyperplane fitting as unsupervised learning on S^{dim-1}:** Reformulates classification-boundary discovery as finding normal vectors on the unit sphere. For our project, this reframes the question "is the correctness signal rank-1?" as "does BIC prefer K=1 or K>1 hyperplanes in activation space?" — a cleaner formulation than ad-hoc multi-direction sweeps.

- **Soft-to-hard phase transition:** The two-phase approach (soft EM → hard assignment) mirrors a general principle: explore geometry with soft weights, then refine with hard decisions. This is conceptually related to our selective-prediction framework (F-8), where a soft confidence score transitions to a hard accept/reject decision at a coverage threshold.

## Implementation details worth capturing

- Code: https://github.com/aaronworry/HyperplanesFitting (Python, license unclear but paper is CC-BY-4.0).
- Inverse-square kernel (1/D²) outperforms Gaussian (e^{-D}) and linear (1/D) for Phase I weights — use this default.
- Window parameter W = 2δ–4δ for initialization; W < 2δ overestimates K.
- Convergence proof (A.7.3) applies only to Phase II (hard refinement); Phase I has no convergence guarantee.
- The method scales O(n × K × dim) per EM iteration; the bottleneck is initialization (sphere sampling), which is exponential in dim for uniform coverage.
- Maximum tested dimensionality: 5D with 120 points. **No experiments in dim > 5.** Scalability to 1536-d is unvalidated.
- Critical degeneracy: with n=500 and dim=1536, ⌊n/dim⌋ = 0 — the BIC upper bound on K is 0. Must reduce dimensionality first (PCA to d ≤ 50 is necessary for the method to be well-posed).
