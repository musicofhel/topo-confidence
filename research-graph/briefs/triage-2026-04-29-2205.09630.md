# Triage brief — 2205.09630 — Acceptability Judgements via Examining the Topology of Attention Maps

Source: https://arxiv.org/abs/2205.09630
Triaged: 2026-04-29

## Refutations

1. **Direct refutation of F-10's "PH = Gaussian null" framing on a sister object.**
   F-10 establishes that persistent homology on the *residual-stream* point cloud
   sits at the Gaussian null (EXP-026). This paper shows that PH applied to the
   *attention-map* graph (same model, same forward pass — different filtration
   object) yields a strong, supervised-classifier-grade signal: H0M alone gives
   ~+0.10 MCC over a frozen-LM baseline on CoLA, and the full TDA bundle adds
   +0.14–0.24 MCC. Mechanism: attention is sparse and content-conditioned (heads
   specialize to next-token / [SEP] / punctuation patterns), so the resulting
   weighted graph has structure that random point clouds do not — Betti numbers
   and barcode features survive a Gaussian null that residual-stream Rips PH
   cannot. **Falsifiable test**: compute H0M / β0 / β1 / # cycles on every Qwen
   1.5B attention head over the 500 MATH-500 prompts (cached in Stage 4a per-token
   activations? — need to verify attention output was kept), train a logistic
   regression vs MATH-500 correctness, compare AUROC against (a) the random-graph
   null with same edge density, (b) F-2's prefill DoM 0.7731. If any single head's
   topology AUROC exceeds 0.65, F-10's "PH-at-null" generalisation is over-broad
   and must be restated as "Rips-on-residual-stream-points only".

2. **Refutation of F-3's prefill/final orthogonality as a layer-19 phenomenon.**
   F-3 reports cos(prefill_DoM, final_DoM) = 0.046 at L19 in the residual stream.
   This paper shows that for grammatical acceptability the strongest BERT heads
   are clustered at layers [3, 6–9, 11] and for RoBERTa at [2–3, 8–11] —
   crucially, the *same* heads carry the H0M / RTD signal across both binary
   classification and minimal-pair scoring. If correctness in Qwen is a
   "comprehension"-flavoured task whose head-level signal also concentrates at
   one cluster, then prefill vs final-token correctness predictors should reside
   at the *same* attention heads even when their residual-stream DoM directions
   are orthogonal. Mechanism: residual-stream geometry mixes contributions from
   all heads at that layer; per-head attention topology de-mixes them.
   **Falsifiable test**: compute per-head H0M on prefill vs final-token attention
   maps (Qwen 1.5B, MATH-500). If the top-K head sets overlap by ≥80%, F-3's
   orthogonality is a vector-space artifact of mixing, not a circuit-level fact.

3. **Refutation of F-9's "CoE redundant with single-layer L19 DoM" framing.**
   F-9 argues CoE-60 trajectory features add nothing over L19 DoM. This paper's
   RTD operates on *pairs* of attention graphs and produces a feature
   (topological divergence between two graphs) that no single-layer DoM probe can
   express by construction — RTD requires two forward passes, not one. If RTD
   between (problem, retrieval-prototype) attention graphs predicts MATH-500
   correctness above CoE-60 = 0.811 AUROC, then F-9's redundancy claim is
   restricted to *single-pass scalar features* and a non-trivial
   pair-wise-topology feature class survives. **Falsifiable test**: build
   "prototype" attention maps from K=10 known-correct MATH-500 problems per
   difficulty level, compute RTD(problem, prototype) per problem, fit a linear
   probe — compare AUROC against CoE-60 on identical 500-problem split.

## Direct connections to F-N / H-N

- **F-10 (PH on trained residual streams at Gaussian null)** — this paper is the
  cleanest contrast piece in the literature: same family of techniques (Rips
  filtration, barcodes, Betti numbers) yielding *signal* on attention graphs
  while EXP-026 finds *null* on residual-stream point clouds. The right
  research-graph edge is `METHOD_DIFFERS` (graph filtration vs Rips on points)
  combined with `EXTENDED_BY` (this paper points to where TDA *does* have
  purchase on transformers).

- **F-7 (D-bucket has collective geometric signature)** — RTD is purpose-built
  for pair-wise topological discrepancy with vertex correspondence; D-bucket
  membership is exactly the kind of "this problem's attention diverges from a
  consensus pattern" signal RTD targets. This is adjacent to P7-FE2 (HalluZig /
  TOHA), but with a sharper formal tool (`RTD` rather than generic graph PH).

- **F-2 (prefill L19 DoM AUROC 0.7731)** — paper's "Top Head" alone outperforms
  144-head majority on BLiMP by up to 10.6%; if the analogue holds for
  MATH-500 correctness, a single Qwen attention head's topology score could
  rival or beat F-2's prefill DoM. Direct head-to-head comparison is required
  before F-2 can be promoted from "strong predictor" to "best label-light
  predictor".

- **H-13 (head-level attribution of prefill vs final-token circuits)** — this
  paper provides the methodology template: per-head topology features →
  Logistic Regression → identify dominant heads via Shapley values. H-13 should
  be operationalised using exactly this pipeline rather than waiting for a
  bespoke causal-tracing setup.

- **H-21 (D-bucket has narrower prefill attention than A-bucket)** — H0M on a
  bucket-stratified attention extraction is the cheapest possible test of H-21
  (~20min CPU once attention is dumped).

## Methodologies extracted

- **Attention-as-weighted-graph filtration** — represent each head's attention
  matrix as a weighted directed graph; threshold edges by τ to form a filtration
  Gτ; track birth/death of connected components and cycles.
  *Replication cost*: ~1h CPU per 500-problem dataset on cached attention
  matrices, or ~2.4s/text per 144 heads on K80 GPU (paper's number).
  *We'd plausibly run this*: yes — directly tests F-10's domain of validity.

- **Topological feature vector (β0, β1, #SCC, #edges, #cycles per head)** —
  concatenated across heads + thresholds → fed to a Logistic Regression
  classifier.
  *Replication cost*: same as above; LR fitting is seconds.
  *We'd plausibly run this*: yes — it is the direct PH probe on the object F-10
  explicitly excluded.

- **Barcode statistics (H0S, H0M, sum/mean/variance of bar lengths, entropy)** —
  cheaper-than-full-PH summary derived from the 0/1-dim barcode of A0 = 1 −
  max(A, A^T).
  *Replication cost*: trivial; Ripser++ does it.
  *We'd plausibly run this*: yes — H0M alone gave +0.10 MCC; cheap label-free
  candidate.

- **Distance-to-attention-pattern features** — Frobenius distance of attention
  matrix to canonical patterns (next-token, [SEP], [CLS], punct).
  *Replication cost*: 10min CPU.
  *We'd plausibly run this*: maybe — these are MATH-irrelevant patterns; would
  need MATH-specific patterns (e.g. attention to operands, attention to "=").

- **Representation Topology Divergence (RTD; Barannikov et al. 2022 ICML)** —
  pair-wise topological dissimilarity of two graphs with one-to-one vertex
  match. Paper uses Ripser++ for the merged-graph PH.
  *Replication cost*: ~95s/text worst-case on 512-tok input across 144 heads;
  needs Ripser++ install + paired-input setup.
  *We'd plausibly run this*: yes for D-bucket-vs-prototype experiment; no for
  routine deployment (too slow).

- **Beam-search head ensemble selection** — pick odd-sized subset of heads
  whose majority vote on a held-out auxiliary set maximises BLiMP accuracy.
  *Replication cost*: 1h CPU per task once head scores are cached.
  *We'd plausibly run this*: yes — analogue for MATH-500 correctness routing.

- **Shapley-value head-importance attribution** — feature-importance over
  per-head TDA features after PCA decorrelation.
  *Replication cost*: 30min CPU.
  *We'd plausibly run this*: yes — for H-13.

## Approaches & framings

- **"Attention graphs, not point clouds, are the right TDA object for
  transformers."** This is the headline reframing. F-10 implicitly assumed
  Rips-on-points was the canonical TDA test for transformer interpretability;
  this paper demonstrates that the *graph* induced by attention is a
  qualitatively different filtration object that survives the random-baseline
  test. Intersects F-10 directly: the Gaussian-null result needs to be scoped
  to its filtration choice.

- **"Per-head, not per-layer, is the natural unit of analysis."** The paper
  treats each (layer, head) pair as an independent classifier, then ensembles.
  Our project has been layer-centric (L19); this reframing argues the right
  granularity is the head. Intersects F-2, F-3, H-13.

- **"Pair-wise topology (RTD) as a forced-choice score."** Reframes minimal
  pairs as topological divergence rather than likelihood ratio. By analogy,
  K=8 majority-vs-K=1-greedy could be reframed as
  RTD(attention_K=1, attention_K=8) → a label-free B-bucket / D-bucket
  detector. Intersects F-7, H-19.

- **CoLA** — Corpus of Linguistic Acceptability. ~10k sentences, English, MIT
  license, HF datasets. Applicable? no — grammaticality task is far from MATH
  correctness; useful only as a sanity-check dataset for attention-graph TDA
  pipeline, not as a substantive comparison.

- **ItaCoLA** — Italian acceptability. HF. Applicable? no — same reason.

- **DaLAJ** — Swedish L2-error judgments. HF. Applicable? no — L2-specific
  noise is orthogonal to our use case.

- **BLiMP** — 67k minimal pairs, 12 phenomena. HF. Applicable? no for our
  pipeline directly; yes as a reference benchmark for any "RTD on minimal
  pairs" generalisation we publish (BLiMP-style "minimal pairs of MATH-500
  problems differing in one operand" would be a generalisable evaluation
  protocol).

## Implementation details worth capturing

- Code & datasets released at `github.com/danchern97/tda4la`.
- Ripser++ (`github.com/simonzhang00/ripser-plusplus`) is the canonical PH
  toolkit used; GPU-accelerated; has a Kruskal MST path the paper relies on.
- For a 512-token input on K80 GPU with 144 heads: H0M = 2.41s, full RTD =
  94.5s — empirically the actual end-to-end times on BLiMP (67k pairs) are
  2.4h (H0M) / 15.7h (RTD).
- A0 transformation: A0 = 1 − max(A_attn, A_attn^T) — required to feed
  asymmetric attention into Ripser++ (which expects a distance matrix). This
  symmetrisation is non-trivial and would need to be replicated exactly.
- For RTD with subword tokenisers, the one-to-one vertex correspondence breaks
  when paired sentences segment into different sub-token counts; paper notes
  this is a real practical limitation (relevant to MATH where minor numeric
  swaps may re-tokenise differently in Qwen).
- BERT used 768-dim, 12 layers × 12 heads; classifiers are plain Logistic
  Regression on the concatenated TDA feature vector.
