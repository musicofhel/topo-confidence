# Triage brief — 2407.11094 — Robust Score-Based Quickest Change Detection

Source: https://arxiv.org/abs/2407.11094
Triaged: 2026-05-06

## Refutations

1. **Could refute F-2 (L19 uniqueness as single correctness-predictive layer).**
   The RSCUSUM framework applied to per-layer activation statistics (DoM AUROC, participation ratio, spectral features) across the 28-layer Qwen stack treats layers as a sequential data stream and detects the *change-point* where uninformative layers transition to informative ones. If robust change-point detection identifies a different layer, a *range* of layers, or no sharp transition (gradual ramp), the claim that L19 is uniquely informative weakens. The least-favorable-distribution (LFD) approach is specifically designed to be robust to uncertainty in the pre/post-change distributions, so it would give a worst-case bound on where the signal emerges — a more conservative test than simply picking the layer with the highest AUROC.
   *Falsifiable by:* Run RSCUSUM on the 28-point per-layer DoM-AUROC sequence (or per-layer Fisher divergence between correct/incorrect groups). If the detected change-point is not at L19 (or if no single change-point exists), F-2's "single L19 direction" framing is undermined.

2. **Could refute F-1 (breathing is a single universal pattern).**
   If RSCUSUM detects *multiple* change-points across the layer stack (e.g., an early expansion phase, a mid-network plateau, and a late-layer collapse), this would replace the "universal breathing" narrative with a "multiple distributional phase transitions" interpretation. The robust detection framework would ensure these are genuine distributional shifts, not artifacts of boundary effects.
   *Falsifiable by:* Apply sequential RSCUSUM to per-layer participation ratio or intrinsic dimensionality estimates. Multiple detected change-points with negative-then-positive drift patterns at distinct layers would refute a single breathing cycle.

3. **Could refute F-10 (PH adds nothing beyond Gaussian null) via Fisher divergence as alternative non-parametric divergence.**
   F-10 established that persistent homology summaries on residual streams are indistinguishable from Gaussian-matched controls. Fisher divergence (Eq. 8 in the paper) measures distributional differences via score functions (gradients of log-density) rather than topological summaries. If Fisher divergence between correct and incorrect L19 activation distributions significantly exceeds what a Gaussian-null model predicts, it would show that non-Gaussian structure exists but PH failed to capture it — i.e., F-10's null is instrument-specific, not a property of the geometry.
   *Falsifiable by:* Estimate Fisher divergence between correct/incorrect prefill L19 activations using score matching on cached NPZs. Compare against Fisher divergence of Gaussian controls with matched mean and covariance. If the real data shows significantly higher Fisher divergence than the Gaussian null, F-10's conclusion ("Gaussian suffices") is challenged at the divergence-measurement level.

## Direct connections to F-N / H-N

- **F-2 (L19 DoM AUROC 0.7731):** The paper's change-point detection framework offers a principled way to test whether L19 is a genuine phase boundary or an arbitrary peak. The RSCUSUM detection delay bound (Theorem VI.8) provides asymptotic guarantees that the detected change-point is optimal under worst-case distributional uncertainty — applying this to the 28-layer sequence would give a robust characterization of *where* the correctness signal emerges.

- **F-10 (PH-null):** Fisher divergence (Definition IV.2) is a score-based divergence that, like PH, doesn't require normalized densities. But unlike PH, it captures distributional differences through gradient information rather than topological summaries. The paper shows Fisher divergence = KL divergence for certain Gaussian families (Section V), which directly connects to F-10's Gaussian null: if Fisher divergence and KL agree on our activations, the Gaussian assumption holds at the divergence level too.

- **F-3 (prefill/final orthogonality, cos=0.046):** The RSCUSUM framework could be applied to the token-position dimension to detect the change-point where prefill transitions to generation. The orthogonality of prefill and final DoM directions might correspond to a distributional change-point at a specific token position.

- **F-4 (asymmetric collapse):** The paper's drift analysis (Lemma VI.5: negative drift pre-change, positive post-change) provides a formal statistical framework for characterizing asymmetric behavior across a distributional boundary — directly applicable to testing whether correct/incorrect collapse asymmetry is a genuine distributional shift.

- **H-4 (Breathing ↔ Sharpness Dimension / EoS):** The change-point framework offers a competing formalization: instead of breathing being a sharpness phenomenon, it could be characterized as a sequential distributional change detectable by score-based methods.

## Methodologies extracted

- **Fisher divergence estimation** — Non-parametric divergence measure between two distributions using score functions (gradients of log-density). Avoids needing normalized densities. Eq. 8: D_F(P||Q) = E_{X~P}[½||∇log p(X) - ∇log q(X)||²].
  *Replication cost*: 30min CPU on cached activations (need score estimation step via score matching or kernel density estimation).
  *We'd plausibly run this*: **yes** — directly applicable to comparing correct vs incorrect activation distributions at L19 without assumptions about normalization.

- **Hyvärinen score** — Scoring function S_H(x, P) = ½||∇log p(x)||² + Δ log p(x) that is invariant to scaling of density functions. Can be computed for unnormalized models.
  *Replication cost*: 20min CPU on cached activations (requires gradient estimation on density).
  *We'd plausibly run this*: **yes** — Hyvärinen score differences between correct/incorrect group distributions could serve as a per-sample feature, alternative to DoM.

- **RSCUSUM / SCUSUM sequential detection** — Cumulative sum of Hyvärinen score differences with threshold-based stopping rule. Designed for online detection of distributional changes in sequential data.
  *Replication cost*: 1hr CPU (need to set up the framework, estimate scores per layer, run detection).
  *We'd plausibly run this*: **yes** — applied to the 28-layer sequence of activation statistics to identify where correctness signal emerges.

- **Least favorable distribution (LFD) identification** — Finding the pair of distributions from two uncertainty classes that minimizes Fisher divergence (hardest to distinguish). Closed-form for Gaussian mixtures (Theorem VII.5: reduces to nearest-mean pair under V-norm).
  *Replication cost*: 15min CPU for Gaussian case (just need to find nearest centroids between correct/incorrect Gaussian fits per layer).
  *We'd plausibly run this*: **yes** — the Gaussian LFD result (Theorem VII.5) applies directly if we model correct/incorrect activations as Gaussians with shared covariance. The LFD pair would tell us the "hardest" correct/incorrect configuration to distinguish.

- **Hutchinson's trace estimator for Laplacian** — Used to estimate the Laplacian term in Hyvärinen score for mixture models (Eq. 59). Stochastic trace estimation via random projections.
  *Replication cost*: 10min CPU.
  *We'd plausibly run this*: **yes** — needed for computing Hyvärinen scores on high-dimensional activation distributions.

## Approaches & framings

- **Distributional change as layer progression:** Reframes the question "which layer is important?" as "where does the distribution change?" in a sequential statistical framework. This intersects F-2 by providing a hypothesis-testing framework for layer importance rather than a peak-picking approach.

- **Robustness via worst-case pair:** The LFD concept (finding the hardest pair to distinguish) provides a natural framework for understanding *why* some problems are harder to classify as correct/incorrect — the correct and incorrect distributions for D-bucket problems (F-7) might be closer in Fisher divergence than for other problems.

- **Score-based vs. likelihood-based distinction:** The paper's core insight that score functions suffice when densities are unknown/unnormalized directly applies to our setting where we have 1536-dim activation vectors but no explicit density model. This reframes the "what probe to use" question from "pick a classifier" to "estimate the score function."

## Implementation details worth capturing

- RSCUSUM algorithm is simple to implement: maintain cumulative score Z(n) = max(Z(n-1) + z(X_n), 0), stop when Z(n) ≥ ω (Algorithm 1).
- For Gaussian case with shared covariance V: Fisher divergence D_F(C||D) = ½||V^{-1}(μ_C - μ_D)||² (Eq. 47). Reduces to Mahalanobis distance squared / 2.
- LFD for Gaussian mixtures with shared covariance: just find nearest means under V-norm (Theorem VII.5). No iterative optimization needed.
- For non-Gaussian (e.g., RBM): learn LFD via neural network with Softmax output + Langevin dynamics for particle sampling (Section VIII-B). Architecture: MLP with single hidden layer.
- Detection threshold ω = (log γ)/ρ where γ is the desired ARL (mean time to false alarm) and ρ satisfies the MGF bound E[exp(ρ·z(X))] ≤ 1.
- Code: not released in the paper. Published in IEEE TIT vol. 71, July 2025.
