# Triage brief — 2510.04309 — Activation Steering with a Feedback Controller

Source: https://arxiv.org/abs/2510.04309
Triaged: 2026-04-29

## Refutations

1. **PID's "integral across layers" does not address F-3's "orthogonality across token
   positions."** The paper indexes the controller state by *layer* `k` (Eqns. 11–18 of
   the paper); the integral term `K_i Σ_{j=0}^{k-1} r(j)` accumulates the
   diff-in-means at a fixed token across layers. F-3 (`cos(prefill_DoM, final_DoM) =
   0.046`) is a mismatch between *token positions* (prefill vs. final-token) at the
   same layer L19. The prior admission note's hook ("PID accumulates error across
   layers to handle rotation — directly addresses our failure mode") is therefore
   miscalibrated: layer-wise integration cannot fix token-position rotation.
   *Falsifiable test*: derive the PID-AcT steering direction at L19 on cached prefill
   activations (Qwen-2.5-1.5B), apply at the final-token position, and recompute
   `cos(u_PID(prefill), u_PID(final))`. If the cosine remains <0.1, layer-wise PID
   does not bridge the prefill→final orthogonality and the prior admission rationale
   is refuted (FE below).

2. **Layer-wise PID should beat single-layer L19 DoM if F-9 is wrong.** PID's value
   proposition is that "the layer-wise construction of feature directions" matters
   (paper Sec. 1, Contribution). F-9 says CoE-60 (60-feature trajectory across all 28
   layers) is *redundant* with single-layer L19 DoM for correctness. If PID's
   integral-derivative terms genuinely extract structure across layers, then a
   PID-derived feature direction used as a *correctness probe* (not a steering
   vector — read-out only) should beat AUROC 0.7731. *Falsifiable test*: compute the
   PID feature direction `u(L=19) = K_p r(19) + K_i Σ r(j) + K_d (r(19)-r(18))` over
   cached residuals, fit a logistic readout, OOF AUROC. If ≤0.7731 we re-confirm F-9
   and refute the layer-wise-dynamics claim for correctness probing; if >0.7731 we
   refute F-9.

3. **PID assumes a per-problem setpoint; F-7 says D-bucket only has a collective
   signature.** The framework requires a target reference `x_sp(k)` (Eqn. 7, Eqn.
   13) and a per-problem error `e(k) = x_sp(k) − x(k)`. For the D-bucket
   (K=1-right-but-K=8-wrong) F-7 explicitly says there is *no per-problem direction*
   — only a collective geometric signature. PID applied with a "avoid-D-bucket"
   target would compute `r(k)` against a target with no per-instance basis; the
   I-term accumulates noise rather than signal. *Falsifiable test*: per-problem PID
   error norms `||e(k)||` should *not* separate D-bucket from non-D-bucket members.
   If they do separate (>10% AUROC lift over random on D-bucket vs A/B/C), F-7's
   "collective only" claim weakens.

4. **PID has no closed loop in correctness readout — refutes any claim that PID
   improves probing.** PID is fundamentally a *steering* method (closed-loop
   modification of `x(k)` via `u(k)`). For correctness *prediction* (F-2, F-8) we
   read once and never feed activations back. Therefore PID cannot improve
   selective-prediction (71.6% at coverage 0.5) or AUROC numbers absent intervention.
   *Falsifiable test*: any FE that promises PID improves probing alone (no actual
   activation modification at generation time) is refuted by definition. If the user
   later proposes "PID-derived probe direction" experiments with an expectation of
   beating 0.7731 *without intervention*, this brief flags that as
   incoherent — the paper's stability gains live in the closed loop, not in the
   feature direction.

5. **F-10's PH-at-Gaussian-null result narrows what "dynamical structure" PID can be
   exploiting.** The paper frames residual streams as a non-trivial dynamical system
   (Sec. 2.1, 4.1). F-10 says trained residual streams give Gaussian-null persistent
   homology — i.e., higher-order topology of the per-layer manifold is not
   distinguishable from Gaussian noise. PID's integral assumes coherent error
   structure across layers; if the across-layer dynamics in our regime were
   PH-Gaussian-null, the I-term would integrate noise. *Falsifiable test*: at L19 on
   our cached MATH-500 prefill activations, compute the eigenvalue spectrum of the
   mean local Jacobian `Ā(k)` between L18→L19→L20 (their Prop. 2). If `||Ā(k)||`
   exhibits no clear ISS-stable structure (spectrum dominated by noise), PID's
   stability guarantees collapse on math/correctness data — distinct from
   safety-task data their experiments use.

## Methodologies extracted

- **PID feedback controller per layer** (Eqn. 18) — `u(k) = K_p r(k) + K_i Σ_{j<k} r(j) + K_d (r(k)-r(k-1))`. Drop-in replacement for diff-in-means steering vector. *Replication cost*: ~1h CPU on cached prefill activations to produce PID feature direction across L0–L27 of Qwen-1.5B. *We'd plausibly run this*: yes — to test refutations 2 and 4.

- **PID-AcT** — PID applied within Mean-AcT's sequential framework (best variant in their toxicity table). *Replication cost*: 4h H100 — needs closed-loop generation with intervention at each layer. *We'd plausibly run this*: yes — H-1 has been blocked on H100 pod time; PID-AcT is the strongest steering baseline now.

- **Mean local Jacobian estimation** — `Ā(k)` is the per-layer Jacobian averaged across the contrastive pair. Required for their ISS proof. *Replication cost*: 30min CPU on a 32-prompt sample. *We'd plausibly run this*: yes — if we want to falsify ISS structure on math data (refutation 5).

- **Steady-state error scalar projection** `<e(0), e(k)>` (their Fig. 3 metric) — measures how much of the initial error direction survives after `k` layers under different controllers. *Replication cost*: 30min CPU on cached residuals. *We'd plausibly run this*: yes — direct measurement of layer-wise drift, complements F-3 / H-17 analysis.

- **Stability-first one-gain-at-a-time analytical strategy** (paper's Sec. 6 limitation) — sweep `K_p`, then `K_i`, then `K_d` rather than joint optimization. *Replication cost*: trivial methodology note. *We'd plausibly run this*: yes — for any PID-style sweep.

- **Hyperparameter ranges** — best `K_p ∈ [0.01, 0.05]`, `K_i ∈ [0.05, 0.10]`, `K_d ∈ [0.01, 0.05]` for jailbreaking; similar for toxicity (paper Fig. 6). *We'd plausibly run this*: yes — initial sweep range for FEs below.

- **0-shot LLM-as-judge with QVQ-72B-Preview** — toxicity evaluation via large MLLM. *Replication cost*: not applicable to our task. *We'd plausibly run this*: no — we measure correctness against ground truth on MATH-500.

## Approaches & framings

- **Activation steering as state-feedback control** — recasts ActAdd / DirAblate / Mean-AcT as proportional controllers and identifies their steady-state error as the missing piece. Intersects our framing of L19 DoM as a "feature direction" (P-controller analogue): suggests we should distinguish the *direction* (P) from the *magnitude / persistence* (I) of any steering proposal under H-1.

- **Layer index k as a discrete time variable** — they treat `f^{(k)}(·)` as a dynamical system advancing in `k`. This is the same trick CoE used (P9). F-9 says it's redundant for correctness; the paper says it's load-bearing for steering. The asymmetry is interesting: layer-wise dynamics may matter for *changing* outputs but not for *predicting* them.

- **Disturbance decomposition** `w(k) = w∥(k) + w⊥(k)` (their Sec. 4.2.1) — splits error into the "matched" component PID can cancel and an "unmatched" component it cannot. Useful framing for understanding *why* DoM steering at H-1 might cap out: if the unmatched disturbance is large on MATH-500, even ideal control leaves residual error.

## Implementation details worth capturing

- Code: https://github.com/dungnvnus/pid-steering
- Models tested: Gemma2-{2B,9B,27B}-IT, Llama3-8B-Instruct, Llama3.1-8B-Instruct, Qwen2.5-{3B,14B}-Instruct (3B–14B range), plus FLUX-Schnell + SDXL-Lightning for diffusion.
- Hyperparameter sweep ranges: `K_p ∈ {0.0, 0.01, 0.05, 0.10, 0.15}`, `K_i ∈ {0.0, 0.05, 0.10, 0.15}`, `K_d ∈ {0.0, 0.01, 0.05, 0.10, 0.15}` (paper Fig. 6 ablation).
- Best regime for jailbreak (Llamaguard3 ASR proxy): high `K_i` (0.10–0.15) + small `K_d` (0.01–0.05) + small `K_p` (0.01–0.05).
- Steering function `ρ_steer` is unchanged from underlying method (ActAdd / DirAblate / Mean-AcT); only the *vector* fed into it changes from `r(k)` to `u(k)`.
- Sequential vs non-sequential mapping (Eqns. 4–6 vs 1–3) determines whether each layer's intervention is composed with prior interventions; PID-AcT is the sequential variant and consistently wins in their tables.
- Steady-state error metric: scalar projection `<e(0), e(k)>` plotted across "extraction points" (essentially layer indices on randomly-init Llama3 baseline + pretrained Qwen2.5-3B) — Fig. 3.
- Theoretical guarantees rest on `sup_k ||Ā(k)|| ≤ M < ∞` and `sup_k ||M_p(k)|| ≤ q < 1` where `M_p(k) = Ā(k)(I − K_p)`; ISS stability requires `q + Mh < 1` where `h = ||K_i||`.
