# Triage brief — 2605.12394 — Detecting overfitting in Neural Networks during long-horizon grokking using Random Matrix Theory

Source: https://arxiv.org/abs/2605.12394
Triaged: 2026-05-17

## Refutations

1. **Refutes H-763/H-766 (DoM is weight v1 artifact):** The paper's "Correlation Trap" method explicitly separates structural spectral outliers (artifacts of weight matrix statistics) from the MP bulk. If the L19 DoM direction (F-2, AUROC 0.7731) were simply the leading right singular vector v1 of an L19 weight matrix — i.e. a structural artifact rather than a learned correctness signal — then applying the shuffled-spectrum diagnostic to Qwen-2.5-1.5B L19 weight matrices should reveal that DoM aligns with a Correlation Trap direction. This would refute F-2's interpretation of DoM as encoding *correctness* and instead recast it as a non-self-averaging spectral mode that persists regardless of task semantics. Falsifiable: compute cos(DoM, v_trap) for any L19 traps found by the entry-wise shuffle method; high cosine (>0.5) refutes the "learned signal" interpretation.

2. **Refutes F-7 (D-bucket collective geometric signature):** F-7 claims that difficulty-bucket "D" problems exhibit a *collective* geometric signature distinct from other buckets. The Correlation Trap framework provides an alternative: what appears as a collective signature could be driven by a few localized trap modes that happen to activate on hard problems. Specifically, if certain weight-matrix Correlation Traps localize on coordinate subsets that overlap with the hard-problem activation subspace, the "collective signature" would be an artifact of non-self-averaging structure rather than genuine task geometry. Falsifiable: ablate detected L19 traps and re-measure the D-bucket separation — if it collapses, F-7's "collective" claim is an artifact.

3. **Refutes H-711 (WeightWatcher alpha peaks at L19):** H-711 hypothesizes that the per-layer WeightWatcher alpha profile peaks (minimizes toward 2) at or near L19. This paper introduces a *complementary* diagnostic (shuffled-spectrum traps) from the same WeightWatcher framework. If L19 has many Correlation Traps — i.e. its weight structure is non-self-averaging — this would reframe L19's "special" status as potentially *harmful overfitting* rather than a well-trained layer that concentrates correctness signal. The alpha-near-2 hypothesis assumes L19 is the best-trained layer; Correlation Traps would suggest it's the most *overfit*. Falsifiable: run WeightWatcher trap detection on all 28 layers of Qwen-2.5-1.5B; if L19 has the highest trap count, the "well-trained" interpretation needs revision.

4. **Refutes F-2 (single L19 prefill direction predicts correctness):** The paper demonstrates that anti-grokking produces prototype-like directions in weight matrices that achieve perfect training accuracy but fail on test data via norm-based collapse rather than semantic features. If the DoM direction operates by a similar mechanism — responding to activation *magnitude* patterns rather than genuine correctness-encoding structure — then F-2's AUROC 0.7731 could be a Correlation Trap analog: a non-self-averaging spectral mode that separates correct/incorrect via |x|₂-like statistics rather than meaningful geometry. Falsifiable: replace L19 activations with norm-matched Gaussian noise preserving only ‖h‖₂; if DoM still separates correct/incorrect at AUROC > 0.6, F-2's mechanism is norm-based not semantic.

## Direct connections to F-N / H-N

- **F-2 (DoM AUROC 0.7731):** The paper's core method — detecting spectral outliers in shuffled weight matrices via MP fits — can be applied to test whether L19's DoM is structurally special (a spectral mode that separates from the bulk) or whether it's just the leading PC direction of an essentially MP-distributed layer.

- **F-10 (PH null):** F-10 established that topology summary statistics on residual streams are indistinguishable from a Gaussian null. This paper's MP-based null is conceptually parallel: test whether weight spectra or activation spectra are distinguishable from their randomized null. The paper's success where PH failed (F-10) would suggest that weight-space spectral analysis is more diagnostic than activation-space topological analysis.

- **H-711 (WeightWatcher alpha at L19):** Directly relevant — this paper uses WeightWatcher and extends it with the Correlation Trap diagnostic. Running both alpha and trap-count diagnostics on Qwen-2.5-1.5B per-layer would test H-711 and generate new signal about whether L19 is "well-trained" or "overfit."

- **H-743 (L19 spectral gap outlier):** The paper provides the exact methodology to test whether L19's spectral properties are outliers among all layers — the shuffled-spectrum diagnostic quantifies precisely this.

- **Cov-spectrum AUROC 0.7928:** The paper's finding that the MP fit provides a self-averaging null for spectral analysis directly connects to our cov-spectrum probe (top-20 log-eigvals). If the L19 activation covariance eigvals that drive our 0.7928 AUROC sit beyond the MP edge of a shuffled-activation null, they are "Correlation Traps" in activation space (extending the paper's weight-space method to our data).

## Methodologies extracted

- **Entry-wise weight shuffle + MP fit + right-edge outlier detection (Correlation Trap method)** — Shuffle weight matrix entries i.i.d., compute covariance spectrum of W_rand, fit Marchenko-Pastur, count eigenvalues beyond λ+ + Δ_TW.
  *Replication cost*: 20min CPU (WeightWatcher is pip-installable, Qwen-2.5-1.5B weights are local).
  *We'd plausibly run this*: yes — directly tests H-711 and H-743 on our model.

- **JSD diagnostic ablation test** — Replace a trap direction with a random vector, pass probe inputs through original and ablated models, measure Jensen-Shannon divergence of output logits. Classifies traps as harmful vs benign.
  *Replication cost*: 1-2h GPU (needs forward passes through model with modified weights).
  *We'd plausibly run this*: yes, if traps are found at L19 — would test whether removing them degrades DoM-like predictions.

- **Activation-space extension of shuffled-spectrum diagnostic** — Apply the same MP-fit + outlier method to the activation covariance matrix (not weight matrix). This is not in the paper but is a natural generalization.
  *Replication cost*: 5min CPU (apply to cached 500×1536 L19 activation matrix).
  *We'd plausibly run this*: yes — directly extends the paper's weight-space method to our cached data.

- **Localization metric for trap eigenvectors** — Measure inverse participation ratio (IPR) of top eigenvectors to quantify whether variance is distributed or concentrated on few coordinates.
  *Replication cost*: 5min CPU (on cached covariance matrix eigenvectors).
  *We'd plausibly run this*: yes — tests whether DoM is "localized" in the paper's sense.

## Approaches & framings

- **Anti-grokking as a distinct third training phase** — The paper identifies a post-generalization overfitting regime where train accuracy stays perfect but test accuracy decays. This intersects H-5 (prefill signal encodes problem familiarity vs decomposability): if Qwen-2.5-1.5B is in a partial "anti-grokking" state for certain MATH topics, the DoM direction might be detecting which problems still benefit from the model's generalizing solution vs which have regressed to norm-based memorization.

- **Self-averaging vs non-self-averaging as the fundamental diagnostic** — Rather than asking "is this layer special?" (our current H-711 framing), the paper asks "is this layer's randomized spectrum consistent with self-averaging?" This is a sharper version of the same question — a layer where the shuffled spectrum still has outliers has learned non-random correlations that could be either beneficial or harmful.

- **Benign vs harmful spectral outliers** — Not all spectral anomalies indicate problems. This intersects our DoM interpretation: even if DoM aligns with a spectral outlier in L19, that doesn't make it "bad" — it could be a benign structural mode that happens to encode useful information.

## Implementation details worth capturing

- WeightWatcher v0.7.5.5 (pip install weightwatcher) implements the full Correlation Trap detection pipeline automatically.
- The diagnostic is weight-only: no training data, no test data, no gradients needed. Only a checkpoint.
- Entry-wise shuffle must be truly element-wise (not row/column-wise) to destroy learned correlations while preserving the entry distribution.
- MP fit uses ratio Q = N/M of the weight matrix dimensions; Tracy-Widom scale Δ_TW provides the significance threshold.
- For the JSD ablation test: temperature T=1 softmax on logits, random-token probe inputs, measure D_JS between original and trap-ablated outputs.
- Code: supplemental artifact bundle available (training scripts, analysis scripts, checkpoints). WeightWatcher at https://github.com/CalculatedContent/WeightWatcher.

Check whether any outlier eigenvector beyond the MP edge aligns with DoM. Uses: cached NPZ activations + DoM direction from `pathway11_h100/prefill_gated_compute/results.json`.
