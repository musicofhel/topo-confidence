# Triage brief — 2210.00069 — Topological Singularity Detection at Multiple Scales

Source: https://arxiv.org/abs/2210.00069
Triaged: 2026-04-29

Authors: Julius von Rohrscheidt, Bastian Rieck (Helmholtz Munich / TUM). ICML 2023.

## Refutations

1. **F-10 ("Persistent homology on trained residual streams is at the Gaussian null") may only hold for *global one-parameter* PH, not for *local multi-parameter* PLH.** TARDIS replaces the global Vietoris–Rips filtration with a tri-filtration `(F(B_r^s(x), t))_{r,s,t}` over intrinsic annuli, then takes a bottleneck distance against an *equal-density Euclidean model annulus*. Mechanism: a Gaussian-null match in global PH (EXP-026, EXP-018) collapses the spatial signal because every local irregularity is averaged into one persistence diagram; PLH preserves per-point, per-scale departures. Falsifiable test: compute Euclidicity on a 500-problem subset of cached L19 1.5B activations and on a covariance-matched Gaussian; if the Euclidicity distribution on real activations is right-shifted vs the Gaussian at any (r,s) grid cell beyond Tukey-α=0.05, F-10's null collapses for the local construction. The paper's own pinched-torus / wedge-sphere experiments (Fig. 1, Fig. 5a) show that local PLH separates singular points where global PH would not — that is the exact mechanism F-10 implicitly assumed away.

2. **F-7 ("D-bucket has a *collective* (not per-problem) geometric signature") is directly threatened by the MNIST classification result.** The paper reports per-image Euclidicity on raw MNIST flattened to 784-dim points and shows that *misclassified* samples have mean Euclidicity 0.39 vs 0.33 for correctly-classified samples (Welch's t-test significant; FashionMNIST: 0.35 vs 0.31). Mechanism: TARDIS gives a *per-point* singularity score, and per-point Euclidicity already correlates with per-sample correctness on a comparable hidden-state-style point cloud (flattened images). If we apply TARDIS to per-prompt prefill activations and recover a similar per-prompt Euclidicity↔correctness gap (or a D-bucket-vs-A-bucket gap), F-7's "collective only" framing is wrong: the right detector was just the wrong probe.

3. **H-7 ("Density-based outlier detection finds D-bucket") is partially preempted and possibly *outclassed* by Euclidicity.** Density methods (LOF, HDBSCAN) cannot distinguish a regular low-density region from a singular point — a counterexample TARDIS explicitly demonstrates (Section 5.5: high-Euclidicity regions in the iPSC PHATE plot have *lower local intrinsic dimension* in the original 33-dim space, not lower density). Mechanism: density-only methods conflate manifold thinness with non-manifoldness; Euclidicity disentangles them by comparing to a model annulus. Falsifiable test: run both LOF and TARDIS-Euclidicity on the same prefill embedding cache; if Euclidicity's D-bucket-detection AUROC > LOF's by a margin larger than its single-parameter alternative (Stolz et al. 2020) margin in the paper's Appendix A.7, H-7 needs to be downgraded or merged into a TARDIS-equivalent.

4. **F-2 ("Prefill L19 DoM is a strong correctness predictor, AUROC 0.7731") may be partly an unsupervised geometric signal masquerading as a learned probe.** TARDIS Euclidicity requires no labels at all yet separates correct from incorrect MNIST classifications. Mechanism: if per-prompt Euclidicity on prefill L19 has non-trivial AUROC (≥0.6) for correctness on MATH-500, then a fraction of the 0.7731 supervised AUROC is geometric, not semantic — the DoM logistic-regression direction is partially recovering an *unsupervised* singularity signal that any density-comparison method would also catch. Falsifiable: compute Euclidicity per problem on cached prefill activations, test for AUROC > 0.6 on K=1 correctness; if yes, F-2's claim that DoM is a *learned* direction overstates the case.

## Methodologies extracted

- **TARDIS framework (Topological Algorithm for Robust DIscovery of Singularities)** — joint per-point PID + Euclidicity score. *Replication cost*: medium — code at github.com/aidos-lab/TARDIS, builds on Ripser/GUDHI; 1000-point batches with k=50 NN tractable on CPU; high ambient dim makes VR memory-heavy. *We'd plausibly run this*: yes — applies directly to cached residual-stream point clouds.
- **PLH (Persistent Local Homology) as multi-parameter persistence** — applies the tri-filtration `(F(B_r^s(x), t))_{r,s,t}` on intrinsic annuli of a point. First time PLH treated as 3-parameter module. *Replication cost*: low if you accept the bottleneck-distance approximation (Eq. 3); 20-step grid × 2-3 minutes per point on CPU. *We'd plausibly run this*: yes — direct upgrade path for our pathway-8 PH-at-null line.
- **PID (Persistent Intrinsic Dimension)** — `i_x(ε) := max{i : ∃ r<s<ε with PH_{i-1}(F(B_r^s(x),•)) ≠ 0}`. Theorem 2 guarantees recovery of true dim on smooth manifolds. *Replication cost*: low. *We'd plausibly run this*: yes — direct competitor to twoNN (which we already tried in EXP-021 → 0.407 AUROC) and to the participation-ratio breathing measure.
- **Euclidean-annulus model space comparison** — for each (x, r, s), sample uniform points in R^n at matching density, compute PLH of model annulus, take bottleneck distance to data annulus's PLH. *Replication cost*: low (1000-point Gaussian baseline cheap). *We'd plausibly run this*: yes — gives a principled null for F-10.
- **Persistence-threshold filtering of artefact features** — drop features in dim k whose lifetime is below the max lifetime in dim k-1; a denoising heuristic for sparse samples. *Replication cost*: trivial. *We'd plausibly run this*: yes — improves any future PH on residual streams.
- **Multi-scale parameter selection (k=50 default)** — `s_max` = distance to k-NN, `r_min` = nearest non-zero distance, `r_max = s_min` = ⌊k/3⌋-NN distance, 20-step grid. *Replication cost*: trivial. *We'd plausibly run this*: yes — defaults we can adopt directly.
- **Mini-batch + sub-sample stability protocol** — repeat over 5 sub-samples of 1000 from 10000 to demonstrate distributional stability. *Replication cost*: trivial. *We'd plausibly run this*: yes — directly informs how to design the F-10-vs-Gaussian test in a memory-bounded way.
- **Geometry-vs-misclassification correlation protocol** — train a simple classifier, compute mean Euclidicity on correct vs incorrect, Welch's t-test. *Replication cost*: trivial on cached MATH-500. *We'd plausibly run this*: yes — direct port to A/B/C/D-bucket comparison.

## Approaches & framings

- **Stratified-space framing of point clouds** — replaces the manifold hypothesis with a stratified-simplicial-complex hypothesis where intrinsic dimension is *allowed to vary across the data*. Direct intersection with F-1 (breathing as varying-dim phenomenon?) and F-7 (D-bucket as a stratum of different intrinsic dimension?). Reframes the breathing curve from "global PR oscillation" to "per-token movement between strata of differing dimension."
- **Singularities ≠ outliers** — outliers come from labelling/sampling errors and should be removed; singularities carry information and should be detected. This framing supplies a principled distinction between "noise" and "structure" that our F-7 D-bucket discussion has been missing.
- **Multi-scale locality as a first-class object** — the paper's central methodological move: locality has *no canonical scale*, so analyse over a (r,s) grid. This is exactly the move F-10 didn't make (we computed PH at one global scale per layer).
- **Euclidicity as an unsupervised geometric-complexity probe** — recasts "how predictable is this sample" as "how Euclidean is this sample's neighbourhood," giving a label-free analogue of correctness probes. Direct competitor framing to the supervised DoM (F-2).

## Implementation details worth capturing

- **Code:** https://github.com/aidos-lab/TARDIS (pyproject.toml, README.md). Backbone: Ripser (Bauer 2021), GUDHI, giotto-tda.
- **Filtration:** Vietoris–Rips. Memory grows exponentially with intrinsic dim — *we should expect this to be the binding constraint* on 1536-dim L19 activations. Authors recommend DTM-filtration (Anai et al. 2020) or sparse Rips (Sheehy 2013) for high-dim data. Their proofs are filtration-agnostic.
- **Distance metric:** mean of bottleneck distances over (r,s) grid (Eq. 3); approximation of interleaving distance on 3-parameter modules.
- **Default hyperparameters:** k=50 nearest neighbours, 20 grid steps, intrinsic dim from twoNN if not assumed (e.g. iPSC mean dim = 16). For MNIST they assume dim=10 (Pope et al. 2021).
- **Parallelism:** Eq. (2) is embarrassingly parallel over points — critical for our scale.
- **Stability protocol:** 5 sub-samples of 1000 from 10000-point pool; Tukey range test at α=0.05 to verify distributions don't differ.
- **Artefact filter:** drop dim-k features with lifetime < max lifetime in dim-(k-1) — small but meaningful denoising step we should adopt for any PLH replication.
- **Limitation flagged by authors:** Euclidicity reliability requires correct intrinsic dim; if PID is wrong, the model annulus is wrong.

## Replicable intermediates

- **Per-prompt Euclidicity on prefill L19 (1.5B, MATH-500):** Use cached `pathway11_h100/prefill_gated_compute/results.json` activations (or wherever the L19 prefill embeddings sit — 500 prompts × 1536-dim). Run TARDIS with assumed intrinsic dim from twoNN (we already have twoNN code from EXP-021). Compute mean Euclidicity for K=1-correct vs K=1-incorrect, Welch's t-test. **This is the cleanest one-day CPU experiment in this brief.**
- **Per-token PID temporal trace on cached temporal NPZs:** Pull the cached `scratch/pathway10_temporal_and_verifier_results.json`-source NPZs, compute PID per-token-position over the 1024-tok generation, plot alongside the breathing PR curve. If PID is flat where PR oscillates, F-1 is partially refuted as a topological phenomenon.
- **Local PLH-vs-Gaussian-null test on a 100-problem MATH-500 subset:** Match covariance to the Qwen-1.5B L19 batch, sample equal points, compute PLH-bottleneck for both, compare distributions. Direct counter-test for F-10. ~4h CPU.
- **No replication possible at full ambient dim** — the 1536-dim VR is memory-prohibitive. We'd need to PCA-project to 64–128 dim first; the authors' Theorem 1 stability bound on (r,s) does *not* cover dimensionality reduction, so this is a methodological caveat to log.

## Proposed HYPOTHESES.md additions

### H-73: Per-point Euclidicity (TARDIS) on prefill L19 activations matches or beats the supervised DoM AUROC of 0.7731 *without labels*
**Priority:** HIGH
**Motivated by:** 2210.00069 (TARDIS) + F-2 + EXP-021
**Test:** Compute TARDIS Euclidicity for each MATH-500 prompt's L19 prefill activation (PCA-project to 128-dim first because Vietoris–Rips memory blows up otherwise; intrinsic dim from twoNN; k=50; 20-step (r,s) grid). Score Euclidicity AUROC for K=1 correctness, OOF 5-fold to match F-2's protocol. ~1 day CPU.
**Requires:** CPU; cached `pathway11_h100/prefill_gated_compute` L19 activations; TARDIS pip install; PCA pre-projection.
**Would change:** If Euclidicity AUROC ≥ 0.65, F-2's framing of L19-DoM as a *learned* probe is partly wrong — a fraction is unsupervised geometric singularity. If Euclidicity AUROC < 0.55, TARDIS-style geometry is uninformative for Qwen residual streams and we close the door on this whole TDA branch.
**Blocks:** H-7 (density-based outlier detection — Euclidicity is a strict generalisation; if Euclidicity wins, demote H-7).

### H-74: Per-token PID is flat across breathing peaks/troughs — i.e. breathing (F-1) is a covariance/sample-statistic phenomenon, not a local-intrinsic-dimension phenomenon
**Priority:** MEDIUM
**Motivated by:** 2210.00069 (TARDIS Theorem 2) + F-1 + F-5
**Test:** On cached pathway-10 temporal NPZs, compute TARDIS PID at every 50th token position for 100 correct + 100 incorrect MATH-500 problems on Qwen-1.5B. Plot mean PID vs token position alongside the participation-ratio temporal curve. ~1 day CPU.
**Requires:** CPU; cached pathway-10 temporal activation NPZs.
**Would change:** If PID oscillates with the same shape as PR, breathing is a real local-dim phenomenon and F-1 is a topological claim. If PID is flat (within ±0.5 of the mean) where PR oscillates by ≥10 ratio units, breathing is a 2nd-moment phenomenon (covariance flattening, not dimension change), and F-1's "universal dimensional breathing" framing should be reworded as "universal participation-ratio breathing."
**Blocks:** H-4 (Breathing ↔ Sharpness Dimension correspondence) — if PID is flat, the EoS-correspondence hypothesis weakens.

### H-75: Local 3-parameter PLH on residual streams escapes the F-10 Gaussian null for at least one layer
**Priority:** HIGH
**Motivated by:** 2210.00069 + F-10 + EXP-018 + EXP-026
**Test:** On 1000 token-residuals per layer ∈ {12, 19, 24, 27} from Pathway 8 cached activations, compute Euclidicity using TARDIS, compare to a covariance-matched Gaussian null of equal sample size, Tukey range test α=0.05. ~4h CPU per layer.
**Requires:** CPU; cached pathway-8 layer-wise NPZs; TARDIS install.
**Would change:** If at least one layer separates from the Gaussian null, F-10 should be re-scoped: "global one-parameter PH is at the Gaussian null; local multi-parameter PLH is not." If all layers match the null, F-10 generalises and we can permanently retire PH-on-residual-streams as a research direction.
**Blocks:** P7-FE1 (zigzag PH) and P7-FE2 (PH on attention graphs) — if local PLH already matches null, those alternative filtrations probably do too.
