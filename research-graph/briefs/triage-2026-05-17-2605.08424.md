# Triage brief — 2605.08424 — Generalized Wasserstein Flow Matching: Transport Plans, Everywhere, All at Once

Source: https://arxiv.org/abs/2605.08424
Triaged: 2026-05-17

## Refutations

1. **Refutes F-2 (single L19 direction at AUROC 0.7731) — transport geometry captures multi-dimensional structure that projection destroys.** The paper's sliced Wasserstein framework computes distributional distances by integrating 1-D projections over *all* directions on S^{d-1}. If SW₂ between correct/incorrect L19 activation clouds significantly outperforms the single DoM projection (and isn't reducible to mean-shift), it proves the correctness signal is fundamentally multi-directional and our 0.7731 AUROC is a lossy compression of richer transport structure. *Falsifiable*: compute SW₂(correct_cloud, incorrect_cloud) as a scalar classifier on cached NPZ; if AUC ≤ 0.7731, refutation fails.

2. **Refutes F-10 (PH null on residual streams) — optimal-transport geometry may succeed where persistent homology failed.** F-10 established that topology summary statistics on residual streams are indistinguishable from Gaussian null. But PH's failure doesn't imply *all* geometric summaries fail — the paper's OT-NNA (Nearest Neighbor Accuracy via W₂) is an alternative distributional geometry metric that captures shape differences without assuming manifold structure. If W₂-based distances between correct/incorrect activation distributions discriminate significantly above chance while PH doesn't, it shows the null finding is specific to homological invariants, not to geometry broadly. *Falsifiable*: compute OT-NNA on stratified correct/incorrect L19 activations vs. same-mean/cov Gaussian draws; if both are at chance (0.50±), refutation fails.

3. **Refutes the cov-spectrum probe's sufficiency (AUROC 0.7928 from top-20 log-eigvals) — transport plans encode non-spectral distributional structure.** The covariance spectrum captures second-order statistics of the activation population. The WoW framework operates on full distributional geometry including higher-order moments through the transport plan itself. If a transport-plan-derived feature (e.g., the LLW alignment cost or the fraction of "long-range" transport mass) adds signal beyond the cov-spectrum, it refutes the implicit claim that second-order statistics exhaust the discriminative geometry. *Falsifiable*: add OT cost as feature to cov-spectrum logistic regression; if coefficient is zero and AUROC unchanged, refutation fails.

4. **Refutes F-7 (D-bucket collective signature) — bucket-level geometry may be an artifact of centroid displacement, not genuine collective structure.** The paper's framework makes explicit that Wasserstein distance between point clouds decomposes into centroid-shift (mean displacement) and shape-matching (internal coupling) terms. If the D-bucket "distinctive geometric signature" is fully explained by the mean difference between D-bucket and other-bucket activation centroids (i.e., OT cost after mean-centering drops to noise), F-7's "collective" claim reduces to a trivial location shift. *Falsifiable*: compute W₂(D_bucket_centered, all_others_centered) vs W₂(D_bucket, all_others); if the centered version is indistinguishable from null, refutation holds.

## Direct connections to F-N / H-N

- **F-2 (DoM AUROC 0.7731):** DoM is a single-direction projection. The paper's sliced Wasserstein integrates over all unit-sphere directions, providing a proper distributional alternative. The cos(DoM, PC1) = 0.9216 headline suggests most variance is 1-D; SW₂ would quantify exactly how much discriminative power lives off the DoM axis.

- **F-10 (PH null):** The paper provides alternative geometric invariants (OT cost, transport plan structure) that respect measure-theoretic properties without relying on simplicial complexes. These are strictly different from PH barcodes and could succeed where PH failed.

- **F-4 (asymmetric collapse):** If correct trajectories collapse harder at final token, then W₂(correct_final, correct_prefill) should be smaller than W₂(incorrect_final, incorrect_prefill). The transport cost quantifies collapse more naturally than mean participation ratio.

- **H-762 (implied by admission note):** The admission filter explicitly flagged extending H-762 via Wasserstein distances between correct/incorrect distributions. SW₂ is the computationally tractable version for d=1536.

## Methodologies extracted

- **Sliced Wasserstein distance (SW₂)** — integrates 1-D W₂ over random projections on S^{d-1}; avoids O(N³) OT. For d=1536, uses M random projections, each costing O(N log N) sort.
  *Replication cost*: 10min CPU (our N=500, d=1536; M=100 projections; just sorts).
  *We'd plausibly run this*: yes — direct drop-in on cached activation matrices.

- **Lazy Linear Wasserstein (LLW₂)** — precomputes a barycentric reference, then aligns via optimal permutation to that reference. Reduces OT to a Hungarian assignment + Euclidean distance.
  *Replication cost*: 15min CPU (N=500 is tiny for Hungarian; reference = mean of all activations).
  *We'd plausibly run this*: yes — simple and would expose whether activation alignment to a reference carries signal.

- **OT-NNA (Nearest Neighbor Accuracy via W₂)** — two-sample test: compute pairwise W₂ matrix between point clouds, run 1-NN, report accuracy (optimal=0.5). Adapts directly to "are correct/incorrect activation distributions distinguishable?"
  *Replication cost*: 20min CPU (500 samples, pairwise matrix is 500×500, each entry is a sort for sliced version).
  *We'd plausibly run this*: yes — immediate two-sample test on our cached data.

- **Coupled outer/inner transport plans (WoW framework)** — models distributions of distributions. Would require framing each problem's activations as a distribution (e.g., across layers or token positions) and then computing transport between these meta-distributions.
  *Replication cost*: 2h CPU for a multi-layer extraction + WoW computation.
  *We'd plausibly run this*: maybe — requires multi-layer activations we don't currently cache (only L19).

## Approaches & framings

- **Metameasure geometry (measures over measures):** Reframes the problem from "how do individual points differ" to "how do populations of distributions differ." For us: instead of asking "does this single activation predict correctness?", ask "does the *population* of correct activations, as a distribution, differ geometrically from the incorrect population?" This is a distributional-level reformulation of F-2.

- **Transport plan as a richer signal than scalar distance:** The paper emphasizes that the OT *coupling* itself (which points map to which) carries information beyond the scalar cost. For our problem: the optimal coupling between correct and incorrect activations could reveal which incorrect problems are "close" to correct ones — potentially a soft version of the D-bucket signature (F-7).

- **Straightness of flow paths as a quality metric:** In flow matching, straighter paths indicate better coupling. If we interpret the "flow" from incorrect→correct activations in residual stream space, path straightness could indicate how much information the model needs to "add" to go from uncertain to confident — a different angle on F-5 (content-dependent breathing).

## Implementation details worth capturing

- Sliced Wasserstein with M=50 random projections is sufficient for generation tasks (d=2,3); for d=1536 more projections may be needed (suggest M=200–500).
- Adam lr=5×10⁻⁴ for all flow matching training (not directly relevant to us).
- POT library (Python Optimal Transport) used for all OT computations — pip-installable, well-maintained.
- Barycentric reference ρ̂ computed from B_ref=8 samples for LLW; for our use the barycentric reference would be the global activation mean.
- Euler integration with 125 steps for generation quality; for our discriminative use case we only need the transport *cost*, not the full flow trajectory.

## Replicable intermediates

- **SW₂ between correct/incorrect L19 prefill clouds:** Load `pathway11_h100/prefill_gated_compute/` NPZ, split by correctness label, compute sliced Wasserstein with `pot.sliced.sliced_wasserstein_distance`. Compare scalar SW₂ as a population-level discriminability metric.
- **Per-problem SW₂ to class centroids:** For each of 500 samples, compute SW₂ from that single-point "distribution" (degenerate) to the correct/incorrect centroids. This reduces to comparing distances, so actually simplifies to a mean-distance classifier — sanity check that SW₂ doesn't degenerate to Euclidean for point measures.
- **OT cost matrix between stratified activation subsets:** Take K=5 random 50/50 splits of correct vs incorrect, compute pairwise W₂ (via Sinkhorn on the 250×250 cost matrix), report NNA. Compares directly against Gaussian null.
