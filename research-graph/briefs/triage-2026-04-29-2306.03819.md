# Triage brief — 2306.03819 — LEACE: Perfect Linear Concept Erasure (Belrose et al., 2023)

Source: https://arxiv.org/abs/2306.03819
Triaged: 2026-04-29

## Refutations

LEACE is a closed-form affine map P\* = I − W⁺ P\_{WΣ\_XZ} W (with whitening W = (Σ\_XX^{1/2})⁺) that **provably renders a target concept Z linearly undetectable** in features X with **minimum mean-squared change** across all inner-product-induced norms. It is the strongest minimum-damage linear-erasure baseline available, and it is a refutation tool for any of our findings whose framing depends on a *linearly readable* axis in the residual stream.

1. **Refutation of F-2 (Prefill L19 DoM is a strong correctness predictor, AUROC 0.7731):** Fit LEACE on cached Qwen-1.5B prefill L19 features with the K=1 correctness label as Z, transform the features, and re-fit the DoM probe. *Mechanism*: LEACE removes **all** linear-classifier information about correctness while changing features minimally. *Falsifiable prediction*: AUROC should collapse to ≈0.5. If AUROC remains substantially above chance after LEACE-scrubbing, then either (a) our DoM is not actually exploiting linear-readable correctness (the probe is leaking via a non-linear residual / measurement artifact), or (b) the LEACE-scrubbed embedding still carries correctness via interactions our linear-probe protocol is silently using. Either outcome reframes F-2.

2. **Refutation of F-3 (Prefill & final-token DoM are orthogonal, cos = 0.046):** Apply LEACE at L19 to scrub the *prefill-derived* DoM direction across the train fold, then refit the *final-token* DoM and re-measure final-token DoM AUROC. *Mechanism*: cos = 0.046 rules out one specific overlap (single-vector cosine) but does not rule out shared linear subspaces of rank ≥ 2. LEACE kills the entire rank-r linear-separability subspace for the prefill correctness concept, not just one direction. *Falsifiable prediction*: if F-3's "geometrically unrelated" framing is right, final-token DoM AUROC (currently 0.7186) should be **unchanged** post-prefill-scrub. A drop of >0.05 AUROC would refute F-3's strong-orthogonality reading and show the two probes share a covert linear subspace.

3. **Refutation of F-9 (CoE-60 is redundant with single-layer L19 DoM):** LEACE-scrub L19 with the correctness label; this perfectly erases linearly-readable correctness at L19 and propagates downstream via concept scrubbing (Section 6). *Mechanism*: if CoE-60 truly sources its 0.811 AUROC from L19, post-scrub CoE-60 should collapse to chance. *Falsifiable prediction*: if CoE-60 AUROC drops to ≈0.5 after L19-only LEACE, F-9 is reinforced. If it survives (e.g., still ≥0.70 by sourcing from earlier layers), F-9's "redundant with single-layer" framing is **wrong** — CoE-60 is exploiting a multi-layer signal that L19 alone doesn't capture. This is a sharper test than the original L19-vs-CoE-60 comparison because it surgically deletes L19's content rather than swapping probes.

4. **Refutation of H-1 (per-position DoM steering):** LEACE-scrub the prefill DoM at L19 *during inference*, not training. If steering at the same direction recovers any of the lost correctness signal, the steering mechanism is exploiting a non-linear interaction LEACE cannot reach — supports H-1's mechanistic-direction claim. If LEACE wipes both the predictive signal *and* the steering effect, then the DoM is a passive correlation-readable axis only, and per-position steering is a probe-leak artifact (kills H-1).

## Direct connections to F-N / H-N

- **F-2 (AUROC 0.7731, prefill L19 DoM):** LEACE provides the canonical closed-form **null** — what AUROC looks like when the linear correctness-readable subspace at L19 is surgically deleted with minimum collateral damage. Currently we have no such null; the gap between 0.7731 and "what survives LEACE" is the strict-linear-information lower bound on F-2.
- **F-3 (cos = 0.046, prefill ⊥ final-token):** LEACE upgrades F-3 from a single-vector orthogonality claim to a *subspace-level* orthogonality claim, by testing whether the entire rank-r linear-readable correctness subspace at prefill is disjoint from final-token's.
- **F-7 (D-bucket collective signature):** LEACE applied to the B-vs-D label gives a stricter test than DoM AUROC on D — if D-bucket survives perfect linear erasure of its label, the "geometric signature" is non-linear in the residual stream and our single-layer linear-probe framing of F-7 misses the mechanism.
- **F-9 (CoE-60 ≡ L19 DoM):** LEACE-scrub L19 then re-evaluate CoE-60 — see refutation #3 above; this is the sharpest available test.
- **F-10 (PH = Gaussian null on trained residual streams):** LEACE on the *random-Z* control would predict identical PH statistics, since random Z encodes no signal — gives a sanity check that PH is dimensionally agnostic to LEACE-deletable concepts.
- **H-1 / H-13 (head-level attribution):** LEACE provides a layer-specific erasure baseline that head-level attribution can be compared against.
- **H-8 (DoM stable across training checkpoints):** Re-fit LEACE on early/late Pythia checkpoints; the LEACE-required Σ\_XZ rotation across checkpoints is a direct measurement of DoM rotation, complementary to H-8's cosine-based test.

## Methodologies extracted

- **LEACE closed-form projection** — P\* = I − W⁺ P\_{WΣ\_XZ} W, where W = (Σ\_XX^{1/2})⁺. Computed from feature covariance Σ\_XX and feature-concept cross-covariance Σ\_XZ. Pip-installable via `concept-erasure`.
  *Replication cost*: <10 min CPU on cached prefill\_L19 NPZ for one (model, layer, label) triple.
  *We'd plausibly run this*: **yes** — it's the missing strict-null for F-2, F-3, F-9. Highest-leverage import in this brief.
- **Concept scrubbing (Algorithm 1)** — fit LEACE at layer ℓ, apply, propagate to ℓ+1, refit, repeat for all transformer blocks (post-layernorm at each block input). Sequential because intervention at ℓ shifts the distribution at ℓ+k.
  *Replication cost*: ~1h H100 per (model, label) for full residual-stream pass on Qwen 1.5B (28 layers); needs forward hooks.
  *We'd plausibly run this*: **yes** but only after the single-layer LEACE result; this is the multi-layer test of "is correctness representation distributed across the residual stream or localized at L19?"
- **Bits-per-byte perplexity evaluation post-erasure** — measure LM degradation after erasing the concept, distinguishes surgical from collateral damage. (Pythia 160M no-intervention 0.90 → LEACE POS-scrubbed 2.79; random projection 0.99.)
  *Replication cost*: ~30min H100 for a single Qwen 1.5B post-scrub LM eval on a held-out chunk of MATH-500 prompts.
  *We'd plausibly run this*: **yes** — directly measures whether scrubbing correctness-from-L19 wrecks downstream MATH performance, which would be a positive *causal* result.
- **Comparison to mean ablation / SAL / INLP / RLACE** — paper ranks LEACE > RLACE ≈ LEACE in fidelity but ~100× faster; INLP drops 360 dims, LEACE drops 17. Useful as a methodological yardstick if we ever publish steering comparisons.
  *Replication cost*: medium; INLP/RLACE are open-sourced.
  *We'd plausibly run this*: **no** — outside scope; we'd just cite the paper's findings.

## Approaches & framings

- **"Linear guardedness" as a formal property** — concept Z is linearly guarded in features X iff every linear classifier on X performs at chance on Z. This is a stricter, testable analog of the informal "the model doesn't represent X" claim that pops up in our F-2 / F-3 framings.
- **Minimum-damage erasure as a Pareto frontier** — LEACE is not just "an erasure method" but the *closed-form optimum* on the (linear erasure × min L2 perturbation) frontier across all inner-product-induced norms. Reusable framing for any future steering / refusal-probe work where damage-vs-effect tradeoffs matter (intersects H-1, H-12, H-13).
- **Concept scrubbing as a counterfactual on the residual stream** — running scrubbing layer-by-layer is operationally a counterfactual model "what does this network do when concept Z is linearly absent everywhere?" This is the missing intervention for any of our findings that currently rest on correlational probes (F-2, F-7, F-9).

## Implementation details worth capturing

- Reference implementation: `pip install concept-erasure` (https://github.com/EleutherAI/concept-erasure).
- LEACE fits in O(d²) memory and a single matrix square root + pseudoinverse — trivial on cached NPZs.
- Concept-scrubbing application point in transformers: **input of each transformer block, immediately after layernorm** (Section 6.1). Same hook point as Pathway 11's L-by-L extraction; the existing forward-hook scaffolding is directly reusable.
- Pythia + LLaMA tested across full size range (160M → 30B); residual-stream post-LN application transfers cleanly to Qwen-2.5-1.5B / 7B.
- Reported numerical sensitivity: low — closed-form, no training instability. Random-projection control to distinguish "concept removed" from "any projection breaks LM".
- Hyperparameter knob: rank of the cross-covariance Σ\_XZ. For binary correctness label, rank ≤ 1 — single-direction erasure, equivalent to debiasing along the DoM direction *with* whitening (this is the key delta vs. naive subtract-the-mean-direction).

## 2306.03819 — LEACE: Perfect Linear Concept Erasure (Belrose, Schneider-Joseph, Ravfogel, Cotterell, Raff, Biderman, 2023)

**Relevance:** LEACE is the closed-form, minimum-damage linear-concept-erasure operator. Our F-2 / F-3 / F-9 findings all rest on linear-probe geometry of L19 prefill activations; LEACE provides the strictest available **null** for those findings (what does the probe see when the linear-readable correctness subspace is surgically deleted with minimum collateral damage?). The paper's "concept scrubbing" multi-layer procedure is also the natural causal-test counterpart to our existing correlational DoM probe — it converts a "DoM finds X" claim into an interventional "the model relies on X at every layer" test.
