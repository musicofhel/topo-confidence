# Triage brief — 2605.04255 — Entropic Riemannian Neural Optimal Transport

Source: https://arxiv.org/abs/2605.04255
Triaged: 2026-05-09

## Refutations

**R1 — Entropic OT distance could refute the sufficiency of linear DoM (F-2).**
F-2 establishes that a single linear direction (DoM ≈ PC1) at L19 prefill achieves AUROC 0.7731 for correctness prediction. The entropic OT framework provides a *distributional* distance between correct and incorrect activation clouds that is sensitive to nonlinear manifold structure (geodesic cost, not Euclidean), higher-order moments, and the full coupling — not just a single projection. If the entropic OT distance between correct/incorrect L19 prefill distributions (computed with geodesic cost on the activation manifold) substantially outperforms DoM AUROC (e.g. ≥0.82), it would refute the claim that a single linear direction captures the dominant correctness signal — the excess performance must come from nonlinear or distributional structure that linear DoM misses.
*Mechanism:* Compute entropic OT cost OT_ε(μ_correct, μ_incorrect) for L19 prefill activations under Euclidean and Riemannian (e.g. SPD or data-driven) costs; use coupling weights as per-sample correctness scores; compare AUROC to 0.7731.
*Falsifiable experiment:* Run entropic RNOT on cached 500×1536 L19 prefill activations split by correctness label; if AUROC ≤ 0.78, refutation fails and linear DoM sufficiency holds.

**R2 — Riemannian geometry of activations could refute the Gaussian null (F-10).**
F-10 establishes that PH summary statistics on residual streams are indistinguishable from a matched Gaussian null. However, F-10 tested only Vietoris-Rips PH with Euclidean distance on ambient 1536-d space. If the activation manifold has non-trivial Riemannian curvature (as would be revealed by geodesic-cost OT differing substantially from Euclidean-cost OT), then using Euclidean distance for PH is the wrong metric — PH with geodesic distance or Riemannian-aware methods might distinguish correct from incorrect where Euclidean PH could not. The entropic RNOT framework provides a principled way to measure this: if OT_ε with geodesic cost ≠ OT_ε with Euclidean cost on the same activations, the manifold has non-trivial curvature and Euclidean PH was using the wrong distance.
*Mechanism:* Compare entropic OT distances under Euclidean vs learned-Riemannian cost on L19 prefill activations.
*Falsifiable experiment:* If Euclidean and Riemannian OT costs are highly correlated (Spearman ρ > 0.95), then curvature is negligible and F-10's Euclidean assumption holds; refutation fails.

**R3 — Barycentric projections could refute the orthogonality of prefill vs final-token DoM (F-3).**
F-3 reports cos(prefill_DoM, final_DoM) = 0.046, interpreted as structural orthogonality between the two processing phases. However, this was measured via Euclidean cosine similarity of the mean-difference vectors. If the activation manifold has curvature, Euclidean cosine similarity is not the correct inner product — the Riemannian inner product in tangent space at the Fréchet mean could yield a substantially different angle. The RNOT framework's barycentric projection and Riemannian logarithmic maps provide the machinery to recompute this angle intrinsically.
*Mechanism:* Compute Fréchet mean of all L19 activations; log-map prefill and final-token DoM vectors into the tangent space at that mean; recompute cosine similarity in the tangent-space inner product.
*Falsifiable experiment:* If tangent-space cos(prefill_DoM, final_DoM) > 0.3, the orthogonality claim is an artifact of Euclidean measurement on a curved manifold.

The Gibbs coupling π_ε assigns each source sample a transport mass profile; asymmetry in this profile between correct/incorrect groups is a distributional generalization of the scalar DoM projection.

If activations live on a curved submanifold of ℝ^1536, geodesic distances ≠ Euclidean distances, and PH computed with the wrong metric would be expected to see "noise" (matching the Gaussian null) even if intrinsic topology is non-trivial.

- **H-729 (activation manifold curvature):** This paper provides the exact computational machinery to test H-729. If cached L19 activations are embedded via log-map at the Fréchet mean and the pullback metric differs from Euclidean, curvature is non-trivial.

## Methodologies extracted

- **Semidual neural Schrödinger potential** — Parameterize target-side potential g_θ as a 2-layer MLP (256 hidden, SiLU) composed with a feature embedding φ, optimize via stochastic gradient ascent on the semidual objective J_ε(g_θ). Recovers entropic OT coupling as a Gibbs measure.
  *Replication cost*: 30min–1h CPU for 500×1536 data (paper trains in 24s on A6000 for comparable sizes; CPU will be slower but feasible).
  *We'd plausibly run this*: yes — the architecture is a small MLP, the optimization is standard Adam, and the 500-sample L19 data fits easily. JAX implementation available.

- **Barycentric projection via Karcher iterations** — Given the learned coupling, project to a deterministic transport map via iterative Fréchet mean computation (32 iterations, step 0.5) using Riemannian exp/log maps.
  *Replication cost*: 10min CPU once the coupling is trained (simple iterative scheme).
  *We'd plausibly run this*: yes — but only meaningful if we first establish non-trivial curvature in the activation manifold.

- **Heat-smoothed conditional surrogates** — Smooth atomic conditional laws via heat kernel convolution, turning discrete transport plans into continuous densities. Uses Varadhan geodesic approximation.
  *Replication cost*: 15min CPU (Varadhan approximation is a simple distance-based exponential kernel).
  *We'd plausibly run this*: no — primarily useful for density estimation on manifolds, less directly applicable to our binary classification task.

- **Feature embedding via Riemannian logarithmic coordinates** — For SPD/hyperbolic manifolds: φ(x) = Log_z(x) maps to tangent space at base point z. For activations this would require choosing a base point (e.g. Fréchet mean) and computing log-map coordinates.
  *Replication cost*: 20min CPU for computing tangent-space coordinates of 500 samples.
  *We'd plausibly run this*: yes — this is essentially a nonlinear dimensionality reduction that could be compared against PCA for correctness prediction.

- **Median-cost heuristic for ε selection** — Set regularization ε = 0.05 × median(cost matrix). Simple, principled, avoids hyperparameter search.
  *Replication cost*: trivial (one line of code once cost matrix is computed).
  *We'd plausibly run this*: yes — useful for any OT-based experiment.

## Approaches & framings

- **Distributional distance as correctness metric.** Rather than projecting activations onto a single direction and thresholding, compare the *distributions* of correct vs incorrect activations via entropic OT cost. This reframes correctness prediction as a two-sample testing problem with a transport-based test statistic. Intersects F-2: if OT cost is much more discriminative than DoM, the correctness signal is distributional, not directional.

- **Amortized out-of-sample transport.** Train a transport potential once on the training split; apply to new samples at inference time without re-solving OT. This is directly relevant to the selective-prediction stack (F-8): if the learned potential generalizes, it could score new problems without per-instance computation, unlike the current OOF 5-fold DoM approach.

- **Intrinsic vs extrinsic geometry of activation space.** The paper's core argument is that treating curved data as Euclidean distorts distances and averages. This is the central question for our program: are L19 activations approximately Euclidean (in which case linear DoM is optimal) or do they have non-trivial Riemannian structure (in which case manifold-aware methods should dominate)?
